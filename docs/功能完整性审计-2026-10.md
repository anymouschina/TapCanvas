## 二、已修复

### 运行时缺陷
1. **Agent 诊断面板缺组件**：`AgentDiagnosticsContent.tsx` 引用的 `agent-diagnostics/AgentApiExecutionChain` 不存在，生产构建/打开诊断面板失败。已补齐组件（任务选择、阶段链、关联诊断记录）。
2. **语义召回类型契约缺失**：`execution.project-asset-match.ts` 引用的 `agents/semantic-recall.client` 不存在，已补类型契约。
3. **跨章节资产复用永远不命中**：匹配逻辑读取 `sourceFacts.assetReuseKey`，但项目节点资产与快照从未投影该字段。已在 `material.project-node-assets` 与 `execution.project-context` 中补齐。
4. **空章节画布保存崩溃**：章节 `canvas_flow` 为 `{}` 时 `putChapterCanvasFlow` 抛 `TypeError`（`reconcileEditableChapterNarrative` 假设 `nodes` 存在），连带让版本冲突无法以 409 返回。
5. **drive 模式锁顺序错误**：`orchestrateVideoRun` 会用被禁止的内联 `storyPlan.runId` 抢 run 锁；锁被占时本应 400 的请求返回成功 noop。
6. **API Key 权限**：`/agent-api/*` 未纳入 `agent:execute` scope 校验（防御性补齐）。
7. **内置问候工作流**：固定回复为不当文案「我是你爹」，已替换为正常问候，并按不可变版本规则发布 v3（新 `flowVersionId`），避免旧部署启动时报「版本不可改写」。
8. **工作流调用合同误判**：带固定文本的 `workflow.input.text/v1` 节点被判为 `sourceMode=inline_text` 并要求调用方提供 `source`，与执行器「预置文本优先」语义矛盾。

### 提示词 / 工具合同不一致（模型会被引导到必然失败的调用）
1. **角色身份板**：给模型的工具 schema 与 zod 合同要求 `faceViews: [front, three_quarter]`、`readableTextVisible: false`，而 `tapcanvas-character-card` 技能、四宫格模板、执行侧解析器与共享 asset schema 都是 v3 的 `[front, profile]`、`readableTextVisible: true`。按工具 schema 提交会被执行侧拒绝。已统一为 v3，并增加「工具 schema ⇔ 执行解析器」对齐测试。
2. **账号生成偏好上下文**：提示词规则引用了「新账号初始偏好」这一优先级层，但偏好未开启时只写「偏好未开启」，模型看不到服务端实际兜底的模型与规格。现在会写出初始偏好精确值。
3. **图片理解模型**：模型已改为部署配置 `IMAGE_UNDERSTANDING_MODEL_KEY`（默认 `doubao-seed-2-1-turbo-260628`），但 Agent 工具描述、OpenAPI 文档仍写死 `gpt-5.6-luna`。已改为读取真实配置值。
4. **`tapcanvas-visual-focus` 技能**：指示调用不存在的 `tapcanvas_vision`，并传 `imageUrl/modelAlias/vendor` 等真实工具不接受的参数。已改为 `tapcanvas_analyze_image`（`nodeId`/`assetId` + `prompt`）。
5. **`tapcanvas-parse-video` / `tapcanvas-api` 技能**：引用未注册的 `tapcanvas_parse_video_to_canvas`、`tapcanvas_video_retry`。已加可用性说明，避免模型盲调或擅自重提付费任务。

### 工程/测试基础设施
- web 测试缺 `VITE_OBJECT_STORAGE_*` 与 PWA 虚拟模块，导致 70+ 测试文件整体无法加载；已在 vitest 配置中补齐。
- 大量测试夹具落后于当前合同（logicalTaskId、terminalAuthority、logicalTaskState、资产 imageSource、拓扑节点等），已按当前合同更新。
- `CLAUDE.md` 中的命令已失效（`pnpm -w install` 只装根依赖、compose 文件不在 `apps/hono-api`、`db:update:local` 不存在），已更正。
