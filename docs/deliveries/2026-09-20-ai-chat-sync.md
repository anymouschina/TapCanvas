# AI 对话修复同步

来源为 TapCanvas-pro 当前工作区（源 HEAD `0129df801`，包含未提交修复）。本次按对话行为选择性同步，保留 TapCanvas 的 DSH 内核、统一聊天动作入口与已受理工作流的单一持久执行归属。

## 修复范围

- 项目 Flow 创建期间排队，项目/章节切换时隔离待发送消息；队列消费保持顺序。
- 历史消息合并保留本地失败消息的相对位置，同时间戳的用户/助手消息采用稳定排序。
- 会话重置、状态恢复与 SSE 连接支持取消；旧会话异步结果不能覆盖新会话，消费端异常不会触发无限重连。
- 真实终态、物理暂停和暂时未知状态分别投影；恢复能力只来自实际 checkpoint。
- 显式取消逻辑任务时取消其 continuation；物理连接中断保留任务状态，DSH 晚到回调不能覆盖中断快照。
- 普通响应的 Agent 自检可绑定成功工具取证回执；失败回执不能证明交付，有冻结合同而缺少自检时显式失败。
- 工作流工具 `oneOf` 的每个选择分支具有完整调用参数，避免合法触发字段被误拒绝。

## 边界

没有同步 Pro 的旧 Agent loop、A2A/Agent API 新能力、默认模型策略或基于固定超时抢占执行者的逻辑。没有改动 TapCanvas-pro 运行服务、真实画布或数据库，也没有执行付费成片。
