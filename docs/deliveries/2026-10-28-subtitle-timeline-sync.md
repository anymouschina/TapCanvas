## 使用

- 在视频合成编辑器中，字幕条现在可整体拖动；左右边缘分别调整开始和结束时间。重叠字幕分行排列，点击字幕定位播放头并选中左侧内容。
- 聚焦字幕条后，左右方向键按 10 毫秒移动；按住 Shift 使用 100 毫秒步长。聚焦边缘按钮时相同按键调整对应边缘。Escape、指针取消、失焦或缩放变化取消尚未提交的拖动。
- 关闭编辑器或导出时，字幕源时间、样式与实例标识一起保存到 `composeSubtitles`；重新打开恢复。剪辑片段的裁剪/分割布局仍属于当前编辑会话，本轮没有新增剪辑工程持久化。
- 同 URL 的不同上游视频节点使用真实节点 ID 区分，编辑一份字幕不会改另一实例。匿名调用方没有节点 ID 时，以 URL 内的出现序号区分；不能辨识两个完全相同匿名输入互换。
- 连续分割的字幕保持合并；跨不同素材移动会按素材边界拆成独立字幕段，文字保留。裁剪外字幕源范围保留，后续改变裁剪范围可重新显示。
- 重叠字幕在预览与本地烧录中按相同顺序分行显示；字幕覆盖层持续到所有字幕中的最晚结束时间。
