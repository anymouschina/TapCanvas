# 无缝转场/变装爆款导演（短视频达人套路层）

> **职责边界**：本 skill 只产「转场与变装套路方法论」——四类转场、首尾帧钉法、变装身份锁、爆款节奏。成片 pass/fail 判据归 `tapcanvas-video-reviewer`；拆镜硬判断归 storyboard-expert `镜头语言规则.md`；氛围光影归 `cinematic-feel-director`。本 skill 叠在 `tapcanvas-video-workflow` 之上，**不改编排、不改护栏、不改模型/时长决策**。
>
> **定位**：本 skill 管「为什么这条片的转场丝滑、变装炸、一刷停不下来」——靠**转场是设计出来的（不是生怼）+ 变装锁住身份 + 卡点钩子前置**。
>
> **三个接入点**：S1（定转场母题 + 变装次数 + 反差爆点 + 锁身份）；S4（转场类型标到镜间 + 衔接帧对齐）；S6 clipPrompt（首尾帧钉转场 + 变装身份锁 + extend 续链）；S8 QA（无缝/不变脸诊断）。

## 核心诊断 · AI 套路片两大死法

| 死法 | 症状 | 解法 |
|---|---|---|
| **转场硬切跳帧** | 两镜直接生怼，构图/动作/光线全跳；毫无丝滑感，像 PPT 翻页 | 转场是**设计**出来的：四类无缝转场之一 + 首尾帧钉对齐 |
| **变装变脸** | 换装后连人脸都变了，成了另一个人；身份漂移 | **变装身份锁**：脸/发型基底/体型硬 DNA，只换服装造型不换人 |

## 1. 四类无缝转场（转场类型库）

转场不是「切」，是把相邻两镜**缝**起来。四种主力套路：

| 类型 | 原理 | prompt 关键 |
|---|---|---|
| **遮挡擦除** | 物体/手/身体扫过镜头，挡黑瞬间切下一镜 | `hand/object swipes across frame and wipes the cut, foreground occlusion transition` |
| **运动匹配** | 上镜的运动（甩、转、跳）接下镜同方向运动 | `whip pan transition / match on motion, camera and subject motion continues into next shot` |
| **同构图匹配 (match cut)** | 上镜尾帧构图=下镜首帧构图（同位置同形状），内容偷换 | `match cut: same composition and subject position, the scene/outfit changes` |
| **光效过渡** | 过曝/光斑/暗场/失焦做衔接遮罩 | `flash/overexposure/lens flare/defocus transition between shots` |

> 一条片选 1~2 种转场母题贯穿，别每镜换花样（杂乱反而不爽）。

## 1.5 元素接力 morph 衔接（顶流"丝滑"真正的招）

四类转场是"怎么缝"；这一招是"用什么缝"——**让上镜的最后一个视觉元素 morph(形变) 成下镜的第一个元素**，镜与镜靠一个**共享物像**焊死，比单纯构图对齐更狠、更可控（不依赖首尾帧一定生成得出来）。例：刀光满屏→枪口火光；冲击波亮环→枪口火焰；子弹冲镜→摩托车灯。**更多实采案例与来源见 [[liblib-tv-top-works-distilled]] §二**。

**具名词表**（写镜间转场说明 + 单镜内部分拍转场都用）：遮蔽/Wipe、相似/Match Cut、**动势匹配**(旋转/甩动方向接续)、**光源匹配**(枪火→车灯→法光)、**形态匹配**(圆环→圆环、刀光→披风弧)、**反射/反光接力**、**子弹时间**(speed ramp 顿帧——剪辑层专用，禁写入 clipPrompt；生成式等价=表演凝滞+慢运镜)、烟尘/碎屑/披风**遮蔽接力**。

**工程落地（比纯首尾帧钉更稳，文字接力兜底）**：
- S4 拆镜：为每个镜间**指定一个"接力元素"X**，写进镜头表"转场"列——`本镜末 = X 填满/扫过镜头；下镜首 = 由 X morph 而来`。
- S6 写 clipPrompt：**本镜结尾一句**明确该元素填满/扫过镜头（`the [element] sweeps across and fills the frame`）；**下镜开头一句**明确从该元素移开或它形变为新物（`opening on the [same element] which morphs into [next subject]`）。首尾帧能生成就再钉同构图双保险，生成不出也有文字接力。
- **同一支片接力元素母题统一**（全片走"光源接力"或"遮蔽接力"为主），别每镜换一种 morph 逻辑。

## 2. 首尾帧钉转场（关键技法）

无缝的工程实现 = **让上镜的尾帧和下镜的首帧在同一个「点」上对齐**：

- S4 就预设：上镜**尾帧**的动作位/构图 ≈ 下镜**首帧**的动作位/构图。
- S6 用**首尾帧过渡**钉死这个衔接点（上镜 end frame = 下镜 start frame 同构图）。
- 甩动/遮挡类转场：在尾帧让遮挡物刚好挡满镜头，下镜首帧从遮挡物移开开始——黑场对齐即无缝。
- 每个转场缝逐镜裁决：普通匹配剪辑走 `editorial_cut + exitState`；精确变装/形变落幅走 `bridge_frames`；只有真实连续运镜、运动惯性或声场必须继承时走 `reference_video`。不得整片机械串行，也不得整片强制并发。

## 3. 变装身份锁（变装片命门）

变装片最大死法是「变完装脸也变了」。**身份是硬 DNA，造型是变量**：

- 锁定卡只锁**五官 / 发型基底 / 体型**，这三样逐镜原文重复、绝不漂移。
- 每镜 prompt 显式带：`keep the SAME person's face/hairstyle base/body identity consistent, ONLY change the outfit and styling`。
- 变量是：服装、配饰、妆造、场景、光（但光要全片统一基调，防画风跳）。
- **变装物理逻辑**：相邻两套 look 之间若跨度太大（如运动装直接到晚礼服），转场点要给「遮挡/甩动」掩盖换装过程，别让观众看出穿帮。
- 负向恒带：`avoid face morphing/identity drift/becoming a different person across outfit changes`。

## 4. 爆款节奏（达人套路）

| 招 | 做法 |
|---|---|
| **钩子前置** | 第 1 镜（前 3s）就给最炸的：最强反差变装预告 / 最丝滑的那个转场 / 一个悬念 |
| **卡点变装** | 每次变装/转场踩在 BGM 重拍上，节奏点对齐（`editingStyle:'montage'`）。**镜长不规划 sub-floor**：seedance 单镜恒 ≥4s，要更快的卡点切换靠**减少镜数 / 一镜内多次变装**实现剪辑级快切，别写 2~3s（会被 snap 抬到 4s 撞时长上限，见主编排『每镜下限』） |
| **反差爆点** | 全片留一个最炸的反差（土→潮 / 素颜→妆成 / 日常→惊艳），放在钩子或收尾 |
| **统一画风** | 变装/穿越不许跳画风——色调/光线/质感全片统一，只变造型场景 |

## S4 / S6 / S8 接入清单

- **S4**：定转场母题（四类选 1~2）→ 把转场类型标到每个镜间 → 预设相邻镜的衔接帧对齐（尾帧≈首帧）→ 卡点段靠减少镜数实现快切（镜长仍守模型最小档，不写 sub-floor）。
- **S6**：按冻结的连续性模式执行转场；bridge 用真实首尾帧钉 A→B，reference_video 从上一段真实终态续接，editorial 用元素/动作/构图匹配剪辑。三种模式都保留 exitState、变装身份锁、卡点 BGM 与必要音效。模型/时长按主编排硬约束选、不预设。
- **S8**：①转场是否无缝（无硬切跳帧/撕裂）②变装是否不变脸（身份逐镜锁）③卡点节奏与反差爆点是否成立、钩子是否前置 ④画风是否全片统一。
