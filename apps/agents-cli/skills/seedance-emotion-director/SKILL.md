# Seedance 情绪导演（表演层方法论 · per-shot 版）

> **职责边界**：本 skill 只产「表演层创作方法论」——情绪生理化、情绪曲线、动作四要素。成片「木偶脸/演过头」的 pass/fail **判据归 `tapcanvas-video-reviewer` 的 V4**（唯一真相源），本 skill 不另列质检清单。

> **定位**：本 skill 管「角色怎么演」——情绪、动作、台词声音的可拍摄化。它叠在 tapcanvas-video-workflow 之上，**不改编排、不改护栏、不改模型/时长决策**。整片级的画风/身份/氛围由锚定卡与 seedancePrompt 固定层承载（锁身份不锁构图），**情绪与表演内容只写进每镜的变化层（镜头表 + clipPrompt），禁止写进锚定卡原文**（否则静态情绪会传染全片）。
>
> **四个接入点**：
> | 环节 | 用法 |
> |---|---|
> | S2 资产层（2026-07-16 用户拍板） | **强情绪镜批前出「表情图｜<角色>·<情绪>」资产**（自动入库 kind=pose、跨章按名复用）：视觉锚从角色卡**表情栏已设计的格**里选最接近的图生图派生、⛔禁凭空发明表情；措辞按本 skill 双档词表选档+四维同在公式写。日常微表情档不出资产。情绪仍⛔禁写进基准卡原文（身份板恒中性） |
> | S4 镜头表 | 编剧定情绪节拍＝先选情绪曲线链；每镜标注情绪阶段；「神态」列只写生理表现 |
> | S6 clipPrompt | 动态五件套之外的第六层自检：情绪生理化 + 动作四层次 + 台词四维标注 |
> | S8 QA | 审「木偶脸」：情绪无生理支撑/面无表情/长时间不眨眼/说话只动嘴 → 进返工清单；审「演过头」：日常镜露牙大笑/直接嚎哭/情绪只有表情没有肢体载体 → 进返工清单 |

## 铁律一 · 禁文学化修辞

比喻/拟人/象征/夸张一律替换为对物理世界的直接描述（模型拍不出"心如刀割"，拍得出肌肉与呼吸）：

| 禁止 ❌ | 改写 ✅ |
|---|---|
| 心如刀割 | 她双手按住胸口，呼吸急促，面部肌肉扭曲 |
| 怒火中烧 | 他瞳孔放大，下颌咬紧，颈部血管凸起 |
| 悲痛欲绝 | 她双膝跪地，额头抵住地面，肩膀剧烈抽动 |
| 柔情似水 | 她眼睑低垂，视线缓慢移动，嘴角轻微上扬 |

## 铁律二 · 禁精确物理数值

毫米/厘米/度数/赫兹/受光比/小数比例模型无法执行，一律用相对化、可感知描述：

| 禁止 ❌ | 替换 ✅ |
|---|---|
| 移动 X 厘米/秒 | 缓慢/匀速/快速，耗时约 X 秒 |
| 距离 X 米 | 一臂距离／一拳之隔／人物占画面一半 |
| 瞳孔 X 毫米 | 瞳孔明显扩大，眼白增多 |
| 机位 X 度 X 厘米 | 与眼睛平齐／略低于肩膀／从头顶垂直向下；近到看清睫毛／远到人物只占画面一角 |
| 颤抖幅度 X 厘米 | 轻微颤抖／明显颤抖／剧烈颤抖 |

## 情绪 → 生理对照表（写「神态」的唯一合法方式 · 双档按强度选）

**选档规则（防演过头的第一道闸）**：AI 对抽象情绪词的默认演法是夸张化——写「很开心」就露牙大笑，写「很委屈」就直接哭出来。所以**先判断本镜在情绪曲线上的位置再选档**：日常场景/曲线爬坡段/低强度情绪一律用【微表情档】；只有曲线峰值镜/强戏剧场景才允许用【强情绪档】（且峰值镜必须伴随失控反应）。日常镜误用强情绪档＝违和的"演过头"，进 S8 返工清单。

### 微表情档（日常/低强度，默认档）

公式：**面部情绪 = 嘴角状态 + 眼部状态 + 面部状态**——把大情绪拆成三个面部部位的可控小细节。

| 情绪 | 微表情拆解 |
|---|---|
| 开心 | 嘴角轻轻上扬，眼神柔和，眼睛微微弯起，面部放松，脸颊微微上提 |
| 委屈 | 嘴角轻轻下压，眼眶微微泛红，表情有一瞬间的僵住 |
| 紧张 | 嘴唇轻轻抿住，眼神略微游离，表情有些紧绷 |
| 生气 | 嘴角略微下压或紧绷，眼神锐利目光集中，眉头紧皱，面颊紧张 |
| 惊讶 | 嘴巴微张，眼睛睁大瞳孔微微放大，眉毛上抬，额头拉伸 |
| 害怕 | 嘴角微微下拉、嘴微张，眼睛睁大但目光游移不定，眉毛紧缩或上挑，面部微微僵硬 |
| 悲伤 | 嘴角明显下垂，眼神黯淡、眼眶湿润，眉毛轻微内收，面部下垂 |
| 厌恶 | 上唇微抬下唇轻抿，眼睛微眯或偏向一侧，鼻梁轻微皱起，面颊紧绷 |
| 惊喜 | 嘴角大幅上扬，眼睛弯成月牙目光闪烁，脸颊明显上提，额头舒展 |
| 困惑 | 嘴角紧抿，眼神略微游离或偏向一侧，眉毛一高一低或轻微皱起 |

示例：约会被夸的开心 ≠ 露牙大笑，而是「嘴角轻轻上扬，眼神变得柔和，眼睛微微弯起」；被误会的委屈 ≠ 哭出来，而是「眼眶微微泛红，嘴角轻轻下压，表情有一瞬间的僵住」——这才是大部分人的第一反应。

**与动态规则的调和（两轴不混）**：微表情档管的是**表情强度轴**（防演过头），动态五件套管的是**画面运动轴**（防 PPT 感）——二者不冲突：日常镜用微表情档时，本镜的"动"由四维公式的**手部动作/身体姿态/视线移动**承载（捂嘴/捧礼物/前倾/视线落点变化都是有幅度的动作），微表情只是动作的面部伴随，不是本镜唯一的动。同理「动作幅度放大 1.5 倍」只适用于**肢体动作**（治模型动作幅度衰减），**表情强度不放大**、严格按双档走。

### 强情绪档（峰值/戏剧场景专用）

| 情绪 | 生理表现 |
|---|---|
| 恐惧 | 瞳孔明显扩大，眼白暴露增多，胸口快速起伏，手指轻微颤抖，身体向后缩紧 |
| 愤怒 | 下颌肌肉隆起，颈部青筋可见，鼻孔扩张呼气粗重，拳头紧握至指节发白，肩膀向前顶出 |
| 悲伤 | 眼睑缓慢下垂，下眼睑湿润反光，嘴角明显下拉，肩膀向内收紧，头部低垂至胸口 |
| 喜悦 | 嘴角明显上扬，眼角出现皱纹，身体舒展打开，动作幅度增大 |
| 震惊 | 瞳孔骤然收缩，嘴巴微张未合，身体瞬间僵直，长时间不眨眼 |
| 决绝 | 下颌向前顶出，眼神直视固定一点，嘴唇抿成一条线，动作变慢但用力加重 |
| 麻木 | 面部松弛无表情，眨眼间隔变长，身体长时间静止，胸口几乎无起伏 |
| 绝望 | 瞳孔涣散无焦点，头部无力下垂，双手自然垂落身侧，膝盖弯曲跪地 |
| 仇恨 | 眼神直盯目标，嘴角下拉，下颌咬紧，呼吸平稳控制，动作精准无多余 |
| 爱恋 | 视线缓慢扫过对方面部，眼睑低垂，嘴角轻微上扬，身体不自觉倾向对方 |

## 情绪曲线（S4 定，跨镜执行）

**模板**（按剧情选用或组合）：
- 正向链：平静 → 疑惑 → 震惊 → 狂喜 → 失控 → 崩溃 → 释然
- 负向链：压抑 → 愤怒 → 爆发 → 疯狂 → 毁灭 → 空洞

**升级规则**：
1. 每镜在镜头表标注所处情绪阶段，每个阶段必须通过**表情、动作、声音**三通道同步体现；**情绪阶段同时决定词表档位**——爬坡段/回落段用微表情档，峰值镜才切强情绪档（见双档对照表选档规则）；
2. **相邻镜禁情绪跳变**，必须有过渡缓冲（呼吸变化/视线移动/小动作衔接）；
3. 情绪峰值镜必须伴随**失控反应**（见动作四层次）；
4. 情绪回落镜用呼吸节奏放缓、肌肉松弛、动作减速体现。
5. **曲线与节奏联动**（节奏=情绪推进速度，见 video-workflow `references/reference-xhs-director-theory.md` §一）：曲线爬坡段配「情绪铺垫型」慢节奏（少切换、给观众观察细节的时间）、峰值前配「信息压迫型」快切、峰值=「情绪爆发型」先压抑再释放，**峰值镜之后排一个「突然抽空」镜**（突然降速/静默/只剩环境声）——反差让失控反应的冲击力翻倍，也正好承接第 4 条的回落。

## 动作设计（治木偶化）

**四维同在公式（情绪必须有载体）**：**情绪状态 = 表情细节 + 手部动作 + 身体姿态 + 视线方向**，四个维度必须同时在场——只有表情没有肢体＝"用力表演"，四维齐备才是"真实反应"。给每种情绪匹配一套完整的身体反应状态流：

| 场景示例 | 四维写法 |
|---|---|
| 被朋友逗笑（害羞又忍不住） | 嘴角轻微上扬＋手轻轻捂住嘴＋肩膀微微抖动、头稍微后仰＋眼神闪烁 |
| 收到礼物感动 | 嘴角轻轻抿住＋双手轻轻捧住礼物＋肩膀微微收紧＋视线落在礼物上、眼眶微微湿润 |
| 看到喜欢的咖啡拉花（小惊喜+满足） | 嘴角上扬＋右手轻轻抚摸杯沿＋身体微微前倾、头微微偏向一侧＋视线落在拉花上 |

**四要素**：每个动作有起点→过程→终点；动作间有过渡不跳跃；速度有变化（缓慢→加速→骤停）；幅度与情绪强度成正比。力度用「轻柔/用力/爆发」，耗时用「约 X 秒」。

**四层次**（角色必须具备，至少两层同时在场）：

| 层次 | 定义 | 示例 |
|---|---|---|
| 微动作 | 无意识、持续性小幅动作 | 手指轻微抽搐、嘴角无意识颤动、脚尖轻点地面 |
| 惯性动作 | 情绪驱动的习惯动作 | 紧张摸耳垂、焦虑搓手指、愤怒握拳又松开 |
| 神经反应 | 突发刺激的本能反应 | 瞳孔震动、吞咽、喉结滚动、重心瞬间失衡 |
| 失控反应 | 情绪峰值的身体失控 | 肩膀剧烈抖动、膝盖发软、牙齿打颤、身体前后摇晃 |

改写示例：禁「开心地笑」→「嘴角先不受控制抽动，随后笑容迅速扩散至整张脸，肩膀跟着剧烈抖动」。

## 情绪触发原因（情绪不凭空·给"发生起因"）

> 一帆《一个公式控制所有AI视频角色表情》(2026-07-01 蒸馏) 的第二核心：**四维公式解决"怎么演"，但情绪还要解决"为什么演"**。AI 人物尬演的另一半根因＝**情绪凭空出现**（prompt 只给"一个女生紧张"，模型无从演起、只能摆抽象 pose）。

**升级公式**：**真实情绪 = 发生原因 + 表情细节 + 肢体动作 + 说话语气**（后三项＝上面的四维/三通道；前置的"发生原因"是本节新增层）。

- **情绪原因不是多余的剧情**：情绪镜要在画面里给人物一个**触发事件**作起因——人物**看到 / 听到 / 经历**了某件事，情绪才有合理的发生点。写 clipPrompt 时先交代"人物看到/听到/经历什么"，再接四维表演反应链。
- **触发在画面内可见/可感**（不是背景设定）：让触发源进画（那盏红灯、那位旧友、那桌惊喜），人物**先感知→再反应**，观众看得到因果。
- **一帆三例（照抄反应链骨架·换你的触发事件即可）**：
  | 情绪 | ❌凭空 | ✅带发生原因（触发→四维反应链） |
  |---|---|---|
  | 开心 | "一个男人开心" | 男生**突然看见多年没见的朋友**，先愣一瞬 → 眼神逐渐亮起 → 嘴角慢慢上扬 |
  | 紧张 | "一个女生紧张" | 女生独自站在医院走廊，**抬头看见手术室红灯还亮着** → 视线停在灯上不动 → 手指慢慢攥紧衣角 → 肩膀绷住 → 呼吸变浅 |
  | 感动 | "一个女生感动" | 女生推开门，**发现家人悄悄布置的生日惊喜** → 愣一瞬 → 手慢慢捂住嘴 → 眼神在房间来回扫 → 嘴角轻扬 → 眼眶湿润 |
- **同台词多情绪＝四维差异化的最佳自检**（一帆"走开"五版）：同一句"走开"，撒娇=嘴角上扬+头偏一侧+很轻语气；嫌弃=眉头轻皱+鼻尖收紧+身体后仰+不耐烦；愤怒=眉头紧锁+下颌紧绷+身体前倾+低吼；害怕=眼神闪躲+声音发颤+小声；崩溃=眼眶泛红+声嘶力竭。**情绪全靠表情+肢体+语气三维拉开，不靠台词本身**——拆镜时用它检验"这镜情绪写具体了没"。

**接入**：S4 镜头表标情绪节拍时，情绪转折镜先问"这情绪的触发事件是什么、在不在画面里"；缺起因就补一个可见触发（或把触发拆到前一镜），禁只标抽象情绪词。S6 写 clipPrompt 按升级公式：触发事件 → 表情+肢体+语气四维反应链。

## 台词与声音真实化

台词原文仍按 S6 规则作 spoken dialogue 写进 clipPrompt（模型原生发声+口型），**标注以描述词形式贴在台词前后**：

- **四维标注**：语速（缓慢/正常/急促/断断续续）、音量（耳语/低声/正常/大声/嘶喊）、情绪（发抖/哽咽/破音/喘息/停顿）、音质（清晰/沙哑/颤抖/劈裂/含混）。
- **声音类型**：气音（音量极低几乎被环境音盖住）；嘶喊（声带劈裂感、尾音断裂）；断续（"我……我真的……"省略号即呼吸中断）；唇动无声。
- **笑/哭禁写结果，必写形成过程**：笑＝短促吸气→鼻腔挤出笑声→演变成狂笑；哭＝鼻腔堵塞感→压抑抽泣→肩膀剧烈抽动→嚎啕。禁直接写「哈哈哈」。
- **说话时身体必须参与表演**（转头/抬手/前倾），倾听者必须有反应，对话间隙的静默要描述（与动态五件套第④条同源）。
- 声音设计四类齐备：环境声、动作声（脚步/衣物摩擦/碰撞）、呼吸声（沉重/急促/屏息/颤抖）、情绪声（牙齿打颤/压抑抽泣/尖锐狂笑）。

## 单镜情绪长拍（⭐通用范式 · 哭戏为母例 · 2026-07-16 蒸馏自抖音@小王不AI干正事《你能否让我停止这种追逐》，同日用户拍板举一反三到全部情绪）

15s **一镜纯情绪独角戏**的成立范式（适用：任何强情绪镜/情绪MV/情绪特写钩子镜，零台词或极少台词）。与跨镜情绪曲线互补——曲线在**单镜内部**走完一个完整弧。**本范式对所有情绪通用**，四个机制都是情绪无关的结构件：

**四段弧模板**（按秒标注、拍长自定——2026-07-17 拍板密度守恒：每段直接写成一行 3~5s 长拍，把该段的完整微表情/动作弧写满在同一拍文本里，⛔禁再拆成多行独立镜号；描述量与时长相称即合规）：
1. **压抑起点**（~0-3s）：情绪已满但被按住——只给**泄漏级微征**（从微表情档取词）；
2. **生理失控**（~3-6s）：控制动作被**生理极限打破**——情绪的"决堤事件"（一滴泪落/一声笑漏/拳头砸下前的僵住）；
3. **对抗动作**（~6-10s）：对失控的**性格化反应**——动作**用力过猛/矫枉过正**才见性格（赌气擦泪/狠掐自己大腿忍笑/把拳头慢慢松开）；
4. **质变定格**（~10-15s）：反向对峙动作 + **眼神质变收尾**：情绪过程结束时**性格显影**（脆弱→倔强坚毅；暴怒→冰冷杀意；忍笑→眼底真笑意），定格缓缓暗下。

**对抗写法公式（本范式核心·所有情绪通用）**：每一拍 = **控制企图 × 失控泄漏**同时在场。情绪不是单向释放而是内部拉扯——只写释放=演过头俗套，只写控制=木偶脸；两股力同写才有张力：
| 情绪 | 控制企图 × 失控泄漏 |
|---|---|
| 悲(哭) | "试图伪装坚强"ד睫毛不受控微颤"；"极力睁大眼睛"ד泪珠绝望滑落" |
| 怒 | "刻意压低声音放慢语速"ד指节攥到发白、太阳穴跳动" |
| 惧 | "站直不动、下巴抬起"ד膝盖细微打颤、吞咽" |
| 喜(忍笑) | "板着脸移开视线"ד嘴角不受控抽动、鼻腔漏出一声气音" |
| 心动/羞 | "假装专注手里的事"ד耳根泛红、余光一次次飘过去" |

**⭐举一反三推导公式（任意情绪三步套用）**：①**泄漏起点**从【微表情档】取该情绪的词（=压抑段的微征）；②**失控峰值**从【强情绪档】取词（=决堤段的生理表现）；③两端之间按**生理递进**补全生命周期链（从最小可见征兆到不可逆临界点，禁跳步），再套四段弧+对抗公式。双档词表给两端、生命周期链给路径、对抗公式给每步写法、四段弧给时间结构、质变收尾给出口——五件套齐即成片。

**情绪生命周期链**（禁跳步，按序取用；其它情绪按推导公式自行补链）：
- **泪**：眼眶发红 → 泪水在眼底汇聚 → 折射晶莹眼神光 → 饱满泪珠从眼角滑落 → 划过脸颊留下清晰水痕 → 擦拭 → 残余斑驳泪光 → 频繁眨眼逼回；
- **怒**：下颌咬紧 → 呼吸变粗鼻翼扩张 → 颈侧青筋凸起 → 指节攥到发白 → 拳头/肩膀微颤 → 爆发（砸/吼）或强压回（缓缓松拳、闭眼深呼吸）；
- **惧**：瞳孔扩大眼白增多 → 呼吸变浅 → 吞咽、喉结滚动 → 手指微颤 → 重心悄悄后移 → 僵直定住或转身逃；
- **忍笑**：嘴角抽动 → 用力抿嘴 → 鼻腔漏气 → 肩膀开始抖 → 绷不住笑出声（或憋回去眼里全是笑）。

**身体自反馈**（环境反馈链的身体版·动作必须在身体上留痕·所有情绪通用）：粗暴擦拭→皮肤泛红摩擦痕迹；用力压迫→肌肉真实变形；绷紧→下颌线紧绷、脖颈青筋隐现；攥拳→指节发白掌心月牙印；呼吸转换→胸腔起伏带动肩膀。动作不留痕=贴图感。

## 环境反馈链（动作必须改变环境）

| 动作强度 | 反馈示例 |
|---|---|
| 轻微 | 纸张捏皱、灰尘扬起、水面涟漪 |
| 中等 | 水瓶掉落、货架震动、桌面闷响 |
| 强烈 | 玻璃震颤碎裂、门被猛力推开、物体翻倒 |
| 极端 | 墙壁碎屑脱落、家具移位、地面裂缝 |

反馈与动作**同步**发生，禁延迟、禁无因果。

## 特殊场景速查

- **对话镜**：说话者带动作、倾听者带反应、间隙静默有描述、对话内情绪要有升级或变化。
- **动作镜**：预备姿态→重心转移→动作后失衡/恢复，全程带环境反馈。
- **内心独白**：禁直接呈现"内心画面"，用微动作/神经反应/环境变化外化。
- **群体镜**：标注个体与群体关系、视线方向（看谁/不看谁）、空间位置、情绪传染过程。
