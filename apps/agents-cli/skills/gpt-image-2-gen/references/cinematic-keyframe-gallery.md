# 电影级关键帧 look 配方库

> 蒸馏自 [wuyoscar/GPT-Image2-Skill](https://github.com/wuyoscar/GPT-Image2-Skill) gallery（cinematic-and-animation №26-30 + cinematic-film-references №147-152），保留「配方结构」剥掉具体内容——**配方是语法不是模板**（反同质化铁律同规：⛔禁把某条配方的具体场景/构图当默认套路复用）。
> 本地化红线：原文里的 `film grain / 35mm 颗粒 / photoreal` 触发词已剥；**生成关键帧必须叠加全局画风锚参考图**，配方只贡献光比/色板/构图骨架，画风归锚定图。

## 通用配方骨架（每条 look 都由这五件组成）

1. **一句 lineage 定调**（承何种电影视觉血统，如「德国表现主义黑色电影」）——⛔只用流派/美术运动名，**禁真人导演/演员名**、禁点名 IP/作品（2026-07-10 版权拒实测：输出侧审核审成片，真人名与知名形象指纹组合都会撞；细则见 knowledge 卡 ip-safe-design-fingerprint）
2. **色板点名 2–4 色**（双色调对撞是史诗感最稳解）
3. **光的物理来源与对比度**（单一硬光/漫射雾光/轮廓逆光 + 阴影深度）
4. **构图与镜头语言**（对称/低角度仰拍/广角深焦/尺度对比）
5. **情绪一句话收束**（awe/dread/宁静/荒诞）

## 配方速查

### A. 强对比史诗（chiaroscuro）——「强烈对比的史诗电影级画面」首选
- 光：**单一硬主光 + 深部阴影**，影调从纯白到纯黑全域拉开；可加百叶窗/格栅投影做几何阴影。
- 色：近单色 + 一个受控强调色（如墨黑/骨白 + 一点绯红）。
- 构图：剪影优先、低角度、硬轮廓光勾主体边缘。
- 模板句骨架：`高对比 chiaroscuro 布光，单一硬光源来自<方向>，深邃阴影吞没<次要区域>，<主体>被轮廓光从背景中剥出，全域影调。`

### B. 巨物崇高（monolithic scale）——压迫感/神性/终局奇观
- 核心是**尺度对比**：渺小人形 vs 巨构（占画 2/3 以上），人如尘沙。
- 光：低对比漫射、朦胧无直射日光；巨构表面哑光油亮。
- 色：工业单色系（深黑/板岩灰/沙赭）。
- 构图：广角深焦、地平线极低或极高、大面积负空间制造「古老的寂静」。

### C. 双色调迷雾 neo-noir——末世/孤独/悬疑
- 色：**Amber & Cobalt 类双色调对撞**（浓雾单色底 + 一个冷色光点切开）。
- 光：无太阳的恒定弥散辉光，压平细节只留剪影层次。
- 构图：低角度仰视压迫性结构，雾中若隐若现的轮廓分层（近/中/远三层剪影）。

### D. 表现主义阴影几何——心理惊悚/梦境/扭曲
- 场景像舞台布景：建筑歪斜内倾、锯齿三角阴影铺满地面。
- 光：高对比 + 硬逆光 + 蒸汽/积水反射；阴影本身是构图主角。
- 色：墨黑/失泽黄铜/骨白 + 一个远处强调色光源。

### E. 手绘温暖（吉卜力系 painterly）——治愈/日常/自然奇观
- 媒介词：水彩-水粉手绘质感、柔画意边缘、云和草有笔触。
- 光：金色时刻/夏晨的乐观亮度，柔和绘制阴影。
- 色：微降饱和的绿 + 暖肤色 + 花青天色；角色细墨线。

### F. 全 CG 质感（Pixar 系 3D）——需要体积感/材质细节的奇观镜
- 材质词：次表面散射（耳朵/薄物透光）、物理材质、柔和 AO、体积光束、浅景深。
- 造型：干净风格化形体，明确「非恐怖谷」。

### G. 慢电影凝滞（Tarkovsky 系）——⚠️仅叙事片意境镜可用
- 近单色自然色（苔绿/冷灰/湿褐 + 一粒琥珀光），浓雾晨光，静态构图，可触摸的质感（木头腐斑/露珠）。
- ⛔纯享战斗片禁用此系（凝滞预算/戛然而止铁律优先）。

## 用法纪律

- 选配方 = 选**光比+色板+构图骨架**，具体场景/主体/记忆点每次原创（动笔前先定「这一帧的独特记忆点」）。
- 关键帧 prompt 组装顺序：`比例/画布 → 配方光色构图骨架 → 场景具体名词 5-12 个 → 主体与动作瞬间 → 情绪一句 → avoid 短清单`。
- 参考图：全局画风锚必挂 + 出场角色的角色卡（锁脸），配方词只补光色构图——画风描述与锚定图冲突时**以图为准、删文字**。
