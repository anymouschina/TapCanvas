# gpt-image-2 提示词工艺清单（关键帧/海报/分镜向）

> 蒸馏自 [wuyoscar/GPT-Image2-Skill](https://github.com/wuyoscar/GPT-Image2-Skill) 的 craft.md（162 例 gallery 提炼），已按本项目红线本地化：**禁「写实/超写实」、禁噪点触发词（胶片颗粒/grain/35mm/做旧）**；执行一律走自有 new-api 链路，不涉外部 API key。
> 电影级 look 配方见同目录 [cinematic-keyframe-gallery.md](cinematic-keyframe-gallery.md)。

## 1. 画布/比例/版式先于主体

最强的 prompt 都先分配空间再描述细节：`16:9 横版电影关键帧…`、`3:4 竖版海报…`、`3×2 六格分镜网格…`。结构不先声明，模型会把细节预算全花在主体上、版式即兴发挥。

## 2. 画面内文字一律进直引号

需要在图内渲染的文字（题卡/招牌/字幕条/标注）逐字写进 `"…"`，中文原样不转述；多块文字用 `/` 或版式标签分隔；必须可读时加「清晰、无乱码错字」。装饰性文字就说明是装饰。gpt-image-2 中文排版精准，这是它对本项目的核心价值之一（章节封面/分镜标注）。

## 3. 场景密度 > 形容词堆砌

弱：「夜晚的便利店」。强：点名 5–12 个具体名词（冰柜贴纸/促销海报/门口地垫/玻璃反光/湿沥青/手机冷光）+ 2–4 条材质光线约束。⛔禁裸堆 `stunning / beautiful / professional / high quality` 这类无视觉锚点的空形容词——这条与视频提示词的反 slop 纪律同源。

## 4. 材质 / 光 / 色板是三个独立旋钮

别压缩成一个「高级感」：

- **材质**：拉丝金属、宣纸、亚麻、玻璃厚度、冷凝水珠…
- **光**：单一硬主光、柔光箱、轮廓光、霓虹反射、晨光侧射…（强对比画面写 chiaroscuro：单一硬光源方向 + 深部阴影 + 完整影调范围）
- **色板**：直接点名 2–4 色（`靛蓝/橘红/米白`、`amber and cobalt duo-tone`）——史诗感强对比画面的最稳做法是**双色调对撞**而非「色彩丰富」。

## 5. 风格锚要具体且有边界

点名美学/媒介/流派/制作语境（「新中式国漫赛璐璐」「水墨留白+工笔细节」），而不是「好看的动漫风」。**本项目关键帧必须同时挂全局画风锚参考图**（铁律：禁裸生成），文字风格锚只做参考图的补充说明，不与画风图打架。

## 6. JSON/config 式结构化 prompt（复杂画面可选）

当画面有多个交互子系统（环境/主体/材质/光/粒子/输出目标）时，用结构化 schema 比散文可控：

```text
{
  "GLOBAL": { "aspect_ratio": "16:9", "style": "<画风锚补充说明>" },
  "ENVIRONMENT": { "background": "…", "lighting": "…", "atmosphere": ["…"] },
  "SUBJECT": { "primary": "…", "materials": ["…"], "composition": "…" },
  "OUTPUT": { "mood": "…", "avoid": ["…"] }
}
```

键名描述视觉子系统，值写具体视觉约束；数组放可见元素，嵌套对象放材质/物理/光。JSON 不必机器合法，干净可读即可。

## 7. 多格板（分镜/表情格/网格）靠一致性约束

格数精确声明（`3×2`、`16-panel`）、每格给职责/节拍、**共享的美术方向/色板/服装/身份约束写一次全局生效**。分镜格带镜头语言元数据（WIDE/OTS/CU/低角度/摇移/时长）。本项目身份板版式骨架见 video-workflow SKILL 步骤 4（那是拍板铁律，优先级更高）。

## 8. 编辑/多参考图必须声明角色分工与不变量

图生图/编辑模式下手术式描述：先说变什么，再显式锁不变（`只改光线与天气，人物身份/站位/构图保持一致`）。多参考图逐张点名角色：`图1=角色身份，图2=画风基准，图3=场景`——只说「都当风格参考」必翻车。身份/文字/几何跨轮迭代时每轮重申不变量。

## 9. 负向词短而准，只打强先验

只在模型有明确坏默认时加 avoid（`避免赛博朋克霓虹、避免伪日文乱字、no text, no watermark`）。负向清单过长会反客为主。本项目恒带：`no text, no name tag, no watermark`（卡面类），且工具层已自动剥「写实/颗粒」词——prompt 里从源头就别写。

## 10. 海报级画面过「三眼测试」

- 第一眼：剪影/主题瞬间可辨（史诗关键帧的强对比就是为这一眼服务）。
- 第二眼：能读出叙事世界/承诺/信息层级。
- 第三眼：近看有质感细节、小标注、背景彩蛋。

商业海报另加信息层级：主题最大 → 标语 → 模块 → 细则，`legible from a distance`。

## 11. 拍摄语境解锁真实感（谨慎用）

`低机位三分之一角度`、`28mm 广角平视`、`清晨自然侧光`这类**拍摄语境**词比「真实」有效。只选一个主导机位设定，多机位描述互相打架。⛔ `RAW/iPhone 实拍/监控画面` 类词条在本项目基本用不上（风格化国漫），保留认知即可。
