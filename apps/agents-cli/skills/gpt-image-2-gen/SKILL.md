# GPT Image 2 出图方法论（本地版）

> **定位（重要）：本 skill 只给方法论，不执行、不调用外部 key。**
> 本项目的图像生成统一走自己的链路：画布 `image` 节点 / `tapcanvas_image_generate_to_canvas` 工具 → new-api 的 `gpt-image-2` 渠道。
> 因此当需要真正出图时，**用项目自有的生图工具/节点**，把下面的参数与提示词方法论填进去即可；**不要**去注册 EvoLink、不要设任何 `*_API_KEY`、不要 curl 外部端点。

> 本 skill 只服务明确选用 gpt-image-2 的图像任务，不再声明全局默认模型。角色卡必须先使用 `tapcanvas-character-card` 完成设计，再从本轮 `enabledImageModels` 与账号生成偏好选择精确可执行模型和规格；本 skill 不覆盖角色卡的体型、媒介、身份板结构、反趋同或 prompt。gpt-image-2 易出噪点时，可按本 skill 的模型工艺规避，但这只是已选模型的执行建议。

## 何时参考本方法论

当任务涉及用 gpt-image-2 出**线稿 / 设计稿 / 分镜图 / 故事板 / 含文字标注的图 / 电影级关键帧**时（文生图、图生图编辑、批量变体、分镜/网格合成图等），用本文的参数与提示词知识来组织调用本项目的生图工具。彩色出图同样走 gpt-image-2（2026-06-18 拍板全局默认，gemini 已撤）；仅画风锚专图走 doubao-seedream。

## 英雄镜关键帧（2026-07-10 新增职责）

视频管线的「镜头级关键帧」由本 skill 方法论承制。`storyboardImageNodeId` 是图片用途字段，不是媒体类型：单一必要状态直接生成普通 image；确需表达连续变化时，才把 2～3 个决定性状态按时间顺序合并成一张故事板 image；无需额外视觉锚时不生成。两种图片都可以进入对应 clip 的参考图集合并按一张业务图片计费/计预算；禁止一格故事板、整章母板、通用设计板、四格以上分镜板和站位图进入视频参考。
- **准入判据（一句话：这一镜值得当海报才预热）**：K1 英雄镜（变身/大招亮相、climax 决定性瞬间、强对比史诗画面）；K2 文字不可达构图（chiaroscuro 强光比/多元素精确空间关系/极端机位）；K3 新视觉事件首次定义（优先走状态版卡/场景卡既有机制，不重复造）。
- **禁区**：打斗密拍中段（主支出=运动，多图=保真透支）；普通叙事对白镜；「只是想更好看」。
- **配额**：每 run 关键帧 ≤ clip 数 ~15%（15 镜章节 ≤2 张）。挂了关键帧的镜其余参考图降配（画风锚可省——关键帧生成时已锚画风；角色卡只留跨段认人必需）。
- **生成侧**：必须带全局画风锚+出场角色卡作参考图，禁裸生成；2K、比例随片。
- 工艺清单与 look 配方：[references/keyframe-craft.md](references/keyframe-craft.md)、[references/cinematic-keyframe-gallery.md](references/cinematic-keyframe-gallery.md)。

## 参数方法论（gpt-image-2）

| 参数 | 说明 | 默认 |
|---|---|---|
| **prompt** | 图像描述或编辑指令。越具体越好（风格/光线/材质/构图）；上限很高但简洁常更稳。 | 必填 |
| **referenceImages** | 图生图/编辑：1–16 张参考图（jpeg/png/webp）。用于角色/产品视觉一致性。URL 需可直接下载。 | 可选 |
| **size / 比例** | 比例制：1:1 / 16:9 / 9:16 / 4:3 / 3:2 / 21:9 等；或精确像素 `WxH`（16 对齐，最大 3:1）；或 `auto`。 | auto |
| **resolution** | 仅比例制有效：`1K`(~1MP) / `2K`(~4MP) / `4K`(~8.3MP)。需要高质量时显式传 `2K`。 | 1K |
| **quality** | `low`(草稿/便宜) / `medium`(均衡) / `high`(成片，约 4× 成本)。 | medium |
| **count(n)** | 一次出几张变体（用于挑选）。 | 1 |

> 注：本项目 new-api 的 gpt-image-2 渠道，2K 需渠道具备对应 tier model（否则计费/出图会失败）；预算不足时先用 1K 迭代，锁定后再上 2K。

## 尺寸 / 分辨率速查（比例制）

| 比例 | 1K | 2K | 4K |
|---|---|---|---|
| 1:1 | 1024×1024 | 2048×2048 | 2880×2880 |
| 3:2 | 1248×832 | 2512×1680 | 3520×2352 |
| 4:3 | 1184×880 | 2368×1776 | 3312×2480 |
| 16:9 | 1360×768 | 2736×1536 | 3840×2160 |
| 21:9 | 1568×672 | 3136×1344 | 3840×1632 |

竖图把宽高对调。像素制下 `resolution` 被忽略。

## 提示词方法论

场景卡（包括一键成片内部首轮场景生图）先使用 `tapcanvas-scene-card`，其“首轮生图：空间职责与洁净材质”是纯场景与噪点预防的唯一创作方法。本文的英雄镜、人物参考和电影质感配方不适用于无人空间卡；不得套用后再安排二次去人/去噪。质量参数不是去噪强度，不编造 denoise strength 或以 high 保证无噪点。

- 具体、有画面感：写清主体、风格、光线、镜头、氛围。
- 编辑模式：明确"加/改/删什么"，并提供已验真的结构化参考资产 ID 当锚点（如 character-card/v3 身份卡版本 ID、产品资产 ID）。
- 文字渲染：gpt-image-2 中文文字排版精准，含文字的图(海报/UI/标注分镜)优先用它。
- 一致性：跨格/跨图保持角色与场景设定不变，把固定描述写进每次 prompt。

## 成本方法论

- 草稿/迭代用 `low` + `1K`；线稿定稿上 `high` + `2K`（本项目 gpt-image-2 封顶 2K，禁 4K）。
- 用 `count` 批量探索变体，挑定再精修。
- 比例制 + resolution 比纯像素更省心。

## 模型能力速记

- 文生图 / 图生图编辑（1–16 参考图）/ 批量。
- 比例 15 档 + 精确像素；分辨率 1K/2K/4K；质量 low/medium/high。
