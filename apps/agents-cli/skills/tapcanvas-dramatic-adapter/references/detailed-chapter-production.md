# 完整展开版章节生产

适用于从已有小说或剧本一键成片的章级创作。它扩展现有 `source_coverage_and_causality`、`delivery_scope_and_duration`、`audience_narrative_legibility`、`action_causality_physics`、`camera_composition_and_lens` 和 `sequence_control_execution`，不新增 schema、最低字数或语义质量门禁。当前用户明确的短版、预告、指定范围或限时要求优先。

## 交付目标

没有明确的缩写要求时，交付完整展开版：读到章节末尾，覆盖事件、对白、心声、消息、必要设定、关系变化、动作因果和结尾。先完成可演出的内容，再推导总时长与片段数。估算秒数只是预算说明，不是截断上限；不得根据历史运行的十段、四个节拍、样例时长或单次供应商窗口反推内容删减。

“最详细”指有效内容和演出充分，不是重复原文、填充形容词或让每镜都复杂。原文中具有不同信息或人物作用的内容分别有承载；同一事实不因重复写在标题、账本和镜头说明里就算多次完成。

## 扩写、润色与视听设计

- 扩写先补原文省略的可演出过程：刺激与判断、动作准备与执行、接触和结果、人物反应、道具交接、空间变化与转场。保留既有主线、人物关系、世界规则和结尾方向。新增过程记录其来源锚点与作用；不可把创作补充伪称为原文事实。
- 润色改善叙事衔接、表演节奏、视听可读度和表达精度。原文逐字发声账本保持不变；授权新增人声单独进入 narrativeAudioPlan。用户未授权重写原文台词时，不以润色名义删句、换义或改写既有发声。
- 特效先说明剧情依据、触发主体、空间影响、可见阶段、环境响应及结束后残留，再由单段 writer 编译。具有能力、梦境或主观感知依据时充分设计相应表现；普通文戏可以靠表演、调度、光影和声音达到完整度，不为“详细”凭空增加能力、爆炸或胜负结果。
- 运镜先由章级规划确定观众应看见什么、何时获得信息以及动作与转场边界；单段 writer 根据冻结事实设计景别、构图、摄影运动和剪辑。镜头运动服务信息与动作，不代替主体实际完成动作，也不在每段重新开场收尾。
- 扩展完成后重新核算发声、换人、反应、动作、特效阶段和转场所需时间。可同步发生的声画安排重叠，需要独立注意力或物理先后的过程分别留时；容量不足时增加合法片段或调整尚未冻结的边界，不通过虚报语速和省略后半章解决。

## 同链自检和证据

章级作者从原文逐项反查最终草稿，而不是让草稿自己的摘要证明草稿完整。将来源事件落到 sourceFidelityAudit.sourceBeatLedger，将源人声落到 sourceCoveragePlan.speechLedger，并核对实际事件、声音和状态变化的承载。新增表演与表达进入现有事件、状态和叙事音频字段。可执行字段可以简练，但来源义务不能缩减。

冻结前检查遗漏、被摘要替代的过程、对白容量与跨段承接；发现问题就在当前作者链补写并重排相关段落。单段 writer 只展开已冻结事实；不能接管上游改剧情，也不能把无法容纳的源事件藏在审计字段。冻结后发现矛盾时保留所属输入与具体问题，由原规划责任方按授权修订路径处理，不擅自重置已经受理的媒体。

## 完成声明与批次边界

完整章稿、全章提示词、视频节点准备和真实完整成片是不同交付。用户只要求完善规则时不启动生成；onlyVideoNodes 仍按原用户选择执行。

max clip、供应商时长和单批数量属于物理生产边界。前 N 段完成只证明本批次完成；若章级来源清单还有未承载范围，保留余段与原任务范围，不得称整章已经完成。启动前检查已装配配置能否兑现已冻结的全章目标；发现范围冲突，由当前 Agent 在已授权配置或分批能力内解决，不能静默接受删尾，也不能绕过付费边界或假设不存在的自动续批能力。

“不能声明整章完成”不是终止任务或拦截资产的理由：保留成功结果，继续当前授权范围内的规划、提示词修订或合法恢复。仅结构性事实由代码验证，创作与覆盖判断由 Agent 依据真实来源承担；不得建立本地关键词、分数或最低时长闸门。


## 验收不能由缩写稿自证

源账本必须先于物理段数。审查时从完整原文向最终事件和发声反查，不能仅比较由同一份短稿产生的 sourceBeatLedger 与 storyEvents。世界规则、内心判断、问答推进、喜剧停顿、情感转折与结果各有承载；写进摘要或资产说明不算观众已经经历。长话轮按 dialogue-duration-planning 的连续逐字片段跨 Clip 承载，不因完整句大于单次窗口而丢弃。

“化腐朽为神奇”体现在补足可演出的过程、压力与选择、铺垫和兑现、人物微妙反应及有动机的视听表达。保留只是起点，不能把原本有戏的内容降成事件梗概，也不能靠增加同义修饰词或重复镜头伪装扩写。已正确展开的部分保留，缺口在原任务内补充。
