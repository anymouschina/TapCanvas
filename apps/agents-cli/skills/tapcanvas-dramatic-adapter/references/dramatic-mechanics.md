# 叙事机制与反例

## 可迁移机制

### 实力或能力兑现

```text
建立限制与怀疑 -> 主角承受压力或主动付代价 -> 能力以具体结果兑现 -> 旁观者/对手/环境被迫改变判断 -> 新压力出现
```

价值来自判断和权力变化，不来自光效大小。没有前置怀疑和后续反应的能力展示只是演示片。

### 身份或真相揭露

```text
具体错误认知 -> 可回看证据 -> 简洁揭晓 -> 关系或行动立刻改变 -> 揭晓带来更大的未解问题
```

揭晓后所有人继续原计划，说明信息没有戏剧价值。

### 悬疑与安静张力

```text
稳定常态 -> 一个可验证异常 -> 人物给出暂时解释 -> 第二证据使解释失效 -> 人物选择隐瞒/追查/逃避 -> 风险逼近
```

动作少不代表节奏慢。物证每次改变判断，观众会持续向前。

### 喜剧递进

```text
观众知道规则 -> 人物误解规则 -> 为修复误解采取行动 -> 行动制造更大误解 -> 真相以最不合时宜的方式暴露
```

喜剧兑现是预期错位和关系后果，不是把角色写笨或突然摔倒。

### 克制情绪

```text
人物维持日常程序 -> 具体刺激打破节奏 -> 人物更用力维持控制 -> 一个小动作泄漏真实压力 -> 选择暴露他愿意付的代价
```

外部冲突可以很低，行动选择必须很具体。

### 动作与战斗

一次有效交换必须改变距离、角度、退路、资源、信息或控制权。`A 出招 -> B 格挡 -> 拉开 -> 重来` 没有新局势，只是动作轮播。

## 反例集

用这些反例防止系统把“吵、快、密”误判为精彩：

- 克制丧亲：外部冲突低，但日常程序被一个缺席物件改变，情绪和选择很强。
- 密集追车：剪辑很快，但人物没有目标、路线判断和代价，质量应判低。
- 安静物证：动作少，一个物证连续推翻两次解释，追看力应判高。
- 喜剧误会：没有打脸升级，兑现来自观众预知与人物误判的时间差。
- 反高潮：刻意不兑现外部胜利，但人物拒绝旧价值，仍构成不可逆变化。
- 乱序快剪：信息很多却无法建立因果，不能因“高密度”得高评价。

## 题材适配

不要套固定波形。先判断本章真正的观看承诺：求胜、求真、求爱、求生、求认同、求和解、求失控快感或求审美余味。节奏结构服务承诺，不能反过来让所有故事变成升级打脸。
