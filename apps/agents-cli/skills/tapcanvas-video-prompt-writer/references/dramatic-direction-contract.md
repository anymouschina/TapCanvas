# 戏剧导演与战术交换合同

## 目标

把章节原文从“事件摘要”改造成观众能经历的戏。专业感不来自镜头术语数量，而来自三条同时成立的因果链：

1. 人物链：目标与赌注 -> 有限感知 -> 判断/误判 -> 不可撤回选择 -> 后果 -> 下一策略改变。
2. 导演链：观众跟谁看 -> 观众和角色各知道什么 -> 按什么顺序揭示 -> 权力如何改变。
3. 物理链：位置/距离/角度/惯性 -> 动作 -> 过冲/刹停/恢复 -> 新局势。

情绪不是第四条独立装饰链。情绪必须改变人物何时出手、是否迟疑、愿意付什么代价，或失败后怎样调整下一次选择。

每拍还必须服从连续性账本：期待债务有稳定 ID 和生命周期，完整兑现不得早于冻结的最早拍；必要因果逐条绑定源事实或必要物理结果；上一拍的 `residueOut` 必须成为下一拍逐字一致的 `residueIn`。writer 只能演出这些事实，不能修改账本来迁就单镜场面。

writer 还要提交 `dramaticCoverage` 作为逐镜承载索引。它不评价镜头好坏，也不证明最终视频兑现，只回答冻结合同中的每条状态动作、观众揭示、债务推进、可见后果、反应、情绪行动变化和必要因果分别由哪些 `shotNo` 承担。服务端只检查引用闭包与一一对应；最终是否真正可见，必须由真实视频 AI 诊断和用户反馈验证。

## 语义强度守恒

镜头语言可以放大可见性，不能放大事实等级。writer 必须区分：客观发生、人物看见、人物猜测、人物口述、人物表态和观众暂时误认。后五类不能通过特写、音效、表演标签或剪辑顺序伪装成第一类。

- 对象身份或归属被误认，只演出具体对象、错误对应关系和由此产生的动作；禁止自动命名为偷窃、欺骗、栽赃或罪责。
- 人物说“不是我的字迹”，只演出他说出或写下这句话及他随后做的动作；禁止用法证式特写、确认音效或旁白把它变成鉴定结论。
- 源事实写“不断示意”，可以累积示意次数、被谁看见和留下多少知情痕迹；禁止擅自写成示意越来越用力、越来越愤怒或越来越敌对。
- 源事实只确认沉默、停顿或视线变化时，不用心跳骤响、惊恐喘息、阴险笑容等声音与表演替角色补写动机。

当镜头需要递增，优先改变可见证据的数量、位置关系、退路、资源、时间压力、问题指向或行动后果。若这些维度都没有变化，就合并或缩短镜头，而不是增加情绪和罪责强度。

## 章节人物弧

`filmBible.characterArcs` 对每个主要角色写一条本章可兑现的变化：

```text
角色：起点欲望/信念 -> 本章压力测试 -> 关键选择及代价 -> 本章落点 -> 留给下一章的问题
```

人物弧不等于“冷静变愤怒”。合格变化必须触及信念、策略、关系或底线。短章允许微弧，例如“相信速度足够 -> 连续扑空 -> 开始利用对手判断”；不强迫每章完成性格翻转。

## 每拍人物因果

有具名角色的 beat 填 `dramaticPlan`：

- `focusCharacter`：这一拍由谁承担决定。
- `objective`：此刻具体想得到、保住、阻止或隐瞒什么。
- `stake`：失败会失去什么，成功会改变什么。
- `perception`：角色实际能感知的有限证据，禁止上帝视角。
- `judgment`：基于证据做出的预测、误判或有意识牺牲。
- `choice`：判断落实成的不可撤回动作。
- `consequence`：物理、关系或心理后果。
- `arcChange`：后果如何改变下一拍策略、信念或底线。

误判必须可见：

```text
看见证据 -> 形成预测 -> 提前承诺身体/资源 -> 新证据推翻预测 -> 非自主反应 -> 带代价恢复
```

不能只在结果后写“他判断失误”。观众必须先看见他为什么相信自己是对的。

可见表演优先写“维持控制的企图 × 不由自主的泄漏”，而不是直接贴情绪标签：角色可能故意不回头、维持平稳语气、借过冲掩饰失手，但呼吸、下颌、手指、视线时差或提前承诺的重心暴露真实压力。泄漏必须发生在新证据推翻判断或代价落下的节点，并推动下一次选择；不能按固定配额给每镜添加皱眉、喘息或眼震。

动作连续不等于人物重置。每次扑空、松手、过旋、受阻或侥幸得手之后，下一拍必须继承至少一项变化：更冒险或更克制的策略、暴露的习惯、失去的资源、获得的读法、被迫改变的路线或加深的底线。若下一拍仍按原策略无代价重来，这只是物理状态机，不是人物弧。

## 每拍导演计划

每个 beat 填 `directorPlan`：

- `primaryDramaticChange`：一条 clip 唯一的变化终点。
- `shotPOV`：客观空间、某角色有限视点，或有动机的视点切换。
- `audienceKnowledge` / `characterKnowledge`：分别写开拍时已知与误信。
- `revealOrder`：反应、原因、结果谁先出现。
- `powerBefore` / `powerAfter`：空间、信息、关系或道具控制权变化。
- `soundPerspective`：声场跟随谁的注意力，何时收窄或恢复。
- `essentialCausality`：不可删除的因果，按优先级排列。
- `continuityLocks`：身份、空间、道具、光线与状态事实。
- `optionalTexture`：超预算时先删的衣摆、尘屑、次级反应等纹理。
- `capacityDecision`：`keep` / `simplify` / `split`。
- `capacityRationale`：说明为什么在时长内可读，不能写“信息很丰富”。

摄影不是持续追踪最重要的物体。客观镜可先交代地理，角色判断点把视觉或声音短暂交给角色，结果发生后再回到客观控制权。遮挡也应表达角色看不全，而不只是制造层次。

## 战斗分支边界

本文件不再定义 `tacticalExchange`、战斗专用字段或第二套战术模板。战斗、追逐、争夺、围猎、闪避、擒抱、多人混战与技能对抗统一读取并服从 `combat-action-expansion-standard.md`，并把结果编译进既有 `continuity`、`shots[]`、`motionDynamics` 与 `exitState`；不得创建平行 schema。

通用人物目标、有限感知、选择、代价、观众信息与控制权变化仍可作为冻结戏剧事实进入 writer，但不能绕过唯一战斗标准改写能力、胜负、伤势、持有关系或动作结果。

## 案例学习纪律

公开 prompt 合集通常是精选成功案例，不是可复现实验。没有完整参考资产、精确模型版本、请求参数、尝试次数、失败样本、原始音轨与 A/B 的案例，只能提供待验证的镜头假设，不能证明稳定成功率，也不能直接固化成模板。

- 可吸收：刺激如何触发感知，非自主反应如何暴露判断，声音如何随 POV 收窄，动作如何造成价值与控制权变化。
- 不可吸收：`8K/cinematic/epic` 等质量词堆、具名导演模仿、正面对波或中央碰撞的轮流蓄力模板、`Animate this image` 等空指令、以哭喊/跪地/眼震代替人物因果，以及把单次精选结果宣称为多参考图或音画同步的稳定能力。
- 长提示词没有天然优势。完整因果成立后，仍应删除重复 look、全片分析、装饰性禁止项和不改变选择的动作纹理；这属于信号纯度判断，不是字符上限。

## 最小充分信息与供应商边界

writer 不设置创作上限，也不设置固定字数下限。先做事件容量裁决，再写镜头；最终渲染提示词以“冻结事实完整、因果可读、状态连续、逐项可执行”为停止条件：

1. 当前 clip 先锁一个与冻结 durationBudget 相匹配的 `primaryDramaticChange`。
2. 保留 `essentialCausality`，否则事件看不懂。
3. 保留必要 `continuityLocks`，否则身份和空间漂移。
4. 最后才放 `optionalTexture`，超限先删这一层。
5. 参考图已经承担的脸、服装、媒介、固定色系只声明职责，不长篇复写。
6. `emotionalArc`、`characterArcs`、分析结论只服务 writer，不复制进视频模型提示词。
7. 因果与执行事实已经完整后立即停止扩写，不用重复形容词、方法论复述或模板句凑字；若仍有事实缺口，按缺口继续修订，而不是用字符数冒充完成度。

真实供应商若对请求施加物理字符边界，由执行层在提交前按实际请求事实校验。该边界不构成 writer 的创作预算；禁止自动截断、删除资产合同或把供应商拒收伪装成质量评分。若冻结合同与可执行因果无法同时满足供应商边界，在 `selfQaNote` 中记录 `input_contract_budget_conflict`，由同一执行链根据事实修订或显式失败。

任何合法时长的 clip 都没有统一镜数或动作数。容量取决于交互复杂度：多人接触、精确道具转移、口型、参考图数量和复杂运镜会竞争同一保真预算。判断、误判、反应和恢复都需要可读时间；若删除纹理仍读不清，就在父任务允许的结构内 `split`，不能继续压缩拍长。

## 出镜自检

每条 clip 交付前回答：

1. 不看 logline，能否从画面看出焦点角色想要什么？
2. 能否看见他依据什么做出判断，而不只是看到结果？
3. 情绪是否实际改变了时机、力度、路线或代价？
4. 观众是否知道自己此刻跟谁看，是否有意比角色多知道或少知道？
5. 结尾的权力、知识、距离或控制权与开头有何不同？
6. 动作场面是否形成新局势，而不是双方轮流展示技能？
7. 删除所有摄影品牌、质量形容词和重复 look 后，主要因果是否仍完整？

任一关键问题答不出，先改 BeatSheet 或 shots；不要靠追加情绪词、冲击波、慢动作和更长禁止清单补救。
