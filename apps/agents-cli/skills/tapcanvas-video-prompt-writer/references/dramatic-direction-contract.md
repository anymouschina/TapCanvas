# 戏剧导演方法参考

可按当前戏剧问题选择这些思考角度，不必逐拍建立计划表、人物弧或审查账本。字段与结构由本轮 schema 决定。

人物的目标、感知、判断、选择和后果能帮助组织演出。重点是观众理解当前事件为何发生、人物为何这样做、结果怎样影响后续；故事没有发生策略或性格变化时，不额外制造变化。

观众掌握的信息可与人物不同。构图、揭示顺序、表演与声音可以组织期待、疑虑或共情，但观众感受的设计不授权新增人物动机、关系、对白或结局。人物猜测、口述和客观事件保持各自事实强度。

在当前内容需要时使用视点、信息差、潜台词、选择压力和空间关系。长话轮、静默、旁白和持续观察都可以传递剧情；不把因果可读性等同于每镜动作、每句转折或不可逆选择。

只补足实现冻结剧情所需的演出细节，保留核心人物、世界规则、主线因果与关键结果。剪辑可以省略不影响理解的过程，不能掩盖剧情缺口。具体编舞、对白与取景按当前事实自主创作；引用、来源和真实资产约束继续有效。
