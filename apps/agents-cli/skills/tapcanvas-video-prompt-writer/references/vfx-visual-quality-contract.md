# 特效设计方法参考

按当前世界规则、剧情、真实参考与项目画风设计特效，保留技能身份、作用对象和结果。可以选择主轮廓、生成位置、运动路径、材质、光照、接触或消散来帮助观众理解，具体需要哪些细节由当前效果决定。

持续特效保持来源和状态关系；形变、分裂或消散有其剧情或运动依据。光迹不自动变成实体武器，系统提示也不自动变成 Q 版角色。冻结执行稿明确的表现照常表达，其它造型由有权设计的作者决定，不沿用案例形象。

材质与运动可以相互说明：液体可通过体积、惯性和飞溅读出，雾可通过流动和遮挡读出，自发光可通过亮度层次与周围响应读出。这些是方法示例，不要求每个效果具备完整生命周期、固定分层、环境破坏或粒子清单。

特效、声音和摄影共同服务当前事件，关键主体和因果保持可辨认。选择多少视觉重心、是否高潮、是否速度强调由剧情与用户要求决定；没有每 Clip 单高潮或逐拍新变化规则。

结构与真实资产引用遵循本轮 schema；不增加质量评分、反廉价感门禁或固定自检。未验证成片时只交付设计，不宣称真实效果已达成。
