# VFX 画面质量合同

本合同用于章节叙事 clip 中的技能、法术、能量、生物化血气、风压、水体、护罩、内部命核与类似视觉效果。目标不是增加形容词，而是让视频模型生成一条在连续帧中可追踪、可受力、可消散的视觉对象。

## 第一原则：先有主形，再有华丽

每个具名 VFX 先选择一个主形：束、刃、浪、膜、环、核、柱、兽形体、卷流或其他单一可读轮廓。主形在当前 clip 内保持同一身份；尺度和形变可以变化，但不能在相邻拍无因果地从血浪变触手、从水幕变冰墙、从风压变光球。

一条 VFX 高质量描述的优先级是：

1. 主形和生成源。
2. 运动方向与速度变化。
3. 接触对象和受阻后的形变。
4. 材质、透明度与光照层级。
5. 尾迹、碎屑和环境二级反馈。

二级粒子不能比主形更亮、更密或更抢眼。

## VFX 在三段上的专门要求

每个可见主体按共享方法走完“结构 → 轨迹 → 环境反应”，并逐拍继承位置、方向、厚度、速度。该三段的定义与通用要求随 Skill 注入的 `references/user-gold-standard-2026-09.md` 已经给出，本节不重述，只写 VFX 主体在其上的专门要求：

- 结构：它是一具连续体还是一群离散个体；离散群体要写粒径、密度与材质。前缘先出现，主体随后增厚，尾部延迟跟随，观众应能在一至两拍内认出主轮廓。
- 轨迹：蓄积阶段慢且密，释放阶段加速，接触阶段受阻急减速，失去驱动后衰减。接触时前缘先压扁、弯折、分流、绕流、卷起或贯入，接触对象产生同方向的衣摆、碎屑、裂纹、液体或身体反馈；主体继续穿透、回卷、崩解或坍塌，不能在命中帧后凭空归零。
- 环境反应：先减速，再变薄、分裂、落地、熄灭或被环境吸收；特效必须真实遮挡人物和环境，并被场景物体反向改变。

主形把三段逐项写满；二级元素可以更简，但三段都要有，不得只留结构与轨迹而省略环境反应。

## 材质推导：从属性得到表现

材质决定这三段各自怎么读，但不要按材质名去查表。任何材质的表现都由下面三个变量推出；遇到没有列过的材质（冰、沙、电浆、黏液、血雾、藤蔓……）用同样三个变量推，不需要额外条款。

- 内聚度：连续体还是离散群体。连续体写一个主轮廓，形变连续、可受压可回弹；离散群体写粒径分布、密度与个体运动；中间态（烟、雾、血气）写整体形态加内部纹理。同一主体不得在连续体与离散群体之间无因果切换。
- 驱动与衰减：由什么驱动，离开驱动后怎么衰减。继承发射动作的（碎屑、火星、刃）以惯性为主，沿受力方向连续；持续力场维持的（护罩、水幕）保持形态并受外力形变；自身推进的（能量束、风压）有明确速度曲线；阻力主导的（尘、雾、灰烬）迅速减速并转向重力与气流。
- 表面与光耦合：与表面是附着沉积、反弹、穿透、烧灼还是打湿卷起；与光是自发光、导光、反射、吸收还是半透明。自发光主体必须给出亮度层级（见下节）；非自发光主体必须给出它如何被场景光读出。

三个变量都必须在当前 clip 内有明确取值，相邻拍不得无声改变。

以下是推导示例，用来校准判断，不是材质清单——每条展示的是从变量到表现的推导链，照这个方式推新材质，而不是照抄结论：

- 水：连续体 + 阻力与表面张力主导 + 表面耦合为打湿绕流 → 有体积、惯性、飞沫和绕流，不能只是一张蓝色透明膜。
- 风压：非自发光 + 介质折射读出 + 受压表面耦合 → 用空气折射、尘屑轨迹和受压表面表现，不默认画成发光圆环。
- 血气：中间态，必须选定连续体或离散群体一侧 → 可以黏稠或烟流化，但禁止同时像橡胶触手、液体血泊和烟雾。
- 能量核：自发光 + 有空间深度 + 遮挡与导光耦合 → 必须有组织或甲片遮挡、周围材质导光和破裂传播，不能像贴在胸口的 UI 圆点。
- 护罩：连续体 + 持续力场驱动 + 受击形变与回弹耦合 → 要表现曲率、受击凹陷、应力传播和回弹，不能只做均匀透明半球。
- 光：自发光 + 自身推进或驻留 + 照亮与灼伤耦合 → 必须有内芯、沿路径的运动痕迹、接触面的落地余痕与可见的环境反向改变；四项缺一即视为未写光效，不得用“发光”“照亮全场”“能量爆开”或整条均匀高亮顶替。
- 粒子、碎屑、烟尘、雾与天气：离散群体或中间态 + 阻力主导 + 沉积与卷起耦合 → 必须有真实发射源、继承发射动作受力方向的轨迹、落在具体表面的残留，且相邻拍累积而不是每拍清屏重生。它们永远不承担主形职责，不能比主形更亮、更密或更抢眼，也不能代替身体运动、接触与受力；去掉全部粒子后主体动作与接触因果仍须成立，若去掉后一个动作再也看不出发生过，说明动作本身没被写出来，回到动作链补，而不是加大粒子量。

## 材质分层与亮度层级

任何自发光或半透明主体分成至多三层：

- 核心：密度最高、面积最小、运动最稳定。
- 主体：承担轮廓和主要体积，不得全域过曝。
- 边缘/尾迹：更薄、更透明、更慢，负责速度和消散信息。

高亮只出现在生成峰值或接触峰值的小面积区域。禁止整条特效同亮、同透明、同锐度；否则容易变成霓虹软管、透明 PNG、游戏 UI 发光贴片或塑料实体。

## 视觉中心预算

每个 clip 只设一个 VFX/物理高潮。高潮拍只允许一个主要视觉问题得到回答，例如“血气巨兽完成实体化”“水压击穿护罩”“命核连续破碎”。表情特写、敌方反应、地面破坏、内部剖显和第二种技能只能选择必要项作为次级反馈。

如果一个时间段要求观众同时看清两种技能、三名角色、内部结构和大范围场景破坏，先减少并发事件，而不是增加描述长度。视频模型的信息容量由同一时刻需要保持的独立对象与状态数量决定，不由字符预算决定。

## 反廉价感自检

交付前逐项检查：

- 把颜色词和“华丽、史诗、电影级”删除后，是否仍能画出主形、路径和接触？
- 对画面里每一个可见主体（含光、粒子、碎屑、烟尘、天气）逐个核对：结构、轨迹、环境反应三段是否都有可观察内容？缺段的不按类型补条款，回到共享方法的主体生命周期按三段重写。
- 三个材质变量（内聚度、驱动与衰减、表面与光耦合）是否在相邻拍无声改变？自发光主体是否给出亮度层级？
- 任取相邻两拍，是否能说明同一个特效如何从前一状态连续变到后一状态？
- 是否存在红色软管、蓝色透明贴片、均匀发光半球、胸口 UI 圆点或随机粒子全家桶？若存在，回到材质与接触链重写。
- 去掉闪白、震屏、雾和粒子后，技能的主体运动是否仍成立？不成立则不得交付。
- 参考图是否只承担 `vfx` 职责；若同一静态图还被要求承担角色身份、场景拓扑和构图，必须依赖父任务拆分资产职责，writer 不得用文字掩盖合同冲突。
