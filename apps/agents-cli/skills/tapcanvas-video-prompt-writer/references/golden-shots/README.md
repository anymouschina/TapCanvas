# golden-shots 范例库（critic ≥95 分镜头表沉淀）

> 2026-07-10 用户拍板：95 分不再是及格线，而是**入库线**——critic `overallScore ≥ 95` 的镜头表由父agent（小T）沉淀到本目录，供后续 video-prompt-writer 写作时参考。

## 入库规则（父agent 执行）
- 触发：子agent selfQaNote 报 critic `overallScore ≥ 95`。
- 文件名：`<YYYYMMDD>-<题材关键词>-<分数>.md`（如 `20260710-洪荒修仙夺宝-96.md`）。
- 内容：一行 brief（题材/片型/导演基调）+ 完整镜头表可读文本（与送审版一致）+ 得分与评语摘要。
- **库容 ≤20 份**：满了删同题材里最旧/最低分的一份（curation 归父agent）。

## 使用规则（写手）
- 写前有同题材范例可参考其**密度与结构**（每拍时长分布/拍数/进出态写法/信息含量标尺）。
- ⛔ 禁抄镜头序列/编舞/开收方式——反同质化最高优先；范例回答「好到什么程度」，不回答「拍什么」。
