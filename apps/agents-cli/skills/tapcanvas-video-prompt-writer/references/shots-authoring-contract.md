# 逐镜产物参考

仅在本轮确实声明逐镜 artifact 时读取。当前动态 schema 规定必填字段、枚举、身份、时间 owner 与宿主编译职责，本参考不保留另一套旧字段表或固定输出示例，也不把逐镜要求移入 compact packet。

按播放顺序描述镜头真实声画，以足够的信息呈现本段剧情。动作、表演、取景和声音相互配合，必要事件、人物关系与结果要在执行字段中得到表达，不能只在分析、索引或自评中声称完成。一个镜头能承载多个相连事件，也可跨镜延续同一事件或声音。

冻结剧情、完整发声、相邻边界与资产职责是输入事实。原文引用保持人物、文本、顺序与来源；只提交 schema 实际允许的引用，不从台词长度、镜头数或时间相交猜测语义覆盖。

若当前协议明确声明镜头时间，按该合同填写；未声明内部时钟时不自行增加。供应商整段时长不构成固定镜数、动作率、语速公式或逐秒状态窗。也不借另一产物的列名要求当前作者补导演账本。

取景与状态表达由当前剧情决定。持续表演、稳定机位、静默、旁白、快切、长镜与合理时间省略都可使用；没有每镜单变化、固定运动链或独立复盘步骤。字段只写真实适用内容，不造资产、机器身份、完成声明或额外生产流程。
