# 忠实剪辑与动作覆盖参考

以完整剧情与来源忠实度决定取舍，再选择快切、长镜、正反打、细节镜或声音接续。镜头数量、长度和节奏没有默认配额；用户明确的剪辑要求与本轮供应商合同保持有效。

多个镜头可以呈现同一事件的不同关注点，也可由一个镜头承载相连事件。是否切镜取决于当前动作、信息与表演，不以“每镜必须推进”删除有意义的倾听、观察、强调或停顿，也不为丰富画面机械补微动作。

保持人物、行动者、接触目标、方向和后果。实现冻结动作时，补足观众需要理解的路径、接触或反馈；动作很简单时无需展开完整身体受力清单。摄影运动不能替人物完成位移，合法时间跳跃或场景剪辑也无需补拍全部中间过程。

按真实刺激设计人物反应，不套用词语禁用表、统一表情或情绪递增模板。原文发声按冻结合同完整引用，旁白与心声可跨镜；配乐、音效和文字由当前剧情、用户要求与实际供应商能力决定。

这些是创作方法，不产生新的 schema、逐镜时钟、配额或审查流程。当前输入的真实问题按授权处理并如实记录，不能通过装饰性镜头掩盖缺失剧情。
