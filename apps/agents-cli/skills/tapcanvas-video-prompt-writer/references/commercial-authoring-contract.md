# 视觉与声音设计参考

本参考提供可选导演方法，不定义生产协议、商业质量等级或固定编译流程。结构与引用以本轮动态 schema 和共享 stages 为准。

先理解当前剧情需要观众看见和听见什么，再组织表演、空间、取景、光线、材质和声音。摄影可强调主体、关系、信息差或环境，也可保持固定观察；不要求每镜主体变化、单一运镜轨迹、复杂 ACT 接力或设备词汇。

真实参考与项目方向提供身份和视觉依据。需要时补充构图、明暗、色彩、材质响应和声场透视，避免把一种案例的暗调、写实、胶片、手持或强对比推广为全局标准。动画、实拍、产品展示与其它媒介各按本轮事实表达，均匀照明或简洁构图也可以成立。

保留来源的人物、事件因果与关键结果；背景和心理可由动作、对白、旁白、心声、回忆或组合表达，没有“旁白最后才用”或“不能坐着念”的全局规则。原文发声依冻结引用完整传输。配乐、字幕和音效按当前剧情与用户要求设计，事实性现场声不伪称来自未出现的实体，非写实声音设计明确其表现用途。

人物、道具、场景与特效各按真实资产职责使用。镜头变化不授权改变身份、持物、接触、伤势或时空；回忆、跳跃和返回主线按已声明关系衔接，无需每镜重复所有状态属性，也不固定某种返回景别。

案例提供方法而非当前剧情、身份、规格或权限。第三方资料的来源与使用范围如实记录，已授权项目资产和原文引用保留；权限、真实资产 URL 与供应商硬限制依本轮事实执行。writer 不提交媒体、换模型或创建第二条生产链，已经生成的结果保留。
