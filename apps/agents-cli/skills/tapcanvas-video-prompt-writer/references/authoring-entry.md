# 视频提示词共享作者入口

依据用户本轮目标、实际读取来源和真实项目事实，写出可交给视频模型执行的声画。保留必要人物关系、事件因果、选择与结果；摘要、引用编号和自评不能代替实际剧情表达。已冻结剧情与完整发声不擅自删改，原创细节留在授权表达范围。

导演方法由当前内容决定：把人物在刺激下的表演、动作及其结果写成可见过程，让取景、摄影运动、光线、材质和声音支持理解与观看感受。持续观察、静止镜头、快切或复杂动作各有适用场景；不固定镜数、反应次数、钩子、情绪弧或技巧套餐。连续过程保留相关位置、持物和状态，承接已完成结果，不抢演之后的事。

先理解当前段在整片中让观众经历什么，再决定怎样拍。冻结事件提供“发生了什么”，作者还要设计观众何时注意到什么、人物怎样完成它。围绕当前的关系、任务、阻力与已知信息选择可演的细节：视线落点、接近或避开的距离、动作的迟疑或干脆、持物与接触、呼吸和说话之间的关系。只选当前人物与事实支持的细节；克制、维持姿态或继续手头的事也能是准确表演。不要把“伤心地说”“紧张对视”“完成操作”等结论原样当作全部演出，也不为丰富表演增加原文没有的心理转折。

取景从观众需要读到的证据出发：关系或动作路线需要同框时给足空间；一个细小结果决定理解时让它看得见；人物努力掩饰时，可以选择让观众读到掩饰或暂时跟随另一人的观察。稳定机位、遮挡、移动、景别变化各自解决具体观看问题。把决定写成 camera 与 action 中实际可执行的画面，而非仅写“电影感”“有张力”或镜头术语；也不要求每镜换景别或运动。声画可同时揭示、先后揭示或保持静默，依据冻结发声和当前声音权限设计；现场声的来源、远近、遮蔽或中断有用时写清，让它与动作、空间和注意变化发生联系，不把每镜重复的环境声或强音效当作节奏。

节奏来自观众获得信息和人物完成行动所需的展开：决定停留在哪里、哪里可以省略、什么必须先被看到或听到。长对白可持续在动作或聆听画面上，静默可保留尚未得到回应的当下；不靠增加动作、快切或空泛氛围填满请求时长。技术段边界服从这一进程，当前末镜和下一首镜的主体、动作阶段、方向、持物与声音关系按相关事实交接；明确换场也可成立。没有真实前段视频或尾帧时只设计提示词接点，不宣称实片已无缝。

直接文本交付须自含完整声音与视觉指令：台词、旁白、心声写全文和实际发声方式；用户明确画风、媒介与音乐要求保留在正文。真实参考存在且会随提示词送入模型时，才用其声明的身份与用途；没有相应输入时写清必要外观与场景，不杜撰图号、角色卡、URL 或宿主补全。

结构化交付只使用本轮动态 schema。仅当合同明确由真实 renderer 投影冻结声音、参考绑定或画风时，才通过声明字段引用并交给它物化。packet/v2 的完整声音用 speechEventIds 在开始镜头引用一次，renderer 插入全文，长话可跨镜继续；其 sound 不含背景音乐，全章配乐由剪辑承担。其它输出不继承该分工。

结合当前任务与实际已读来源判断知识是否充分，通过统一 `record_knowledge_assessment` 记录依据、专业缺口，以及检索或不检索的具体理由；目录提示或 Skill 名称不证明已具备方法。需要补充方法时，从技能章节与 references 导航选择读取，可按需加载文戏、动作、视觉设计等领域 Skill。搜索先看候选元数据，再依相关性、信息增益、成本与已有证据选择读取零条、一条或多条正文，并记录取舍。只对成功读取的内容记录实际来源，故障留诊断，继续根据本轮事实原创。案例人物、剧情、参数和手法不变成本轮默认事实。

用当前创作问题选择资源，例如“这段拒绝怎样从礼貌中被看见”“同一动作跨段如何不重启”“声音怎样让观众先发现来人”。目录标题只能帮助找正文，不能当作已经吸收方法。读到方法后，判断其适用前提与本轮差异，把有用机制转成实际表演、取景、声音或交接；不适用时舍弃。已有证据足够就直接创作，不设必读数量。若记录采用理由，指向成功正文读取回执和实际改动位置；工具不可用、零命中、弃选或读取失败只进诊断，不进入已用来源。

交付前对照用户目标和实际产物，检查观众仅凭将被执行的声画能否经历当前剧情。发现把事件改写成摘要、表演只剩情绪标签、必要证据没有被取景呈现、声音与动作矛盾或接点重置时，在同一作者链直接修改实际消费字段并复核受影响的相邻内容；不是追加“已加强”的自评。检查范围与方法按实际问题选择，不增加独立 reviewer、固定审查顺序、草稿数或通过分数。缺失来源或权限如实披露，冻结上游事实只按已授予路径修订。提示词完成不等于媒体已生成，本技能不创建资产、提交媒体或替用户重跑。
