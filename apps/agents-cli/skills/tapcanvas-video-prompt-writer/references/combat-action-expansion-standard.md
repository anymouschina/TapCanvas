# 战斗与追逐编舞参考

本参考从已有动作案例中提取可迁移方法，按当前场景需要选用；案例不是唯一标准或默认高烈度模板。运行时不回读 `assets/`、`docs/` 或 `ai-metadata/` 样本。

保持冻结的人物能力、武器、施受关系、重要命中、伤势、胜负和故事后果。稀疏结果型叙述可以扩成具体编舞：从当前位置和状态发起，交代攻击或移动路径、防守选择、接触或落空、反作用和结果，让观众看懂因果。不擅自新增能力、阵营、不可逆伤害或胜负反转。

动作接力可继承上一过程的位置、速度、失衡、持物与未完成动作，避免无依据重置；但对峙、读招、停顿、脱离和收势也可属于故事，不要求一直移动或每次接触都改变战局。动作幅度、快慢与材料反馈按本场事实决定，不默认最高强度。

空间、距离、遮挡与武器差异可以产生编舞。需要时设计换位、借力、反制或地形反馈；没有依据时不要发明场地、破坏等级或物理数值。可用景别与机位让路径、接触和结果清楚，快切、连续长调度、局部插镜及风格化冲击都由当前剧情和用户要求选择。

声音、特效和环境反馈辅助动作的可读性，不能凭装饰替代关键接触或改变故事结果。题材允许的夸张遵循既定世界规则与项目画风；真实感不等于真人写实。

不要从供应商整段时长推导招式数、镜头秒数或固定高潮。无需先建战斗账本、固定阶段或独立 reviewer；结构引用以当前 schema 与共享 stages 为准。事实冲突按已有权限处理并记录，已有生成资产保留。
