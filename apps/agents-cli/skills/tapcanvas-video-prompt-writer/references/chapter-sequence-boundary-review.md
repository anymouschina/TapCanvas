# 跨 Clip 衔接方法

本参考可在当前剧情需要跨段衔接时读取，不要求每段进行固定复盘。

技术 Clip 是完整故事的一段执行窗口。依据已读取的进入态、有序事件、退出态和相邻边界写当前段；无需为每段另造开场、高潮或结尾。事件和发声属于明确声明的 Clip，前段已经完成的过程不重演，后段结果不提前兑现。

同一人物、场景或道具沿其故事时间承接最近成立的状态，包括位置、持物、损伤、已完成的修复及环境残留；离画、换镜与技术分段不重置事实。对象隔段回场时按需要查 stateChain 中相关先前计划出口，再结合后续事件，不把它当实片观察或要求读完整条历史。时间跳跃、回忆或换场按来源关系取态；修复、清洁与治疗可真实改变状态，不预设损坏只增不减，也无需补拍合理省略的路程。

相邻来源摘录保留身份、原文和范围，是核对上下文的证据；段落和字符边界本身不决定剧情归属。章节结构与具体输入矛盾时，记录准确差异，按已授予的修订能力处理，不自行覆盖冻结事实。

用实际声画承接，而非仅在边界标签或自评中宣称连续。稳定姿态、持续对白、停顿和动作中切镜都可成立，是否采用取决于当前故事，不要求每镜变化、开放结尾或固定节奏。整段时长遵循供应商合同，片内节奏由视频模型适配。

连续动作跨独立生成段时，章级首尾态应让两位作者知道交界处观众实际看着谁、在哪里、动作进行到哪一步，以及需要保持的运动方向与外观。段末再切到旁观者、远景或反应，会改变实际交接画面；不能仍把较早的动作镜头当作最后一帧。逐段作者把相关事实落实到最后与最初镜头，按剧情选择动作接续、声音接续或明确换场，不强迫同机位，也不把技术分段当作剧情重新开始。

人物、场景或道具使用初态图或状态版时，实际 referenceFacts/referenceUsage 只传递本段适用的事实，并与 scene/shots 的过程一致。状态图属于某个时点，既不能把未来结果提前，也不能让已消除的损伤在后段复现；同一图的沿用不等于同一初态的沿用。没有真实相邻视频或尾帧时，只能设计提示词层的接点，不声称已经实现帧级无缝。
