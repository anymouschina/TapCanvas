# 案例方法参考

本参考由用户提供的视频提示词样本离线提炼，提供可迁移的声画方法。它不是逐段默认加载的标准，不要求读取案例、建立草稿版本、固定回放步骤或追逐评分。

值得按当前需要借鉴的角度：让人物和对象的动作能执行；让路径、接触与结果能理解；让摄影服务关注点；让连续状态与合理剪辑相容；让声音、光线和材质支持当前表达。

只使用已经实际读取的案例正文，说明它对当前创作提供了什么方法。人物、剧情、资产、时长、规格和权限由本轮真实输入决定，不能从样例复制。没有适用案例就自主原创，检索失败只保留诊断，不伪造来源。

当前用户需要完整剧情的忠实影视化时，案例中的密度、快切、动作层次或画面风格不能成为删减剧情的依据。镜头数、长度、表演方式和声音选择由作者根据本轮内容决定。

交付当前可执行产物，发现具体冲突可直接修稿。修订工具和记录按实际任务需要使用，不强制首稿落私有 artifact、独立事实回放或多稿流程；也不把自评当成真实视频效果证明。
