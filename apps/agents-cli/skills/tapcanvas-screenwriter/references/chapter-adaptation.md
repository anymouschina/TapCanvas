# 章节改编与生产交接

在用户选择的来源、范围与改编幅度内，把已有故事改为可理解的声画。完整保留剧情事件、原因、关系与知情变化以及结尾状态；可以删不承担剧情的信息，无需逐句搬运叙述或为每句建立独立镜头。开头节选与全章明确区分，不让模板、案例或供应商单段时长缩小本轮剧情范围。

## 来源与声音

对白、心声、旁白、画面与可读文字平等由作者选择。必要信息实际出现在声画中，不以“解释来由”“已理解”等概述交下游临时发明。改编叙述视角时核对说话或思考的人、指代对象与角色可知范围；保留原有误会与不可靠叙述的作用。

引用原话逐字真实。未经授权删改的源对白及明确要求保留的声音保留内容、说话人和顺序；概括、润色、新增声音属于作者改编，保留其来源追溯，不伪称原句。画面可以省去重复说明，但不能用表情代替剧情所依赖的具体提议、判断或回应。声音可以跨多个镜头延续。

## 时间与技术投影

chapter-sequence/v4 只规划合法供应商 `clips[].durationSeconds`、有序事件和 Clip 归属，不提交每拍、每句或每镜秒数。内部节奏交视频模型。其它 artifact 只有当前合同明确要求时间字段时才填写，不能把一个 artifact 的规则迁到另一个。

用户未限定总长时先完成剧情，再根据内容安排合法片段。明确限时时在授权内取舍并保留剧情联系；若真实时长边界与必须保留的内容冲突，说明具体冲突与选择，不静默删剧情、超时或改快读。必要的分镜、角色卡和模型提示词由对应环节根据同一稿件及真实模型合同编译。

## 交接事实

优先复用当前正文、项目事实和真实工具回执。使用现有 schema 传递所需来源身份与 revision、实际改编选择、关键进入/退出状态、相邻承接及资产依赖，不另建事实包协议。新增连接属于创作选择；未决事实保持未知，待生成不冒充已有资产，URL 不伪造。

只要正文时不附内部追溯标签、预算表或质检报告。需要持久化的任务按 [project-facts-and-save.md](project-facts-and-save.md) 分别验证正文保存与事实提交，保留各自结果。改稿后回读受影响的声音、状态与交接，不能以自述覆盖证明代替实际内容。
