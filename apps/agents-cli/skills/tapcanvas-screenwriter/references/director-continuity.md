# 导演选择与连续性

按需解决当前稿件的空间、状态或观众注意问题。先理解本稿发生什么及观众需要获得什么，再选择站位、视线、取景、节奏和声音；不预设情绪曲线、切镜频率或特效清单。

追踪会影响下一步的事实：位置、方向、持物、身体限制、接触、角色知识与持续环境变化。转交、受伤、离场或揭示应在后续保留其作用；获得、移动、恢复或时空跳跃可改变状态，关键变化让观众能理解即可，不给所有元素建账或把每次移动机械展开。
