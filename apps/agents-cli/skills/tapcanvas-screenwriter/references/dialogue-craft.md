# 对白与声音

需要打磨人物表达或声音交接时按需读取。对白可以争取、解释、坦白、日常交流或有意重复；不要求每句有策略、每轮改权力或每段设潜台词。旁白、心声、画外音与画内对白都可承载剧情，作者按人物、来源和观看目标选择。

## 人物与理解

先理解谁在说、对谁说、此时知道什么以及为何这样表达。人物声音来自其经验、关系、关注点与措辞，不能靠统一口语或每人一个口癖替代。长发言、直白说明、诗性、笨拙和沉默都可以成立；只有具体冗余或理解问题才修订，不按句长或动作断点删台词。

需要潜台词时，让观众能从已知情境、台词或表演推断言外之意；没有隐瞒理由的信息可以直接传递。动作、打断与停顿依据真实表演作用选择，不在每句之间加微动作或强行中断持续说明。重复可能有关系、记忆或仪式作用，是否精简由本场含义判断。

## 来源与交接

原文引用逐字真实；冻结或用户明确要求保留的声音保留完整内容、说话人和顺序。获准改写或新增台词记录为作者创作，不混入原话。说话、心声、消息文字和叙述不是同一身份，观众可听信息也不自动变成剧中人物可知信息。

给下游完整发声内容及其在当前 schema 的归属；动作中写“他解释”不能替代必要台词。声音可跨镜头连续，发声者不必入镜。独立供应商 Clip 不自动共享音轨，跨 Clip 延续由作者安排接续内容；叙事声音计划不证明已有独立音频资产。

估时依据完整话轮、语气、换气、接话与必要反应；没有录音时只是文本估算，不能声称实际发声时长。可并行的动作按表演关系考虑，先后依赖的过程不靠“同时”压缩。v4 章节稿与 packet v2 不提交内部发声时钟；其它 artifact 按当前合同填写。装不下就调整合法片段归属或说明真实时长冲突，不能擅自删冻结原句或用快读掩盖。

回读实际台词和前后声画，确认人物归属、信息顺序和情境含义；发现具体问题同链修订，不输出评分或强制通过清单。
