# 对白方法

本资源随需读取：当交付以对白承载主要信息，或需要打磨台词的策略、潜台词与人物声音时使用。总纲见 `scene-engine.md`，交付前修订见 `revision-passes.md`。

对白不是角色把剧情资料读给观众。每一句都发生在具体关系里：说话者试图改变对方的行动、判断、情绪位置或公开形象，对方用自己的目标回应。对白比例、金句数量、句长和口癖数量都不能证明质量。

## 规则分级

- `structural_invariant`：说话者、场景边界、画外/画内区分与精确文字要求。这些必须可解析，且要能进入下游的逐字发声台账。
- `reviewed_invariant`：对白是否有议程、是否回应上一动作、是否改变局面、人物声音是否可信。靠引用正文判断，不给"自然度"空泛打分。
- `craft_default`：让信息通过争取、回避、交换和后果出现。有明确理由可以覆盖。
- `taste_option`：口语程度、方言、停顿、沉默、直白、打断与句式长短。由人物与作品风格决定。

## 先写议程，再写句子

写一轮对话前，为每个主要说话者在内部回答：

```text
此刻想让对方做什么？
最怕对方看见或说出什么？
手里有什么筹码？
哪件事不能公开说，为什么？
认为对方想要什么？
先用什么策略，失败后怎样换？
哪条底线受到压力才会越过？
```

两人可以表面谈同一件事，实际争不同结果。例如都在谈"交钥匙"：一人要结束控制，一人要迫使对方承认责任。

**`craft_default`**：先写"这句话想对对方做什么"，再决定字面表达。没有行动目标的句子通常可以压缩或转为动作。

## 台词是一种行动

同一句事实可以执行不同动作。事实："门在九点锁。"

- **催促**："你还有三分钟。"
- **推责**："九点以后，钥匙不归我管。"
- **试探**："你是不是以为九点以后没人进得来？"
- **威胁**："九点一到，里面是谁都不重要了。"
- **保护**："九点前走，我就当没见过你。"

字面信息相近，关系动作完全不同。写作时优先选定动作，再挑字面。

### 策略库

不是模板轮换，只在符合人物目标时选用：要求／命令／请求／交换；试探／诱导／套话／验证；重新命名问题、缩小或扩大责任；先承认一部分以保护更大秘密；借第三人或公共规则施压；假装无所谓、拖延、转移；把选择交还给对方；暴露自己愿付的代价；拒绝旧称呼或旧关系位置；用沉默迫使对方继续说。

### 策略必须会受阻

若一方每句话都成功，对话会变成演讲。让另一方：看穿并点破策略；接受字面条件却拒绝隐含关系；提供反证；改变公开范围；把对方的词反过来使用；拿走说话所依赖的时间、物件或身份；不给预期反应。

一轮对话中，策略受阻后应当换策略、付代价或退出。重复同一句要求只会延长时长。有意的重复可以表现仪式、创伤、压迫或喜剧，只要重复本身改变效果或关系。

## 方法都有反向条件

只写"该怎么做"而不写"什么时候不该"，结果是方法被当成质量指标全场铺开——**对白最常见的坏味道不是方法用得少，是方法用得到处都是**。

| 方法 | 它失效的条件 | 失效后读起来是什么样 |
|---|---|---|
| 写潜台词 | 人物没有理由隐瞒 | 该说的话被作者按住不说，人物显得莫名其妙地躲闪 |
| 把说明改成有利益的传递 | 这条信息本来就中立 | 为了制造冲突而硬派立场，观众看得出争的是假的 |
| 打断 | 被打断的那句带着观众此后拿不到的信息 | 信息断供，后面的推断失去依据 |
| 停顿与沉默 | 沉默没有可见对象 | 观众读不出在权衡什么，只读到空档 |
| 把选择交还给对方 | 交出者本来就无权扣住它 | 不是让步，是虚张声势 |
| 借第三人或公共规则施压 | 这条规则观众此前不知道 | 像临时发明的挡箭牌 |
| 先承认一部分 | 观众还不知道有更大的秘密 | 部分承认被当成全部真相，后面揭露时观众觉得被耍 |
| 区分人物声音 | 差异只落在口头禅上 | 标签化：换掉那个词人物就没了区别 |
| 用动作断开长发言 | 这段发言本来就没有内部转折 | 插入的动作是填充，该做的是缩短 |
| 让每轮承担不同工作 | 场景本来只有一件事要办 | 为了不重复而制造支线，冲淡了唯一的目标 |

配重的用法不是"用之前先查表"，而是**修订时反查**：一场对白读着别扭却说不出哪里错，多半是某个方法用在了它的反向条件上。先找方法，再看条件是否成立。

## 潜台词来自已知差与风险

潜台词不是人人说谜语，而是"真正想做的事不能或不愿直接说"。先找出不能直说的原因：说出会暴露秘密；会失去体面或关系；现场有第三人；说话者尚未确认对方知道多少；直接要求会显得自己没有筹码；角色连自己都不愿承认真实需要。

三层检查（不要求每句都复杂）：**字面层**——实际说了什么；**行动层**——想让对方做什么；**风险层**——为什么不能直接说。

> "你把窗户关上吧，外面的人都听得见。"

字面是要求关窗；行动是把对话从公开变私下、夺回解释权；风险是说话者害怕某个事实被第三人听见。若现场没有外人、秘密或权力差，这句就只是生活指令，不自动具有潜台词。

潜台词需要可观察的推断依据：角色避开一个具体词；对方触碰或藏起相关物件；称呼改变；先回答旁枝、拒绝核心问题；台词与可见证据矛盾；第三人进入后语言突然改变。**潜台词不能完全依赖作者事后解释**，观众必须能依据正文中的台词、动作与已知事实推断。

## 信息如何进入冲突

信息更有戏时，至少一方对它有态度或利益：争夺（谁有权读、说、保存或解释）、验证（证据是否可信，来源是否暴露）、交换（信息换取行动、沉默、时间或关系承诺）、指控（说出事实会把责任落到某人身上）、纠正（新事实迫使对方重新选择）、回避（不回答本身暴露风险）、公开（同一句话在私下与众人面前代价不同）。

弱：

> "我们这家店是母亲二十年前开的，她把合同放在纸柜里。"

带议程：

> "你要真觉得这只是家店，就别拿母亲那把纸柜钥匙。"

后者不必一次交代所有背景，却把历史、所有权和当下动作绑在一起。

人物不会为了观众重复彼此都熟知的事实。让说明带着争取目标进入；能由动作或证据表达的部分，不再由两人完整复述。**动作已经让观众看懂机制时，台词优先承担新的工作**：改变关系、收窄结论、隐藏态度或迫使下一步。若一句话只是逐项复述观众刚看到的因果，删掉后画面仍完整，就让人物回应结果而不是给画面配答案。

## 人物声音如何区分

"一个总说成语，一个总说网络词"只是表面。更稳定的声音来自人物看世界和处理关系的方式。五个维度：

1. **注意什么**：流程、感受、风险、体面、具体物件、长期后果；
2. **怎样证明**：举证、引用规则、讲关系、诉诸经验、逼对方表态；
3. **怎样控制距离**：直呼名字、使用称谓、说"我们"、避免代词、公开或私下说；
4. **怎样隐藏**：多解释、反问、开玩笑、沉默、改话题、过度精确；
5. **压力下怎样变形**：更正式、更短、更礼貌、更粗暴、开始重复或突然坦白。

再加入关系特异性：同一人物面对上级、家人、陌生人和需要保护的人，不会使用完全相同的语言策略。

轻量声音卡（内部使用，不要求成为交付字段）：

```text
角色：
默认策略：
认定什么才算证据：
最常回避的主题：
建立亲近／权威的方式：
压力下的变化：
对角色 A 的称呼与禁区：
绝不会自然说出的表达：
```

不要把声音卡变成强制口癖表。成品中偶尔偏离也可能体现关系或状态变化。

**判据**：如果交换说话者后台词仍完全成立，缺失的是目标、关系或认知差，不是词汇。人物可以极简、健谈、书面、地方化、诗性或笨拙，不要用统一的"自然口语"抹平风格。

## 让对话改变权力与关系

现场权力可能来自：谁能结束谈话或打开门；谁持有可验证证据；谁能让话语公开；谁承担更少退出成本；谁能定义问题与可接受答案；谁愿意付更高代价；谁掌握第三人的信任。**权力不是音量。**

台词改变权力时，应有后续动作证明：对方交出物件、改称呼、停止解释、转向第三人、撤回条件或离开原位置。

关系变化不必由"我不再信任你"宣布，可以通过：从私名称呼改为正式称谓；把共同物品变成个人物品；不再替对方撒谎；首次在第三人面前支持或反对；接受条件但拒绝情感解释；把选择权还给一直被保护的人。

关键对白结束后，至少能指出信息、权力、关系、情绪行动或物理状态的一项变化；否则这一轮只是重复。关系也可以有意维持僵局，但僵局要增加成本、暴露策略或改变观众理解，而不是静止。

## 动作、停顿、打断与沉默

对话间的动作应当完成一件事：操作筹码或证据；改变距离和公开范围；显示话语与行为不一致；给对方一个必须回应的新事实；记录连续性变化。避免在每句间插入"看了看、笑了笑、皱眉"。

停顿要有对象。不要只写"沉默片刻"，写清停顿期间人物在避免、等待或判断什么：

> 岑放没有回答。他把纸柜钥匙从钥匙圈上拆下来，却没有递过去。

这段沉默包含选择，下一句会因此不同。

打断可以：阻止一个危险词被说完；抢走问题定义权；保护第三人；暴露说话者已经知道答案；让本来私密的内容进入公开空间。打断后要处理未说完内容的后果，否则只是制造表面节奏。

## 长发言用动作断开

一段发言长到需要分两口气说完时，有三种处理：连排成两条同角色台词、压成一条长台词、或者在中间插一条可见动作行把它断开。**第三种通常最划算**，因为它同时解决下游两个问题：

- **给分镜一个有依据的切点**：断开处是一次可见变化，分镜可以在这里换景别或换被摄主体，而不必自己在一条长台词中间猜该切哪里——猜出来的切点没有来源，也无从核对。
- **给表演与配音一个换气口**：说话者在断开处做了一件事，这个停顿有对象，不是为了凑节奏的空拍。

**`craft_default`**：只有当发言内部存在**议程转折**时才用动作行把它断开；内部没有转折的长发言应当**缩短**，不是拆开。插入的动作必须满足上一节的标准（操作证据、改变距离、暴露言行不一、给出必须回应的新事实、或记录连续性变化），不能是"看了看、顿了顿"这类填充。断不开就说明这段话本身在替人物做说明，回到"信息如何进入冲突"重写。

判据是转折，不是字数。

反例——原稿把动作塞进台词括注里，两者都被削弱：

```text
【角色甲】：这事跟我没关系。再说，（看了角色乙一眼）你要找的人今晚也不会来。
```

改成两条台词夹一条动作行，括注只留语气：

```text
【角色甲】（轻描淡写）：这事跟我没关系。
▲角色甲抬手把话题挡回去，随即转头看向角色乙，把手里的名册翻过一页，压住了其中一行。
【角色甲】：再说，你要找的人今晚也不会来。
```

连排本身不是错误——连续两条同角色台词在人物抢话、自我修正或对方拒绝回应时都成立。留白长度、标点、重叠对白和沉默密度属于表演与风格选择，不设统一比例。

## 高密度对白场景

一室对谈也可以有强烈运动，关键是让对话不断改变"谁能做什么"。可用的可见锚点：一份可逐步露出内容的文件；一个会改变公开范围的门、电话或录音；一件所有权正在争夺的物品；一个有时间限制的现场任务；第三人的进入、离开或保持沉默；人物位置变化影响谁能读、听、拿到。

锚点服务权力变化，不是为了强行"画面丰富"。

## 与本系统的接口

- **对白要能被逐字登记**。原文已有的对白进入来源发声台账，逐字守恒；本轮扩写新增的对白属于**新增人声**，必须与原文台词分开追踪，不能混淆成原文说过的话。改写原文字句、合并句意或自造一句"原文台词"都属于来源失真，应作为新增内容登记并说明它的剧情作用。
- **对白占时按真实表演估算**。先排完整声音事件，再确定这一段有多长：有录音或配音时用实际发声区间（首尾静默与句内停顿分开核对）；没有音频时按原文、人物语速、情绪和换气估一个区间，并明确标为文本估计。不要先选定一个短时长，再要求人物加快语速把台词塞进去。
- **顺序说话的多句或多人对白累加**，句间停顿与听者反应按实际顺序加入。边说边抬眼的并行动作与对白共用时间；必须等话说完才发生的动作另占时间。不要重复计算已包含在估计里的停顿。
- **装不下时的处理**：按语义和可见状态闭合点拆段，或说明冲突并提出延长、拆段或改稿；**不擅自删词，也不把正常对白改成快读**。
- 纯动作段无需补对白预算。留白与沉默不占对白预算，但占屏幕时间，仍要算进这一段能否装下。

## 对白修订流程

1. **标注行动**：给每句写它想对对方做什么；写不出的句子压缩或转成动作。
2. **检查回应关系**：这句是否回应了上一动作，还是两人各说各的？
3. **删除共同已知说明**：人物不会为观众重复彼此都懂的事。
4. **检查策略变化**：受阻后有没有换策略、付代价或退出？
5. **交换说话者测试**：交换后仍完全成立时，补目标、关系或认知差。
6. **朗读与可表演性**：按真实语速读一遍，确认能说完、换气位置合理、断点落在议程转折上。
7. **保护风格**：人物可以极简、健谈、书面、地方化；回查上面那张反向条件表，确认方法没有用在不成立的场合。

## 失败征兆

- 角色轮流说出作者想让观众知道的内容；台词可以直接互换说话人而不损失。
- 每句都成功，对话变成演讲；或对手只会拒绝，主角只会重复要求。
- 潜台词依赖作者事后解释，正文里没有可观察的推断依据。
- 方法用得到处都是：neutral 信息的传递被硬派立场，没有对象的沉默被当作留白。
- 权力变化只用音量表达，台词之后没有任何后续动作证明。
- 对话间的动作是填充；长发言被拆开但没有议程转折。
- 所有人物用同一套"自然口语"，差异只落在口头禅上。
- 台词长度超出可说完的范围，靠快读或删词解决。
