# 前置生产扩写

仅在现有内容确有缺口时使用，准备判断见 [source-readiness.md](source-readiness.md)。交付本节点要求的唯一完整正文或同剧情结构化章节稿。保留用户意图、既有事实和来源边界，不创建画布、不发起媒体生产；图片理解是来源读取，可以在当前工具授权内使用。

## 真实素材

读取冻结 ProjectContext 中与当前内容相关的 selectedAssetSnapshot、selection、mediaUnderstanding 和 diagnostics。用户选了但尚未解析的资产仍是输入，依据精确 ID 和诊断修复读取；名称、旧 prompt、ready 状态不能证明图片内容。

依赖图片事实的创作先复用足够的成功观察，缺少关键观察时用精确 assetId 调用 tapcanvas_analyze_image。区分观察、图中文字声称、用户事实、推断和未知；不能发明主体结构或功能再称与图片一致。失败保留原因并处理可修问题，无证据处保持未知，不套广告产品或重复原样失败调用。

多图保留各精确资产身份与实际观察的对应，区分同一对象的视角、状态和不同对象；在现有交接字段或正文所需位置传递，供下游复用。图片数量不是每段引用配额。来源身份与理解回执留在 provenance，不能写成已生成结果。

## 补足实际剧情

读完整用户目标与来源，再决定缺失的是什么。补写可以完善行动过程、关系依据、必要信息或前后连接；不是给每段增加冲突、动作、策略变化或亮点。成熟来源无需再写一遍。正文中的关键判断要有可见或可听的表达，旁白、心声、对白、画面与静默由作者选择。

涉及动作时写清对剧情重要的主体、目标、路径、接触及后果，遵守来源设定和已成立的空间、持物、支撑与身体状态。只展开影响理解或后续行动的过程，不规定每个肢体细节、伤害表现、招式或力量循环。幻想能力按已建立设定表现，不能以特效描述掩盖前后矛盾；持续造物保留可辨认身份与状态，具体编舞方法确需时再读相应领域技能。

物件、产品操作和群体行动遵守同一来源边界。新增表演不得变成未确认的产品规格、功能或正史事实。观众能自然推断的交接可以省略，不能省掉导致选择或结果改变的原因。

## 全片与交接

先完成用户要求的完整剧情，再按真实供应商 Clip 合同分配内容。技术窗口接续动作与声音，不另起一轮登场、蓄力或收束；明确时空跳跃保持可辨认的连接。节奏与结尾服从本次用途，预告、氛围、演示和完整剧情不共享一种闭合义务。

明确时长时按实际发声、行动和必要反应理解容量，估算不冒充录音或实演。超载先调整自己增加的内容与组织；不可丢剧情或擅改冻结台词。用户未限定总长时由真实内容决定合法片段组合，不用重复姿势、运镜或同义说明填时间。

交接前对照来源与唯一整稿回读，发现具体缺失或矛盾在同链修订并复读受影响段落。工作记录与工具回执如实保留；自审不成为生产门禁，也不重提已经受理的媒体。方法与案例按实际缺口选择，不规定阅读量，未读取不声称引用。
