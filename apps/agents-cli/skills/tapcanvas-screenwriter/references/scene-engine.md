# 场景组织

按需读取，帮助解决当前场景的因果、表演或信息问题；不是自动加载的固定流水线。以用户目标、来源和实际正文为依据，不为每场设统一冲突公式。

理解这一场让观众看到、听到或感受到什么，以及它与前后剧情的关系。可以是行动、交涉、发现、关系、观察、仪式、等待或后果消化。判断取舍时问：删掉它会失去什么？没有独立作用且与其它内容重复时才考虑合并；平静、重复、支线和主角缺席本身不是删除理由。

目标与对抗组织的场景，可以从人物想做什么、可用条件、阻力、选择及后果理解运动。无需为普通传递虚构争夺，为每轮交谈制造策略失败，或要求每个段落变化。信息按人物能获取的顺序进入，后续判断保留依据；有意误会和留白也应保持自己的含义。

关键动作交代谁在哪里、对什么做了什么以及结果，写足影响后续行为的空间、持物和关系变化即可。内在信息可以用表演、心声、对白或旁白表达，不要求全部转成道具或微动作。只追踪有剧情作用的对象与状态，观众可自然推断的过程不机械铺满；不根据臆测的模型能力预先降级用户动作。

多人场景依据来源和观看重点组织辨识与注意，保持真实人物关系和出入，不按人数阈值删人或固定轮换主对手。证据场景区分已证明的内容、人物推测与未解事实，不把局部依据升级为全知真相，也不为普通事实重复加验证流程。

节奏与出口由本场作用决定，允许停留、开放结果或未完行动；不默认快切、高潮复位或结尾钩子。回读具体问题时同时看前后因果与状态，修订实际正文，方法不成为语义门禁。生产素材与动作交接见 [production-expansion.md](production-expansion.md)，对白见 [dialogue-craft.md](dialogue-craft.md)。
