# 针对问题修订

已有稿件需要修订时按问题选择观察角度，不是必须逐项完成的遍法。一个改动同时影响剧情、对白与表演时一起处理，没有问题不制造改动；不为检查补无依据的动作、道具、冲突或情绪起伏。

可从以下角度回读实际正文：

- 用户目标与来源：本轮产物和落点是否正确，完整剧情、人物关系及确认结果是否丢失或被替换。
- 因果与知识：重要行为和判断有何依据，角色何时得到信息，哪些不确定是有意保留。
- 声画表达：必要信息实际如何传达，说话人、视角和完整发声是否准确，潜台词是否有可理解的上下文。
- 连续性与容量：关键持物、位置、伤况和未完进程如何接续，当前真实时间合同能否承载内容，估算是否被误称实测。
- 取舍：哪些信息确实不承担剧情或体验，可精简而不丢原因、选择、关系与结果。

方法只提供诊断角度，不能以每场公式、字数、动作或检查完成数裁决质量。顺读与慢读可帮助发现指代和顺序问题，模型自述的“快读”不是真人观看实验。发现具体问题就在当前链内修订，并回看影响的上下文；不以评分、自评或建议代替改稿。

遵守现有授权与工具边界，不扩大写入范围。正文保存、事实提交及媒体结果以各自真实回执证明，任一失败如实保留具体结果，不回滚成功部分。用户只要正文时不附内部修订报告。
