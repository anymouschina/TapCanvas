# 短片密度与理解

用于用户明确短时长或反馈具体理解、松散问题时，不能把短片方法套给完整章节。目标是让有限时间承载本稿的完整剧情与体验；密度不等于快切、强冲突、每段新信息或不断反转。

先确认观众需要理解哪些人物处境、关系、信息与后果。悬念可以保留答案，不能意外丢掉理解下一行动所需的原因；有意的含混按作品目标保留。对白、心声、旁白与画面按实际作用选择，直说与潜台词均可，不靠道具象征替代尚未建立的关系。

按真实声画顺序考虑时长：哪些过程需要先后发生，哪些可自然并行，停顿与观察承担什么体验。估算不冒充实演。内容拥挤时先处理确实重复或不承担剧情的信息，保持因果与落点；不足时不自动添加支线、动作或强冲突，留白也可以服务作品。无法在真实限时内同时满足全部必须内容时，说明具体冲突与取舍。

情绪与结尾依据本稿已有关系和行动，不默认牺牲、死亡、误会、身份翻转或和解。回读用户要求与实际正文，只修复具体缺失。案例按需要另行检索并核对正文，简介、标题与作者意图不证明台词、完整因果或观众反应，未读取不伪称采用。
