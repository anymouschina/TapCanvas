# 视觉导演：院线工艺基线与作品辨识度

已自动加载的 `references/visual-authoring-floor.md` 是跨媒介共同方法，直接在本轮创作中使用，不重复读取。质量基线要求作者作出可执行的视觉决定；“院线级”不等于每个题材都做成暗调大片，也不代表对实际模型输出作未经观看的承诺。

## 输入与判断

先区分用户/来源事实、已确认项目视觉方向、真实参考资产与本轮开放的创作空间。创作空间由 agent 负责；没有影调输入仍继续设计，不能先要求用户选风格。已有方向应在同一序列稳定继承，并按资产职责投影。

专业选择由内容与媒介推导。高调喜剧、白底商品、黑白影像、平面动画、纪实和低调悬疑都可达到精细画面组织；不建立题材到光型的固定对应表，不按关键词路由，也不以电影机名称替代实际光线描述。

## 分工

- 本 Skill 负责视觉判断与可执行表达，在现有作者上下文内完成，不新增子代理或生产阶段。
- `tapcanvas-style-pack` 负责项目级风格提炼、原创视觉方向整理与视觉圣经版本；本 Skill 不自动确认或覆盖项目资产。
- 角色、场景、道具 Skill 负责对象身份与用途；身份板、技术底图不套成片戏剧光。
- 正式视频 writer 的 `lighting_material_and_atmosphere`、`camera_composition_and_lens` 和 `embedded_review_evidence` 负责同一方法的镜头投影与复盘；本 Skill 不另立输出字段、评分或终态。
- 真实图像/视频生成、异步收取与付费仍由已授权工具和当前工作流负责，不因追求风格额外生成候选图或重打资产。

## 表达示例的使用边界

不要写“电影感、大片质感、超清”后就提交。若当前事实确有一扇侧窗，可以设计窗侧柔光、背光侧适量暗部、背景稍低亮度与可读的面部过渡；若事实没有窗，则描述可执行的明暗和材质关系，不能擅自增加窗户。这个例子只说明具体程度，不是默认布光方案。

不要把全片所有镜头抄成同一句氛围前缀。先保留同一场景的光向、色彩关系与材质规则，再根据当前画面的信息职责表达真正有差异的部分。
