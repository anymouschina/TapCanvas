# 视觉创作共同基线

用户没指定影调、没给参考图时，仍由作者完成专业视觉设计；不把设计责任退给用户，不套默认滤镜，不把自己的设计伪称为用户偏好或参考图观察。“院线级”是认真处理画面组织的创作目标，不是模型名称、分辨率、认证或对未观看产物的质量保证。本方法适用于原创、改编、单图、角色/道具/场景资产、分镜、单段及多段视频、对话提示词和 Workflow 作者；事实问答、代码任务、技术拓扑与像素忠实编辑不因本方法增加艺术化处理。

## 先分清事实与创作空间

用户明确风格、媒介、保真要求、项目激活视觉规范、资产身份、剧情和供应商合同优先。读取已有事实后，作者自主决定仍开放的视觉维度；没有风格输入是创作空间，不是输入缺失。新设计记为 agent_authored，不混入用户 must/prefer、来源事实或参考 provenance。对同一项目/序列沿用已建立的方向；不得在每个资产或 clip 重新随机选风格。

上游原创/改编作者可在用户授权的设计空间内选取光线、空间和美术实现，并把选择传给资产与镜头作者。接收冻结事实的下游作者只能在这些事实内完成摄影处理：未给光源不等于允许补一扇窗、一盏灯、雨夜或霓虹；可以明确关键区域的亮度层次、高光过渡、阴影细节和不改变本色的色彩关系，保持未知光源不具名。上游方案冲突时在同链回传具体冲突，不重写事实。

## 把审美目标变成可见决定

先围绕当前故事、主体用途和媒介确定一个有理由的视觉主张，再选能真正改变画面的少量关联决定。它应能回答“为何这个内容这样拍”，不能换掉人物名称就无差别套用到所有项目。

- **影调与注意力**：谁是画面视觉重心，主体、前景和背景如何分层；亮区在哪里收住、暗区保留什么。低调不等于欠曝，高调不等于无层次。关键动作、脸、商品标识和必须辨认的空间不能被压黑、漂白或过度光晕遮掉。
- **光线组织**：依据已有或允许设计的光源写清方向、软硬、补光关系与衰减；阴天、柔光、白底、黑白和动画同样有可控层次。主光随场景空间保持一致，换机位不让光源跟着摄影机转。光变须有已有事件或已设计转场依据。
- **色彩关系**：选定主导、支撑和强调色的职责，控制饱和度与冷暖关系；人物肤色、产品本色和身份色不被全局调色改写。色彩可克制、鲜亮或单色，橙青、去饱和和暖高光都不是默认答案。不把语义估色冒充像素采样。
- **材质与空间**：根据真实材料区分漫反射、镜面反射、粗糙度与透光，让环境层次来自遮挡、距离和材质响应。不要全物体同样光滑、同样锐利；也不机械加旧化、尘雾、雨水、颗粒或磨损。动画保留其线条、色块、笔触和材质逻辑，不强行真人化。
- **构图与时间**：明确观看重点和空间关系，构图、景深、机位与运动服务当前信息变化；锁定机位、深焦和长镜头都可成立。视频从资产中继承视觉性格，并通过动作、焦点、光线连续性和切点继续表达，不用推拉摇移代替主体事件。

没有必要给每条决定填数字或设备名。未知曝光、光比、色值、机型或 LUT 不伪造为测量结果；先用可执行的相对关系。纯创作选择可具体，但必须与已知事实、参考身份和当前媒介相容。

## 让设计真正进入生成输入

共同基线只负责方法，不建立新的生产阶段、输出 schema、第二套风格真源或额外生成任务。项目视觉圣经仍由 tapcanvas-style-pack 管理，角色/场景/道具身份仍归其资产 Skill，视频 authoring contract 仍归正式 writer。

上游在现有允许字段传递设计：整片 BeatSheet 用各 beat 的 visualIntent 表达共享方向及本段变化；assetPlans 的 prompt/negativePrompt 按资产职责落实相同方向。不要添加该 schema 不支持的 filmBible 或视觉根字段。其它任务沿本轮真实上下文/现有风格字段传递，不臆造字段。

角色与道具的身份板重在轮廓、本色和材质可读，投影适用的媒介与材质设计，不把剧情夜景、情绪阴影、环境串色或动态效果烘焙进身份卡；用户参考及身份板专属拍摄合同优先。场景资产保留无人空间及固定光线，不复制角色表演。技术站位/俯视底图维持拓扑与标注可读，不强加浅景深、强阴影或电影镜头。

视频作者将当前视觉决定写进最终送模型的 lighting、materialResponse、composition、framing 等真实可执行字段或最终文本。只留在 visualIntent、continuity、自评或规划摘要里不算落地；独立提交的 clip 不能依赖供应商看不到的上一条 prompt。共享设定在每段保留必要核心，镜头只写有用差异，避免重复长前缀。lighting 可因明确不适用而为 null，不能把“用户没说”当作无需设计的理由。

## 按最终画面状态复核与修订

共享的是场景光向、色彩关系和材料本色等稳定约束；局部描述从当前画面重新推导。作者先在当前上下文确认本镜实际时间区间、可见对象、遮挡关系、接触阶段及进入/退出状态，再把共享方向投影到这一状态。状态是内部思考依据，不新增输出字段或第二份持久账本。单图采用同一方法核对其唯一画面状态。

把将真正送给模型的动作、景别、构图、镜头运动、光线、材质和声音连接起来读成一段完整画面，不借 continuity、自评或规划摘要替它解释。逐一核对其中提及的对象和反馈何时出现、何时被遮挡或离画：尚未成立的接触不拥有接触反馈，离画后的主体不因局部光色描述重新出现。一个字段写对不能抵消另一字段的错误；否定句也不能替代改写冲突的正向指令。镜头内确有阶段变化时，把局部处理明确绑定在变化之前、发生时或之后，避免整镜无条件复制结果态。

发现冲突后直接修订最终输入中受影响的所有字段，并回看相邻镜头的承接；保留未受影响的具体光色与材质设计，不能靠清空所有视觉字段消除问题。随后再次只读修订后的最终画面，确认这次修改没有残留、转移或引入冲突。动作桥、原媒介、本色和事实仍优先，不通过补日夜、光源、材质品类或故事事件来解围。这个回读属于同一次作者创作，不另开评分者或生产阶段。

有明确、可修复的作者错误就依据新证据继续修订，不以“已经改过一次”为结束理由。没有新的具体问题或只剩可选审美差异时结束；同一问题无新证据时不反复原样检查。缺少不可推导的源事实、真实参考或供应商条件时如实说明边界，继续交付可完成部分，不编造通过证据，不设运行时语义闸门。

正文稳定后再更新已有 creativeReview/selfQaNote 或本轮记录，说明实际改动及仍需外部证据的限制；不要沿用改稿前的动作摘要、推算数字或“全项通过”。评测、用户明确要求的诊断可读已有真实媒体，但不因本方法自动加跑付费生成。已受理或已生成资产完整保留，不能拦截、回滚、删除或压住交付。真实效果必须有观看证据，提示词回读不能认证动力学、身份稳定或院线成片水准。
