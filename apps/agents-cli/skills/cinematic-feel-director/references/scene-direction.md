# 从剧本到表演与声画

用于被明确委派的一场戏、一个段落或整稿的导演设计。读取本次指定的确切稿件及必要前后文；旧稿、创作闲聊和参考片的故事不是本片事实。任务只给摘录时，不假称已审完整作品。导演可以提出剧本修改，但只有任务授权改稿时才改写事件或结局。

## 找到值得拍的关系

读完戏，先辨认其中最值得让观众经历的具体变化，而不是先挑镜头。它可能是人物第一次不再服从、一次误认、一个无法收回的动作，也可能是关系迟迟不变带来的压力。选择本场的观看立场：观众与谁共同发现、比谁多知道、在哪一刻被留在外面。立场可以改变，但改变应落到实际可见或可听的事件上。

如果原稿尚无足以支撑场面的行为，不用漂亮光线遮盖这个缺口：在授权内补足人物行动，或把具体问题与可用改法交还主代理。不要为制造高潮擅自添加死亡、反转或秘密。

## 让演员有事可做

把表演意图转为角色能对另一个人实施的行为：试探对方是否知道、替对方保住体面、催促离开、争取再听一句。行为由人物关系决定，不把这些例子变成动作词配额。角色的策略遇到回应才发生变化；停顿要有正在处理的信息，移动要有目的、阻挡或接近的对象。避免每逢伤感都指定落泪、握拳或颤抖。

在既定空间中试走动作：人物需要看见谁，是否能够触及物件，另一人如何响应，关键选择发生后谁占据出口或距离。只写会影响表演和观看的空间关系，不给日常戏添加无用的精密坐标。对已有场景不能凭空新增门窗和路线来解决问题。

## 选择覆盖方式

调度、取景与剪辑应共同让事件成立。保留同框可以让观众自主比较双方；改看听者可能让台词的真实后果出现；暂不展示某项信息也可以让声音或人物反应承担期待。选取适用于这一稿的方式，不把任何方式变成固定正解。

想象按最终顺序播放：观众凭哪一个画面或声音获得下一步所需的信息？切镜后谁在哪里、朝向谁、持有什么？需保留的动作是否在可见空间中完成？省略可以有效，但不能省掉决定结局成立的因果。不是每个动作都值得一个镜头，也不是每句对白都需要正反打。

导演改稿改变叙述、对白、内心声或画面载体时，沿用编剧技能[章节改编](../../tapcanvas-screenwriter/references/chapter-adaptation.md)中的“叙述视角转成声画时”方法；需要完整方法可通过 `Skill` 读取 `tapcanvas-screenwriter` 的 `references/chapter-adaptation.md`。更换载体要保留说话者、指向对象及知情/可闻关系，再从实际呈现的前后句判断意义是否漂移。观众获知不等于人物获知；有意改变揭示时点属于需要落实到正文的创作选择，不能只换一个 VO 标签就假定转换完成。

导演意见要落实为可使用的版本。任务要求导演稿时，把表演、走位、观众信息和声画转折写入对应段落；要求局部修改就交具体替换段落及受影响的接点；要求诊断才以问题为主。不要只交“加强冲突、增加电影感”的建议。摄影方法需要细化时读取 `camera-and-light.md`。

## 创作与验证的区别

可以在内部尝试不同处理，依据用户目标和具体效果选择，舍弃的构思不必全部交付。不强制备选数量、反转次数或固定自审轮数。有明确冲突就实际修改并回看受影响的前后段；审美偏好分歧如实保留，不以评分拦截交付。文本设计不能证明演员表演或生成视频已经达到预期，既有媒体与版本完整保留。

## 方法来源

[Roger Deakins 访谈](https://studentfilmmakers.com/cinematograter-roger-deakins-asc-bsc/)说明他依剧本、演员调度与具体场地协作决定摄影，而非采用一种固定的分镜流程。上述面向 Agent 的交付与修订方式是本项目据此作出的实践设计，并非采访原话或成片验证。
