# 产品商业摄影镜头语言（电商带货/产品大片 · 导演拆镜硬判断）

> 用途：电商广告/产品片拆镜时，**电商也是摄影**——不是平铺直叙的克制运镜，是 Apple/美妆/奢侈品级的**商业广告摄影**。按下列触发条件主动设计布光、产品 hero 运镜、质感渲染、构图、节奏，落到每镜 prompt。
> 核心信条：**「干净」≠「平淡」**。产品真实(不漂移/不变形) + 布光戏剧 + 运镜精密 + 质感拉满。一致性仍最高优先，但在此之上要把产品拍出"贵、想买"。
> 物理前提继承 `镜头语言规则.md §0`：无真·高帧慢动作(升格写「动作减速+长保持」)、单镜 2–8s、运镜精密但**单方向丝滑不抽帧**、尾帧可续接。

## 1. 布光先于一切（产品摄影的灵魂）
- **硬规则**：每个产品镜必须显式写布光，不能只写"自然光/柔光"。布光决定材质能不能被读出来。
- **三光基底**：主光(key，定方向与立体)+轮廓/勾边光(rim/back light，把产品从背景剥离、勾出边缘)+补光(fill，压死黑、但留层次)。
- **按材质选光**（关键，落 prompt 写明）：
  - **金属/不锈钢/镜面** → 侧光/掠射光勾出拉丝纹理 + 控高光不死白；黑卡压反光做渐变。
  - **玻璃/液体/透明** → **背光/逆光透亮**(backlit)，让光从内部穿过，边缘亮芯通透；忌正面平光(变浊)。
  - **磨砂/哑光/塑料** → 大柔光(softbox)包裹，避免硬高光暴露塑料感。
  - **织物/皮革/绒面** → 侧逆光起绒毛与纹理层次，掠射光带出编织/毛孔。
  - **食品/饮品** → 背侧光 + 体积光/丁达尔，蒸汽/油脂/水珠在逆光下发亮。
- **氛围光**（电商也可有戏剧性）：暖金晨光(温馨/高端)、冷蓝科技光(数码/极简)、霓虹双色(潮流/游戏)、单色高对比(奢侈/编辑)——按品牌调性，写进全片 styleTone。
- 负向：avoid 死白高光、塑料感、平光无立体、过曝丢细节。

## 2. 产品 hero 运镜（精密戏剧，不是克制）
- **触发=每片至少 1 个 hero 镜**：产品作为绝对主角的定格/揭示镜，运镜要"高级感"。可用：
  - **微距推进 macro push-in**：贴近揭示质感/工艺/接缝/logo，浅景深从虚到实，丝滑减速定格。
  - **环绕/弧线轨道 orbit / arc dolly**：绕产品 90°–180° 展示立体与多面(单方向匀速，别 360 全转易抽帧)。
  - **升格质感 ramp**：注液/倾倒/飘落/喷雾/开合的决定性瞬间「动作减速 + 长保持」(非真 slow-mo)，让水珠/粉末/织物悬停。
  - **推近急停定格 push-in & hard stop**：快速推近到产品 hero 画面急停(钩子/CTA 用)，干净利落。
  - **顶降/俯冲 top-down descend**：平铺类(化妆品/食材)从俯视降到斜俯，展布局与组合。
  - **跟随手持演示 follow**：手持/上身使用产品(口播镜)，gimbal 稳跟，产品始终清晰可读。
- **AI 落地**：运镜可戏剧但**单一主方向、匀速丝滑、幅度受控**；hero 定格尾帧要稳(产品清晰、可续接)。pixverse-v6 擅长精密炫技运镜(20镜头控制焦段/光圈/景深)，hero/微距/强一致性镜偏 SD2 保产品保真；口播两模型都能念(台词写进 prompt 即可)、不必为口播换模型。

## 3. 质感渲染（拍出"想摸想买"）
- **静态质感**：材质纹理(金属拉丝/玻璃通透/磨砂细腻/皮革纹路/织物编织)、工艺细节(接缝/倒角/logo 蚀刻)、表面光泽(高光走位/反射环境)。
- **动态质感（升格点睛）**：水珠滚落、蒸汽升腾、油脂流动、粉末飘散、织物飘动回弹、液体注入分层、开合机构联动——这些是产品片的"高潮镜"，配升格(动作减速+长保持)。
- 写法：微距 + 背侧光 + 浅景深，让质感成为画面主体；avoid 糊/塑料/失真纹理。

## 4. 构图与焦段（产品的尊严）
- **hero 构图**：产品居中或三分黄金点，给足呼吸空间(留白=高级，但别空泛)；背景极简或虚化，不抢产品。
- **焦段对应质感意图**：微距(揭质感细节)、标准 50–85mm(自然产品全貌)、长焦≥85mm(压缩空间、奢侈隔离感、背景奶化)。
- **景深**：浅景深隔离产品破 AI 贴片感；多产品/平铺用中景深保清晰。
- 每镜写明焦段含义("85mm 长焦压缩、背景奶油虚化、奢侈隔离感")。

## 5. 电商节奏结构（带货叙事曲线，落到镜序）
- **钩子镜（前 1–3s，留人）**：最强冲击——产品 hero 急停定格 / 极致微距 / 升格高潮瞬间 / 痛点对比。第一镜决定划不划走。
- **卖点演示镜**：功能/使用场景/效果对比，口播台词同步(写进视频 prompt 即念，SD2/pixverse 皆可)，一镜一卖点别堆。
- **质感特写镜**：微距+升格把材质/工艺拍到极致，建立"贵/值"。
- **CTA hero 定格镜（收尾）**：产品+包装 hero 定格、品牌 logo 清晰、稳定可读，留转化印象。
- 全片 4–6 镜拼 15–30s，每镜 4–8s，尾帧链/视频续写承接。

## 6. 与一致性的关系（底线不破）
- 布光/运镜再戏剧，**产品本体必须紧贴组内真实商品图**：颜色、材质、比例、logo、包装跨镜零漂移(一致性锚：组内图 > 三视图 > 场景图)。
- hero/微距/强一致性镜偏 SD2(产品保真)，炫技运镜/转场/长时长段用 pixverse；口播不分模型(两者都念)，按上述硬能力选型；跨镜锁同一产品靠 referenceImages + 尾帧链/视频续写。
- 宁可布光简单也要产品真实——但"真实"不等于"平淡"，干净的影棚布光本身就是商业摄影。

## 7. 落 prompt 模板（电商 hero 镜示例）
