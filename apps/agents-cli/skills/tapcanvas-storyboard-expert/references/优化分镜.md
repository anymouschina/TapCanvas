# Seedance 提示词收敛指南

## 核心目标

提示词不是字段越全越稳定，而是让每个句子都承担一种可验证职责：继承真实资产、锁定空间、描述变化、限定摄影机、同步声音或交付终态。不能减少歧义、不能保存连续性、也不能改变模型执行结果的句子应删除。

`主体 + 动作 + 场景 + 光影 + 镜头语言 + 风格 + 画质 + 约束` 只是一张不确定性检查表，不是八项强制配额。真实图片、角色卡、场景卡或 `filmBible` 已锁定的信息不得在每拍重新描述。

## 编译顺序

### 1. 先写进入态与空间坐标

- 用门、窗、道路、轨道、桌边、地面标记等场景锚点定位主体。
- 世界空间优先；只有方向可能混淆时，才补“画面左/右”和“角色自身左/右”的映射。
- 写明人物或物体的距离、朝向、视线、持物、遮挡和高差；相邻阶段继续沿用同一轴线。

### 2. 再写动作因果链

每个主要动作至少能够回答：

`谁执行 → 什么触发 → 从哪里起势 → 沿什么路径变化 → 在哪里接触/做出选择 → 谁或环境如何反馈 → 最终停在哪里、保持什么状态`

不要用“拿起、跳上、走近、转身、爆炸”等一个动词吞掉完整过程。动作速度由剧情压力、距离、重量、惯性和时长决定；“缓慢、自然、稳定”不是通用防崩词，高速或剧烈动作也必须通过起势、受力、接触和制动写清，而不是统一降速。

### 3. 裁决连续长镜或内部切镜

- 真正一镜到底：只保留一条摄影机轨迹，在同一 shot 内按时间顺序写阶段；不得同时使用切到、硬切、正反打或甩到新机位。
- 允许内部切镜：每段都是一个真实 edit shot，切点必须由动作完成、视线落点、声音先入/延留、遮挡或新信息出现触发。
- 每个 shot 只有一个有动机的主运镜。写清起始构图、相对主体的方向与速度、结束构图；推、拉、摇、移、环绕不能作为互相冲突的愿望清单。
- 中文可执行描述是默认。`slow push in`、`rack focus` 等英文术语只在确实比中文更能消歧时短括注，不设“camera 必须纯英文”的格式要求。

### 4. 让声音证明同一事件

- 环境底声在起始声场建立一次，声场变化时再更新。
- 动作声按“接触前预示 → 接触瞬间 → 接触后余响”绑定可见事件，例如破风、碰撞、拖擦与落地必须与同一动作时间点一致。
- 对白、旁白和音乐只从冻结合同继承，不自行补写。静默、抽空环境声或无音乐可以是明确的声音设计。
- 音效不能替代主体动作：写了碰撞声，仍必须写谁在何处接触、受到什么反作用并落到何种终态。

### 5. 正向锁定，短约束收口

先写必须出现的主体、构图、动作路径、空间方向、资产不可变项和终态。只有真实资产合同中的 `forbiddenTransfer` 或已知模型漂移风险，才需要补一条具体约束。

不要用长负向词表列出剧情中不存在的人物、场景或事件；这会把无关概念引入模型注意力。不要用“结构正常、动作不僵硬、画面稳定、4K、电影感”替代可见动作、明确构图和物理后果。平台安全或版权限制触发时必须显式失败，不使用拆字、谐音或隐语绕过。

## 最终自检

- 去掉摄影机运动，主体、道具、关系或环境是否仍发生可见变化？
- 每次位移和交互能否复原起点、路径、接触点、反馈和落点？
- 相邻阶段是否继承上一阶段的位置、速度、受力、视线、持物和声场，而非恢复默认姿势？
- 画面方向能否从场景锚点复原，角色自身方向与屏幕方向是否互相矛盾？
- 一镜到底声明是否零剪辑词；内部切镜是否每个切点都有信息功能？
- 每个声音是否有可定位声源、同步事件或明确叙事功能？
- 风格与身份是否来自真实资产和 `filmBible`，没有逐拍重复或临时发明？
- 删除任一句后若不损失事实、连续性、因果或执行精度，该句是否已经删除？
