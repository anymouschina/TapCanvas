# 镜头语言规则（导演拆镜硬判断 · v2，经 Gemini+Codex 双审升级）

> 用途：拆镜/写每镜 prompt 时按下列**触发条件主动设计**调度、轴线、景别、焦段、构图、运镜、节奏，而不是"均匀换景别凑镜头"。每条=触发条件 + 为什么 + 怎么落到 prompt。
> 拆镜顺序（重要）：**先调度 → 再轴线 → 再景别/焦段/角度 → 再构图/景深 → 再运镜/节奏 → 最后声音与尾帧**。景别不是第一决策，关系在空间里怎么变化才是。

## 0. AI 视频（Seedance）物理前提
- **没有真·高帧慢动作**：不要写"slow motion / 子弹时间"。要"慢"就写：**动作减少 + 持续凝视/停顿 + 缓慢推拉 + 长保持**。机位运动速度 ≠ 画面内时间流逝，别混为一谈。
- **先区分生成 clip 与内部 edit shot**：付费提交的一条生成 clip 必须命中当前动态模型合同给出的合法时长档位，禁止在 skill 里写死模型下限；`shots[]` / 文本分镜表中的内部剪辑 shot 只是该 clip 内的时间轴覆盖，可以是 `1–3s` 的快切，也可以因完整动作、对白或停顿而更长。内部 shot 时长总和必须精确等于生成 clip 时长，禁止把每个 1–3 秒 shot 误当成独立生成任务。
- 运镜降复杂度：优先固定/缓推/缓拉/轻微跟随/单方向；少用环绕、快速横移、复杂打斗长跟拍（AI 易抽帧变形）。
- **clip 退出态必须可续接**：内部 shot 只需给出明确切点与动作/视线/声音/道具接力，不要求每一切都稳定摆拍；非终镜可用仍在运动中的 action-out。生成 clip 的末拍必须记录客观 `exitState`，主体、动作方向、视线、持物与环境状态可追踪；若真实尾帧要喂给下一 clip，则禁止以失焦、遮脸或无法辨认的糊帧收尾。
- 参考图职责写清：**图1 锁角色、图2 锁场景、尾帧锁上一镜动作终点**，不要只写"有参考图"。

## 1. 调度先于景别（Blocking）
每镜**先**写清：人物站位、朝向、彼此距离、谁先动谁后动、**谁占画面优势**（前景/更高/更亮/更大者占主导）。
- **硬规则**：若镜头间人物**关系没有变化**，不得只靠"换个景别"硬凑镜头数——要么让调度变化（逼近/退开/转身/夺位），要么合并镜头。

## 2. 轴线与屏幕方向（180°）
对话、追逐、打斗、多人关系**必须锁定 180° 轴线 + 视线方向 + 出入画方向**一致。
- A 看右、B 必看左（视线匹配 Eyeline Match）；A 从左出画、下镜从右入画。
- **越轴**只在：插入中性正面镜、明显转身、或重新建立空间时允许，并写明理由。否则=空间灾难。

## 3. 景别：跟叙事功能走（但别一刀切）
**分镜=信息顺序设计，不是镜头数量**。拆镜前先答三问：①先让观众**看到**什么 ②再**理解**什么 ③最后**感受**什么——AI 提示词笼统时模型会把信息平均塞满画面（画面好看但没重点），所以每镜只交付一个信息、按顺序释放。默认信息释放链：**远景交代环境→全景交代动作→中景建立关系→近景传递情绪→特写放大重点**（先环境后人物再情绪；开场特写制造悬念仍合法，见下）。
| 功能 | 景别 | 说明 |
|---|---|---|
| 建立空间/规模 | 全景·远景 | 交代谁在哪 |
| 交互/对话 | **先判断关系**：双人同框 / 过肩正反打(OTS) / 单人孤立 / 背影听话 / 反应镜头 | 对话主力是 **OTS 正反打**，不是"默认跟随特写" |
| 情绪峰值/关键物/反应/感官 | 近景·特写·大特写 | 剥离环境、强制注意力 |

**组接语义（库里肖夫效应）+ 蒙太奇四型**：观众的理解由组接产生（同一张脸后接孩子=慈祥/接钱箱=贪婪/接倒下的人=危险）——要让观众对 A 产生判断，接一个 B 镜头让观众自己得出，不必让 A 演出来。叙事工具箱四型按需取用：**时间蒙太奇**（几个变化镜头压缩长时间：钟表跳动→咖啡变冷→天色变暗）、**情绪蒙太奇**（不说情绪、用细节叠：握紧的手→额头汗→渐响钟声→逼近脚步）、**平行蒙太奇**（双线交替推进制造担心：她在人群找↔他在站台将走↔车门渐关）、**联想蒙太奇**（后镜改变前镜含义：平静的笑→刀反光→碎杯→袖口血迹）。详表与落地约束见 video-workflow `references/reference-xhs-director-theory.md` §二。
- **开场特写合法**：可制造悬念、限制信息、主观迷失。规则不是"特写前必须有全景"，而是：**若不先建立空间，必须提供替代方位锚点（声音/局部环境/后续揭示）+ 写明导演意图**。
- 对话/情感镜若选 wide/full 仍需理由，否则记 `shotSizeJustificationMissing`。

## 4. 焦段服务心理距离（景别 ≠ 焦段，必写）
同样是特写，24mm 贴脸畸变=压迫/恐慌，85mm 长焦扁平=窥视/隔离，心理天差地别。
- **广角(≤35mm)**：空间压迫、失衡、近身危险、主观恐慌。
- **长焦(≥85mm)**：隔离、窥视、压缩距离、宿命感。
- **标准(50–85mm)**：自然对话与情绪读数。
- **禁止无理由混用焦段**；每镜 prompt 显式写焦段含义（如"广角贴脸、桶形畸变、压迫感"）。

## 5. 机位角度/高度（权力维度）
- **俯拍**：弱小、被压、受困、被审视。
- **仰拍**：强大、威胁、崇高、压迫观众。
- **平视**：平等、客观、代入。
- 角度切换=权力关系切换；写进 prompt 别只写"近景"。
- **水平角度与机位高度是三件不同的事里的两件**（第三件是焦段，见 §4）：写"俯拍"时想表达的若是"从她背后越过肩膀"，那是**水平角度**不是高度，执行端按字面给一个从上往下的机位会让权力关系当场反转。水平角度（正面/斜侧/正侧/后斜侧/背面）回答"观众被允许读到多少表情、站在谁的一侧"；高度回答"谁在这一刻大于谁"，平视是主动表示势均力敌而不是"没选"。三栏缺哪栏就说明哪栏无所谓，不要写死一栏就当作另两栏有了答案。竖屏的纵向本来就长，俯仰会迅速吃掉人物可用高度，要靠角度表达权力时先看水平角度和距离能不能承担。完整对照见 `references/coverage-and-boundary.md`。

## 6. 构图交付权力关系
每镜指定：主体在画面位置（三分/中心）、视线空间、头顶空间、前中后景层次、引导线/框中框、**留白用途**。
- **留白只用于**：威胁、孤独、等待、信息揭示——不得空泛写"高级构图/电影感"。
- 给画面优势者更多空间/更前景/更亮。

## 7. 景深与前景遮挡（破 AI 贴片感）
AI 常出"单薄贴片"画面。对策写进 prompt：**浅景深 + 明确前景遮挡元素（门框/肩/植物/虚化前景）+ 前中后三层纵深**，制造真实空间体积。

## 8. 运镜：没理由别动（理由=情绪意图）
- 运镜必须**绑动作或心理变化**：跟随、缓推、后拉、摇移、手持抖动都要服务具体信息，不得装饰。每镜**先写为什么（情绪），再写怎么动（确切轨迹动词）**。
- **推镜(push-in)**=情绪放大器，且**速度=情绪强度**：慢推=情绪克制积累（士兵独行废墟缓缓推近）；快推=情绪瞬间爆发（中大奖快推到面部）。用在关键台词/反应/内心转折（哪怕只推几寸）。
- **后拉两用**：①孤独感（主体被环境吞没，必须有环境信息可展示）；②**反转/信息揭示**——先近景误导，拉远揭示改变语义的环境物（婚纱微笑→拉远见遗照）。
- **跟镜头三向=选观众视角**：后跟=最强代入、侧跟=交代人物+环境、前跟=突出表情动作。**环绕**=主角感（世界围着他转，要开阔空间）。**上摇**=气势/压迫（从脚边缓慢上抬揭示宏伟）。**希区柯克变焦**=心理冲击/恐惧（主体不变背景拉伸；优先 pixverse-v6）。
- **手持抖动**：纪实/紧张；稳定题材慎用。完整情绪映射菜单见 video-workflow `references/reference-xhs-director-theory.md` §四。

## 9. 节奏与高潮（节奏=情绪推进速度，模板≠硬节拍）
- **节奏的本质是情绪推进速度，不是运镜速度**——镜头不是记录动作，是控制观众情绪。段落级先选节奏类型：**情绪铺垫型**（慢、少切换，给观众观察细节的时间→孤独/高级/沉浸）、**信息压迫型**（快切+多信息同步推进→动作/悬疑/追逐）、**情绪爆发型**（**先压抑再释放**，快慢反差→高潮）。高级节奏感=快与慢、动与静、压抑与释放的反差。
- 一段视频是**重音分布**：全快=麻木，全慢=拖沓。前面有常速垫，重音才砸得实。
- `0-3/3-9/9-12/12-15s` 只是**参考模板，不是硬节拍**——喜剧/惊悚/动作/情绪戏信息密度完全不同，按题材调。
- **五个镜头级节奏技巧**：①**镜头前摇**（动作前给准备动作：开门前犹豫/说话前吸气/奔跑前重心变化，治"动作来得太突然"）；②**情绪停顿**（静止镜头本身是情绪，关键情绪点给静止特写——是"动作收住"不是"画面冻结"，镜内仍要有呼吸/尘埃级微动）；③**情绪切镜**（切点按情绪拐点找不按动作完成找：嘴上平静但眼神慌乱→切特写放大）；④**环境节奏**（环境参与情绪：压迫→风变大、孤独→空间变空、紧张→灯光闪烁）；⑤**突然抽空**（高潮后突然降速/静默：追逐后突然安静、争吵后突然沉默、爆炸后只剩耳鸣——反差让冲击力翻倍）。
- **高潮不止一种解法**：除"特写+缓推+长保持"外，常更适合：静止远景、突然切黑、反应留白、声音抽空、宽景展示不可逆后果。别把所有高潮拍成同一种。

## 10. 特写触发条件（满足其一才上）
情绪峰值（微表情）/ 关键物（导演指物）/ 反应镜头 / 触觉感官点。特写要写"画面被脸或物占满 + 浅景深 + 那个要被读到的细节"。

## 11. 光线与色彩（服务叙事反差，别教条）
- 主光方向/色温/对比是情绪语言，但**不是固定映射**：暖光也能恐怖、冷光也能清醒/神圣/安全。**色彩服务的是叙事反差**，不是查表。
- **每镜必须显式写光（方向+质感+色温），「没写光」比「写错光」更糟**——具体光型选词（八光词表：逆光/顶光/丁达尔/底光/侧光/硬光/柔光/蝴蝶光，含逐光 prompt 短语）以 `cinematic-feel-director` skill 的光型词表为真相源，按情绪意图取用、非机械映射。「普通人用光照亮人物，导演用光塑造故事。」
- 同一情绪段落光线要一致（防漂移见 [[一致性锁定卡]]）。

## 12. 声音设计（短视频的节奏骨架）
写进每镜：环境音、对白密度、**静默的用法**、声画错位、**J-cut/L-cut**（声音先入/延留）、动机声（开门/水声触发切点）、音乐重音。声音常比画面更决定节奏。

## 13. 表演行为链（驱动视频模型）
不要只写"眼眶泛红"。写**可拍的行为链**：动作前犹豫 → 视线逃避 → 呼吸停顿 → 身体后撤 → 手指收紧。给模型连续可执行的微表演，而非静态情绪词。

## 14. 信息密度
**一个镜头只交付一个主信息**；复杂动作给更长保持；台词镜头按字数/停顿估时长。信息塞太满=模型糊。

## 15. 拆镜自检（输出前逐条过）
1. 先写调度了吗？关系没变是否在硬凑镜头？
2. 轴线/视线/出入画方向锁了吗？有没有越轴没解释？
3. 景别选对且非常规有理由？对话是否误用"默认跟随特写"而非 OTS？
4. 焦段/机位角度写了心理含义吗？还是只写了景别？
5. 构图有没有交付权力关系？留白有没有具体用途？景深/前景层次写了吗（破贴片）？
6. 高潮镜是不是被设计成重音？是否千篇一律"特写+缓推+慢"？高潮后有没有「突然抽空」镜（留白/静默）？
7. "慢"是不是错写成高帧慢动作？是否改成了"动作减少+凝视+缓推+长保持"？
8. 是否区分了生成 clip 的合法时长档位与内部 shot 的剪辑时长？内部 shot 总和是否精确等于 clip，快切是否有真实切点，clip 末拍的 `exitState` 是否可续接且不糊不遮脸？
9. 声音/表演行为链写了吗？
10. 节奏是否张弛有度？全片是不是一个节奏跑到底（全快=麻木/全慢=拖沓）？关键动作有没有前摇？
11. 每镜写光了吗（方向+质感+色温，按情绪选八光语汇）？运镜写明情绪理由与速度了吗（慢推=积累/快推=爆发）？
