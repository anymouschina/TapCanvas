# TVC 证据化局部重试

成片复盘的目标是保护成功资产，只修证据指向的失败层。复盘不是生成后的拦截器；所有已生成视频、图片、节点状态、URL、日志与元数据必须保留，后续只追加诊断和修订版本。

## 1. 建立证据包

优先使用当前真实工具返回的：

- 最终视频 URL、真实时长与镜头边界；
- 等间隔抽帧和失败动作附近的连续帧；
- 带时间码转写、声音起止与重复位置；
- 实际使用的 prompt、参考素材职责和导演合同；
- 用户明确指出的成功项、失败时间码与必须保留内容。

只有总结、印象或模型自报结论时，标明证据有限；不要伪造逐帧事实。TapCanvas 已有 `tapcanvas_analyze_video` 可提供只读复盘证据，但它不得改变生产 run 终态、自动返工或丢弃资产。

## 2. 先冻结保留项

按层写出已经成功且本轮不改的内容：

- 商业策略/SMP；
- 产品身份、材质、包装与参考资产；
- 人物身份、造型与表演；
- 场景、光线、摄影与剪辑节奏；
- 旁白、音乐、产品声；
- hero、packshot、endboard 与已有资产 URL。

用户说“前十秒满意”时，把这段作为时间范围保留；不要只写“整体风格保留”这种不可验收的空话。

## 3. 只选一个主修层

| 主修层 | 证据 | 局部修法 |
|---|---|---|
| 商业策略 | 产品不参与因果、主张无法复述 | 重写对应模块的产品/品牌作用，不自动换视觉资产 |
| 信息与节奏 | 长时间无新状态、同功能镜头连续 | 压缩或替换失败模块，保留已成功模块与结尾 |
| 产品物理 | 手在动但结构不变、受力/完成态缺失 | 补结构与受力链，或改预开/拆镜/实拍，不重做人物 |
| 人物/连续性 | 身份、座位、手部归属或产品状态漂移 | 固定对应资产与空间关系，只重做受影响镜头 |
| 声音 | 旁白重复、串角色、硬停止后回声 | 修 cue sheet/音轨，保留成功画面 |
| 品牌交付 | packshot 过早过长、精确文字错误 | 调整结尾预算或后期图文，不推翻前段故事 |

多个问题并存时，先修对观看理解影响最大的层；其余作为后续独立修订，不把所有变量塞进同一次重试。

## 4. 输出局部重试合同

```text
保留范围：明确时间段、资产与成功层
失败证据：时间码 / 连续帧 / 转写 / 用户反馈
唯一主修层：本轮只改什么
替换模块：新的开始状态 → 事件 → 结束状态
不变约束：产品、人物、声音、场景或结尾中哪些保持
验收证据：下一版要从哪些时间码/帧/声音事件确认修复
```

重试只生成必要的新版本，不覆盖旧结果。若供应商已受理异步任务，先等待真实完成证据，禁止因复盘判断重复付费提交。

## 5. 复查

- 每条失败判断是否有可回查时间码、帧或音轨证据？
- 保留项是否具体到时间范围和资产，而非一句“其他不变”？
- 本轮是否真的只改变一个主修层？
- 新模块是否有可见结束状态和明确验收点？
- 已生成资产是否全部仍被保留并可追溯？
