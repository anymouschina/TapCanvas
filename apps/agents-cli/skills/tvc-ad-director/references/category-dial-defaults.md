# 品类证据镜头（不是默认工作流）

品类只决定“观众凭什么相信”，不替代商业路线、SMP、声音与时长决策。先完成 `品牌记忆 / 产品证明 / 转化行动` 路线选择，再从下表挑本片真正需要的证据；不要整行全抄进提示词。

| 品类 | 优先证明 | 可见证据 | 常见失真 |
|---|---|---|---|
| 茶饮 / 酒 / 传统食品 | 香气、液体、饮用仪式 | 透光、挂杯、蒸汽、器皿接触与人物余味 | 只拍氛围，不见真实产品状态 |
| 美妆 / 护肤 | 质地、使用触感、肤感结果 | 膏体/液体流变、取用量、接触点、自然皮肤光泽 | 质地漂移、塑料皮肤、未获批功效前后对比 |
| 服饰 / 穿搭 | 版型、垂坠、行动中的轮廓 | 全身走位、转身后轮廓、面料受风与褶皱回落 | 只拍脸和快切，看不清衣服 |
| 家居 / 香氛 / 文创 | 空间体验、材质、使用时刻 | 人物动线、窗光变化、触摸与物件关系 | 空房漫游，产品与生活因果断开 |
| 珠宝 / 腕表 | 工艺、尺度、佩戴后的身份感 | 微距结构、金属/宝石受光、佩戴接触与稳定 hero | 无限环绕和光扫，没有新的产品信息 |
| 3C / 数码 | 交互、结构、即时结果 | 屏幕/部件状态变化、手部操作、环境反馈 | 参数字幕替代证明，复杂手部与精确屏幕同镜争夺 |
| 食品 / 饮料 | 口感、风味、食欲与余味 | 断裂、气泡、流动、蒸汽、入口触发和特异反应 | 通用慢镜、无触发微笑、风味只靠旁白 |
| 汽车 | 车身材质、动态稳定、驾乘体验 | 流动反射、轮胎/路面反馈、低机位与环境尺度 | 只拍空洞速度感，车身比例和品牌特征漂移 |
| 地产 / 酒店 / 展厅 | 空间就是产品，重点是动线与尺度 | 入口到核心空间的连续关系、材质、光线时段、人物使用 | 随机房间拼贴，空间方位和尺度无法成立 |

## 选择方法

1. 从本片 SMP 反推一个**主要证明**；最多补一个互补证明。
2. 把证明写成 `触发动作 → 可见反馈 → 观众结论`，不要写形容词清单。
3. 产品动作涉及开合、按压、倒出、涂抹或撕裂时，先写结构与受力，再写质感。
4. 品牌记忆路线可让品类证据短暂出现；产品证明与转化路线需要给证据可读时间。
5. 模型、分辨率、时长、参考素材数量与声音能力始终以后续真实工具/schema 为准，本表不提供执行参数。

## 自检

- 关闭旁白和字幕后，证据镜头还能支持主张吗？
- 去掉产品后，这个变化还会发生吗？若会，产品因果不足。
- 这两个证据是否互补？若只是同一动作换景别，删一个。
- 精确包装识别与复杂产品操作是否拆开，避免一个镜头同时承担两个高风险任务？
