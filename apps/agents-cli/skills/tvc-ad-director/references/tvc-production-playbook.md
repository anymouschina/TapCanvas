# TVC 生产导演手册

本手册只在主 Skill 已选定商业路线后读取。它把商业判断编译成时间、产品、声音和品牌收束，不建立平行工作流。

## 来源与迁移边界

本手册吸收并改写以下 MIT 仓库的可迁移机制：

- [`nutllwhy/seedance-tvc-director@9fef40f`](https://github.com/nutllwhy/seedance-tvc-director/tree/9fef40f955f476551eb7e6fc5a7355f7dbc44181)：15/30/自定义时长的信息预算、前三秒事件、产品受力链、旁白单一真源、hero/packshot 预算与证据化局部重试。
- [`s1dashu/director@0972f54`](https://github.com/s1dashu/director/tree/0972f5489740949e0927dc492e3593f385a4f37c)：`内容模式 → style/资产 → tool` 职责分层、参考素材单一职责、镜头开始/动作/结果/摄影终点与按需加载。

没有迁移：上游 CLI 命令、供应商优先级、固定模型/720p、声音资产、二进制素材、未验证的模式、生成前语义阻断，以及与 TapCanvas 现有生产 Skill 重复的编排。当前工具/schema 与用户合同始终优先。

## 1. 把创意写成可验证的商业合同

用这一句内部策略检查方向：

`让[受众]在[具体情境]中相信/感到/采取[唯一变化]，因为[产品或品牌造成的可见证据]。`

去掉品牌名后任何同类都能照搬，说明主张仍不够专属。其余卖点只能作为证明，不得与 SMP 并列抢主线。

## 2. 钩子是事件，不是陈列

有效开场包含四个要素：

1. 第一帧已有情境、欲望、动作、决定、反应或结果；
2. 很快出现可见触发，而不是先等产品显形；
3. 观众能说出一个继续观看才能回答的问题；
4. 该问题直接指向产品、品牌态度或核心主张。

可选机制：结果先行、感官打断、未完成动作、人物瞬间、痛点被打断、现实规则发生矛盾。城市空镜、人物慢慢回家、孤立产品悬浮、Logo 淡入和纯光影奇观只有在它们本身承担商业事件时才成立。

开场使用过的核心动作、景别和视觉异常视为已消耗创意资产；中段只有改变意义后才能回收，不能原样重复填时长。

## 3. 时长是信息预算

### 15 秒

建议骨架：`事件钩子 → 产品/品牌触发 → 一个证明或体验 → 品牌收束`。优先单一空间、3–5 个镜头。若证明需要观察时间，减少场景，不把动作剪碎。

### 30 秒

仍只服务一个 SMP。用 5–7 个叙事模块规定新信息与截止状态，模块内部可以自然形成多个有效镜头；通常全片 8–12 镜。较克制的高端片可以更少，但长镜头内部必须出现状态发展。

让每个模块至少新增一种信息：情境、人物关系、产品触发、材质/机制证明、结果、品牌回收。新机位、换景别、变光色和重复旋转不算新信息。

场景数量由因果决定：

- 一个连续使用仪式或空间发生不可逆变化，可留在单场景；
- 使用前后、私人到社交、现实到品牌隐喻等反差需要两个场景；
- 多个互补情境或关系递进才使用三个场景。

场景之间只选一个主要接口：动作结果、道具运动、形状、光线方向或声音桥。转场是短接口，不是吞掉新场景的漂浮旅程；若风味世界或机制隐喻承载独立信息，就把它当正式场景预算。

### 自定义时长

不要缩放模板。先确认准确秒数，再按当前真实模型入口决定单条或分段；超出单次能力时，每段都要有独立开始状态、完成事件、结束状态和剪辑接口。无法核对能力时显式标注，不承诺单次完成。

## 4. 产品必须产生因果

为每个产品镜头写：

`开始状态 → 谁触发 → 产品如何响应 → 人物/环境发生什么结果 → 结束状态`

去掉产品后结果仍会发生，说明它只是贴片。人物反应也必须有可见触发；未接触、未看见、未听见产品结果的人不能直接进入通用陶醉表情。

复杂开合、撕裂、按压、倒出、涂抹使用五段受力链：

`初始结构 → 锚定点 → 施力点与方向 → 材料反馈 → 完成状态`

参考图看不清包装结构时，不猜缺口、瓶盖或泵头。采用预先打开、声音桥、拆镜或后期实拍，并如实说明。精确品牌正面与复杂手部动作分镜完成。

切镜前让动作结果可读，或让下一镜第一帧继承结果；不要为增加镜头数剪掉关合、接触、入口或落下的完成态。

## 5. 区分三个品牌结尾资产

- **Hero reveal**：产品如何进入品牌高潮，强调运动、光线、尺度或材质关系。
- **Packshot**：卖的具体是什么，强调稳定、完整、可识别的产品/包装。
- **Endboard**：观众记住谁、下一步做什么，承载 Logo、主张、CTA 与法务。

三者不是三个相似定帧。Hero reveal 与 packshot 相邻时可合成“动态进入完整产品 → 稳定识别”的连续收束；endboard 使用获批图文资产后期完成。品牌记忆路线可以没有行动 CTA，产品证明与转化路线按目标决定。

## 6. 声音只保留一个真源

声音模式与时长、商业路线独立：

- 有旁白：旁白只补画面无法准确表达的信息；
- 无旁白：用产品声、环境声、音乐与静默让主张仍可理解；
- 两版都要：分别调整镜头停留和声音结构，不是简单删除音轨。

有旁白时建立唯一 cue sheet：每句只有一个 `VO ID`、一份原文、明确说话者、开始/停止位置和一次默认发声。镜头表只引用 VO ID，不重复粘贴原文；否则视频模型可能把每次出现都当新发声请求。逐字准确的商业文案把生成音轨视为 guide VO，再用正式配音/TTS 后期替换并转写核对。

## 7. 参考素材实行单一职责

按当前真实连接顺序声明每个素材“负责什么 / 不负责什么”：

- 产品图负责产品身份、比例、材质与包装方向，不继承背景或图中文字；
- 人物图负责身份、发型、体态与服装，不固定场景构图；
- 参考视频负责摄影轨迹或动作节奏，不复制人物、产品与品牌；
- 音频负责音色或节拍中的一种，不同时充当准确台词真源。

同一维度只有一个最高优先级来源。没有真实附件时不虚构素材编号，只连接当前片段确实需要的资产。

## 8. 交给视频提示词 specialist 的镜头事实

每镜至少提供：

1. 场景与开始状态；
2. 主体、位置和朝向；
3. 唯一主要动作及执行者；
4. 动作路径、速度、受力与可见反馈；
5. 摄影机起点、主要运动、停止位置与结束景别；
6. 声音事件；
7. 产品/品牌任务；
8. 结束状态与切镜许可点。

参数由工具传递，不重复塞进创作 prompt。删除空泛质量词时，保留素材职责、空间方向、动作过程、可见结果和摄影终点。
