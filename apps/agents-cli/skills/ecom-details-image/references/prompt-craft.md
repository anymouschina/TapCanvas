# Prompt 工艺

## 通用 prompt 结构

默认用英文写 prompt，除非用户要求其他语言。按此顺序组织：

1. **Campaign Style Lock**（多图任务必填，每张完全一致）
2. 主体与场景
3. 图片目的与情绪意图
4. 构图、镜头与取景（含显式角度关键词）
5. 光线、颜色、材质与纹理
6. 风格与真实感等级
7. 平台限制与画幅比例
8. 图片内文字处理（内容与字号见 `conversion-sequences.md`）
9. 负面约束

prompt 要具体到可直接执行，但不要过度规定与用户目标无关的细节。

## 精简原则

GPT-Image-2 在**结构清晰、信息具体**的 prompt 下表现最好。

- 只包含核心信息，去掉冗余约束与重复描述。
- 自然语言优于关键词堆砌。
- 明确描述材质纹理：磨砂玻璃、拉丝金属、哑光饰面、丝绸光泽。
- 始终包含光线方向与质量；场景图指定色温（如 `色温 5500K`）。
- 不要把太多场景、风格、情绪要求塞进一条 prompt。
- 用户提供参考图时，传入参考图比文字描述更有效。
- 中文字用「」包裹；复杂笔画字换简单同义字（95% 准确率不是 100%）。
- 本项目分辨率封顶 2K，不要在 prompt 里写 `8K` / `4K` 这类超出实际能力的口令；需要强调细节时写 `high detail`、`ultra-detailed textures`。

## 风格变体速查

每个模板通常带 3-4 个变体，常见类型：

- **luxury** — 高端奢华：Rembrandt 光线、金色点缀、深色渐变
- **minimal** — 极简现代：纯白/浅色、干净线条、大留白
- **fresh** — 清新自然：明亮自然光、柔和粉彩、通透感
- **tech** — 科技感：戏剧性侧光、深色背景、金属质感

## Anti-AI 真实感（UGC / 直播 / 社媒）

生成 UGC、直播或社媒内容时，必须让图片看起来像真实拍摄：

- 指定具体手机型号：`iPhone 14 Pro`、`iPhone 15 Pro`。
- 添加可见瑕疵：毛孔、轻微噪点、暖色偏移、不完美构图。
- 使用真实感语言：`NOT professional photography`、`NOT AI-generated look`。
- 展示真实环境：略微凌乱、真实物品、水渍、用过的毛巾。
- 参考胶片色调：`Kodak Portra 400 color feel`。
- 明确声明：`NOT retouched, NOT smoothed`。
- 避免典型 AI 词汇：不用 `perfect`、`flawless`、`stunning`、`hyper-realistic`。
- 对应模板若有 `anti_ai_tips` 字段，生成该场景时必须遵循。

## 多图生成执行规则

用户要求直接生成整套电商图片时：

1. 先建立 Campaign Style Lock，并写入图片包计划。
2. 为每张图建立编号、用途、画幅、图片内短文案与独立 prompt。
3. 主图默认 `1:1`，详情页默认 `2:3`，一律 2K。
4. 一张图一份 prompt，避免一条 prompt 生成多屏拼图。
5. 每条独立 prompt 必须以同一段 Style Lock 开头。
6. 保持同一 Style Lock 逐张提交，便于用数据比较风格而不是凭审美调参。
7. 平台不支持某个比例时改用最接近的支持比例，并在结果中说明。
8. 不要虚构认证、实验数据、评分、销量、真实评价或品牌授权；缺失处写 `proof placeholder`。
9. 某项生成失败时保留已成功资产并如实报告该项失败，不用占位图补位、不静默换模型。

## 参考图使用

- 有用户产品照片时优先使用；这是保证产品外观准确最有效的手段。
- 传入方式与职责字段见 `SKILL.md` 的「出图执行」一节；只传节点/资产 ID，不传 URL。
- 素材外观高度可替换的商品（服装面料垂坠、3C 接口与按键细节）翻车率最高，应优先依赖参考图而不是长文字描述。
