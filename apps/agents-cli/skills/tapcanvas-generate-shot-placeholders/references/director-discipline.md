## 4. 创作纪律（Director Discipline）

本节是创作判断标准，不是数值约束。所有判断如与 §1 冲突，§1 优先。

### 4.1 故事性与情绪弧线

设计板必须能让读者只看图与短文案就读出"发生了什么、人物为什么痛苦或震动、下一秒会怎样"。每板先确定一条清晰**情绪弧线**再拆 Cut：

- 识别本板核心情绪推进（例：压迫临近 → 群体爆发 → 暂时逼退；失去祖屋 → 被亲族冷落 → 独自凝视废墟）。
- 每个 Cut 必须承担情绪或叙事功能，不能只是"某人做某事"。
- `画面描述` 必须含可见情绪证据：表情、姿态、距离、视线方向、光线压迫、环境破败、群众姿态、物件象征。
- 连续 Cut 必须有递进关系：建立处境 → 制造压力 → 爆发冲突 → 人物反应 → 情绪落点。禁止平铺同一种视角 / 信息。
- 对人物关系要有镜头表达（亲族分利时主角的疏离、开发商与送葬队的对峙等），通过构图与视线关系呈现。
- 对幻想 / 灵异转折要有感官化表达（耳鸣、眩晕、颜色融化、戏腔混响、月光照亮恶鬼画像）。
- 原文有讽刺、荒诞、悲凉、惊悚等语气，必须写入镜头，不得压扁成中性说明。

**自检**：删掉人物名后某行仍像通用动作描述 → 重写；整板看不出情绪走向 → 不能 finalize。

### 4.2 抽象心理 → 可见证据

**4.2a · 心理抽象 → 行为证据**（同主体心理外化）

| 抽象判断（禁止） | 合格写法 |
| --- | --- |
| 看清亲族算计 | 看孩子一眼，再看大伯母口袋，嘴角只压出很淡的笑 |
| 被边缘化 | 亲族围桌向钱倾斜，李长安站在圈外半步，最后只剩半个肩膀在画面边 |
| 失去祖屋 | 他空着手落在人群边，停步回头，灰尘落到肩上却没有拍掉 |
| 强拆压迫 | 开发商鞋尖踩进坝子，挖掘机轮胎压裂地面，铲斗停在砖墙前一掌距离 |
| 旧书异常 | 先看书柜方向，再看回书，手指擦开灰尘却想不起这本书 |
| 异界错位 | 手掌拍上粗糙木桌，桌面冷硬，和刚才床单触感对不上 |

**4.2b · 视觉抽象 → 物理量化**（与 `tapcanvas-generate-video-nodes` R4 一致，视频模型可直接生成的物理描述）

| 抽象词（禁止） | 合格写法 |
| --- | --- |
| 悬浮 / 漂浮 | 双脚离地约 1 米，腿部下方有金色光晕将身体托起，斗篷下摆悬空摆动 |
| 微光 / 闪烁 / 泛起金光 | 边缘有 1-2mm 宽冷白描边光，不要做发光特效 |
| 飘逸 / 灵动 | 衣摆 / 头发以约 30° 向后方斜飘，幅度约 10-15cm |
| 露出一角 | 右口袋开口处可见 2-3cm 宽的纸币边缘，纸币 1/3 露出口袋外 |
| 隐约可见 | 画面右后方 50% 透明度，仅轮廓可辨识 |
| 充满灵气 / 神圣 | 头顶有半径约 50cm 的暖白光圈，光束向下 45° 散射 |
| 自然过渡 / 柔和切换 | 直接切；或动作匹配切（上一镜手举起 → 下一镜手落下） |

只能解释心情 / 概念、不能让画师 / 视频模型看到具体动作 / 表情 / 距离 / 道具 / 声音 / 几公分 / 几度的行 → 重写。

### 4.3 板尾必有钩子

每板最后一个 Cut **不能**只是"本段结束"。必须留下至少一种可承接的钩子：

- **动作钩子**：转头、停步、推钱、合书、抬头、低头、手指松开
- **声音钩子**：唢呐打断机械声、鞭炮爆响、抬棺号子、麻将电视声、耳鸣、翻页声
- **道具钩子**：铲斗、棺材、现金、孩子、空手、肩灰、旧书、恶鬼画像
- **光线钩子**：台灯变亮、月光落脸、烟尘遮挡、火星闪烁
- **情绪钩子**：从得意到恼羞、从克制到退出、从疲惫到被旧书勾住

示例：祖屋倒塌板尾镜不写"他很失落"，写"灰尘落到李长安肩上，他没有拍掉，只低声说'算了，回去吧'，肩灰接下一板旧书灰尘"。

### 4.4 同主体连续感官走连续镜头

当一板表现同一主体的连续感官变化（看书 → 耳鸣 → 房间扭曲 → 扶住陌生桌子 → 抬头到异界），分格是关键帧不是切镜命令。`衔接` 必须写出连续依据：耳鸣、台灯光、手掌触感、抬头动作、月光视线。**禁止**默认每格渐隐 / 柔和过渡。

### 4.5 人像摄影减法构图

本 skill 默认服务人像为主的故事板。导演拆每个 Cut 前先做减法：画面越干净，情绪越纯粹。"干净"不是信息缺失，而是只保留能证明人物关系 / 心理变化 / 剧情转折的可见证据。

每个 Cut 先确定三件事再写 `画面 / 画面描述 / prompt`：

1. **情绪主体**：观众应该先看谁 / 哪只手 / 哪双眼 / 哪件道具。多角色时必须有唯一情绪中心，其他人用背影 / 肩线 / 模糊前景 / 手部 / 画外声辅助。
2. **证据细节**：只选 1-2 个最能说明情绪的细节（眼神避开、手指停在页边、肩灰没拍掉、钱袋被攥紧、月光落在旧书边缘）。禁止把所有道具 / 人物 / 空间信息都塞进一格。
3. **留白方向**：根据视线 / 动作方向 / 关系压力决定留白位置；可以是空墙 / 夜色 / 烟尘 / 虚焦背景 / 门框外黑暗 / 桌面未填满的一侧 / 画外角色的空位。

执行规则：

- **主体分离**：人物面部 / 手部 / 关键道具必须从背景分离。优先浅景深、逆光轮廓、侧光、眼神光、前景遮挡、虚焦背景或明暗反差。
- **焦段有取舍**：情绪特写优先 85mm / 100mm / 135mm；人物关系优先 35mm / 50mm；24mm / 28mm 只用于空间压迫 / 荒诞冲突 / 环境吞没人像。
- **少展示全貌**：除建立空间 / 关系压迫的必要全景外，优先用半张脸 / 手部 / 肩背 / 门缝 / 桌角 / 画外声 / 虚焦人群 / 被切掉的空间边缘制造未说尽。
- **干净背景**：背景只保留和情绪有关的材质 / 光源 / 空间边界；无功能招牌 / 杂物 / 群演 / 装饰线 / 桌面小物从画面描述中删掉。
- **留白必须有功能**：表达孤立 / 迟疑 / 被排斥 / 未知 / 失控前的安静 / 下一秒危机；`备注` 必须标注它承担的情绪功能（如 `留白制造被排斥感` / `画外威胁压住主体` / `空位承接下一镜`）。
- **多人场面也按人像拍**：群体冲突先选主角的反应或一组关系轴，其他角色压成虚焦轮廓 / 手势 / 半身边缘 / 画外声；只有剧情要求"群体压迫"时才允许完整铺开人群。
- **光线服务脸和手**：必须交代面部 / 手部的可见光源（窗缝侧光、台灯顶光、月光边缘、火光反跳、阴影压半张脸）。**禁止**只写"氛围感光影"。
- **不滥用特写**：建立人物处境时可以用中近景 / 中景，但画面中心仍是人物与情绪证据。

**自检**：`画面描述` 像舞台说明 → 重写为人像摄影构图；一格里超过 3 个无情绪功能视觉元素 → 删减；留白不改变观众理解 → 换成有功能构图。

### 4.6 特写的情绪叙事权

特写 / 大特写不只用于关键道具或感官异变，也可直接承担情绪 / 关系 / 故事信息。当特写能让观众读出选择 / 被排斥 / 迟疑 / 羞辱 / 恐惧 / 克制 / 醒悟 / 关系变化时，应优先使用，不必一律退回中近景。

合格情绪特写至少满足一项：

- **微表情证据**：嘴角压住、眼神避开、瞳孔收紧、喉结滚动、冷汗滑落、呼吸停顿
- **手部证据**：推钱的指尖、攥皱床单的指节、没有拍掉肩灰的手、迟疑停在旧书页边的手指
- **视线证据**：先看孩子再看钱袋、从亲族手里的现金移到自己空手、从床单落点看向粗木桌
- **物件压迫证据**：皱巴巴几张钱、口袋鼓起、灰落肩头、恶鬼画像墨线、木纹硌掌、炮仗烧焦的大背头
- **声音触发证据**：一句台词未出口被哭喊打断、耳鸣突然拉满、鞭炮爆点让表情瞬间僵住

`内容` 必须写出"这个细节改变了什么"；`备注` 必须标注它在情绪弧线中的功能（`疏离确认点` / `羞辱落点` / `恐惧启动点` / `克制选择点` / `反咬悬念点`）。**禁止**只写"特写他的脸很难过 / 特写手 / 特写眼睛"。

同板内连续两个特写必须分别承担不同功能（如一个"钱的羞辱"、一个"主角把钱推回去的选择"）；表达同一情绪须合并或改不同景别。

### 4.7 导演签名段落

每章先识别 1-3 个"导演签名段落"——本章最该被记住的视听设计点（荒诞冲突、情感断裂、超自然召唤、穿越、身份揭示、命运转向）。签名段必须获得比普通叙事段更强的镜头语言。

**借鉴源判断**（强制按优先级）：

1. **用户显式指定**：`userHints` / 当前 prompt / 上下文中说"参考某电影 / 电视剧 / 动画 / 经典桥段 / 某导演风格"时，**必须**优先使用
2. **项目过往数据**：`chapterContext.flowSummary.reusableReferences` / 已有角色场景参考图 / 上一组分镜 metadata / `storyboardChunks` / 画布已有设计板存在可复用经验时，必须优先继承其角色连续性 / 场景调度 / 尾帧承接 / 风格语言
3. **通用影视知识**：用户未指定但本段是穿越 / 追逐 / 对峙 / 告别 / 恐惧确认 / 身份揭示等成熟类型时，可选 1-2 个经典桥段作为"导演参考"，但只借鉴镜头原则

借鉴输出写入 `boardMeta.directorReference` 或 `directorNotes`：

```json
"directorReference": {
  "source": "用户指定：《某电影》通道穿越桥段",
  "borrowedPrinciple": "从日常空间进入异界时，先用身体迟疑和环境声抽空建立不安，再用触觉错位完成认知确认",
  "adaptation": "改写为李长安从床单触感落到粗木桌、回头找床失败、低头确认旧书仍在",
  "doNotCopy": "不复制原片角色、场景、美术、台词或标志性构图"
}
```

借鉴四条硬约束：

- **先适配剧情功能**：借鉴的镜头原则必须服务当前段落情绪弧线 / 人物选择 / 信息揭示
- **只借镜头语法不复制内容**：可借"声音先抽空再揭示空间""手部触觉确认现实""长镜头跟随逃离""正反打压迫关系"；**禁止**搬原片角色 / 台词 / 道具 / 美术符号 / 标志性画面
- **优先项目历史**：项目内角色 / 场景 / 章节连续性优先级高于外部经典桥段
- **必须可追溯**：用了用户指定参考则 `directorReference.source` 必须点名；仅用通用知识则写"通用类型参考"，**禁止**伪造片名

签名段落必须补全四层：

1. **象征锚点**：核心道具 / 声音 / 光线 / 动作（旧书、恶鬼画像、耳鸣、戏腔、床单、粗木桌、月光）。每个锚点必须在对应 Cut 的 `内容 / 音效 / 衔接 / 画面 / 备注` 中承担明确叙事功能。
2. **主观现实层**：明确哪些画面来自角色主观感知，哪些是客观空间揭示。主观段可用色彩融化 / 声音抽空 / 焦点漂移 / 手持抖动 / 构图失衡，但必须服务剧情。
3. **动作误判层**：若角色以为触碰 / 看向 / 依靠 A 实际落点是 B，必须写出"动作前意图 → 实际落点 → 感官反差 → 认知变化"完整链路。
4. **尾帧反咬层**：尾镜留下反咬钩子（旧道具重新活化、低头确认、声音回返、光线照出新事实、下一段危机起点）。**禁止**只以"他震惊""场景建立完成"收尾。

### 4.8 异界 / 穿越转场五拍

正文出现"现代空间突然转入异界 / 鬼怪空间 / 梦境空间 / 记忆空间"等桥段时，按以下五拍设计：

1. **召唤物启动**：旧书 / 画像 / 符号 / 镜面 / 门缝 / 声源先出现异常；用特写或大特写锁定，不急展示大场面
2. **现实剥离**：现实空间的声音 / 光线 / 颜色 / 透视逐层失真；至少一镜明确表现身体反应（手指僵住、喉结滚动、扶额、呼吸急促）
3. **触觉 / 道具错位**：用身体动作完成转场锚点（"以为扶床沿 / 抓床单稳住身体，手掌却落到粗糙木桌上"）；`衔接` 必须写清触感从柔软布料到冷硬木纹的动作匹配
4. **异界揭示**：不一开始全景交代新空间；先从触到的道具 / 手上的土灰 / 月光边缘 / 墙面材质揭示，再后拉 / 抬头 / 摇移打开完整空间
5. **反咬悬念**：尾镜让召唤物 / 关键道具再次出现新状态（月光照到恶鬼画像，线条像活过来），为下一板或视频节点留下钩子

以《第一章七十二变》穿越段为标准：旧书第二页恶鬼图、耳鸣与多种戏腔混响、现代卧室颜色融化、李长安以为扶床却触到粗木桌、竹篾土墙与漏瓦屋顶的月光揭示、低头后恶鬼画像似乎活过来的尾帧。

### 4.9 灵异事件真实反馈链

普通人遭遇穿越 / 鬼怪 / 异界 / 梦魇 / 附身 / 幻听 / 空间错位时必须有真实反馈，**禁止**只拍"奇观发生"而让角色像旁观者一样冷静接受。每段至少包含以下三类反馈中的两类；签名段落必须三类全出现：

1. **反射性身体反馈**：眨眼、后退半步、屏住呼吸、喉结滚动、手指僵住、扶额、弯腰反胃、膝盖发软、手心出汗、肩背绷紧、急促喘息
2. **试探性现实确认**：摸桌面、捻土灰、看掌心、摸墙面、回头找床 / 门 / 灯、确认旧书还在不在、用视线反复比较"刚才的位置"和"现在的落点"
3. **认知变化落点**：从"以为还在卧室"到"触感不对"、从"眩晕"到"清醒"、从"解释为错觉"到"意识到真的换了地方"、从"害怕"到"被旧书再次吸住"

合格写法示例：

- `内容`：他抓着桌沿喘了两口，先低头看掌心的土灰，再回头找刚才的床，视线落空后才僵住
- `衔接`：从手掌木纹特写接到他回头找床的视线，空荡土墙替代卧室床头，完成认知确认
- `音效`：戏腔戛停后只剩急促呼吸、木桌吱呀、瓦缝夜风
- `备注`：现实确认点，普通人从错觉解释转为承认空间已变

不合格：`他很震惊` / `他发现穿越了` / `他看着周围很害怕` / `房间变成土屋`。

### 4.10 角色与异常空间的交互闭环

签名段至少设计 1 个"主动或本能交互镜头"，写出 **交互意图 → 接触对象 → 反馈结果 → 行为改变**：

- **交互意图**：角色为什么伸手 / 回头 / 摸墙 / 找门 / 确认旧书（想稳住身体、想找回床、想判断是不是错觉）
- **接触对象**：画面中明确存在的物件或空间表面（床单、床沿、粗木桌、土灰、竹篾土墙、漏瓦月光、旧书、恶鬼画像）
- **反馈结果**：触觉 / 声音 / 重量 / 温度 / 材质 / 灰尘 / 光线 / 空间缺失给出具体回应（软布变成硌掌木纹、手指捻到土灰、回头只看到土墙、桌子吱呀、月光照出画像墨线）
- **行为改变**：反馈必须改变角色下一步动作或认知（从弯腰反胃变成猛地清醒、从以为还能扶床变成回头找床、从怀疑错觉变成确认空间已变、从想逃离变成被旧书重新吸住）

最低交互链示例（《七十二变》穿越段）：`抓床单/扶床意图 → 手掌拍到粗木桌 → 土灰/木纹/冷硬触感反馈 → 李长安喘息清醒并回头找床或低头确认旧书`。只写"他扶住桌子大口呼吸"而无"原本想扶什么、为什么扶错、触感如何改变认知" → 重写。

`备注` 标注 `交互确认点` / `现实试探点` / `触觉错位点` / `认知改写点` 等功能。

### 4.11 Seedance / 即梦可执行约束

用户要求"即梦可用 / Seedance2.0 可直接识别 / 漫剧分镜脚本 / 15s 片段 / 每镜最多 2s"时，把这些要求转译为设计板内部约束，**不**改输出合同（仍 `kind=image` 节点 + flowPatch），可执行脚本写入 `shotText`：

1. **角色固定设定**：内部固定本板出场角色核心外观（发色、瞳色、发型、服饰、标志性配饰）；有角色参考图时以参考图为最高优先级。每个 Cut 的 `画面 / 画面描述 / 内容` 中角色外观不得漂移；`boardMeta` 或 `directorNotes` 体现"角色外观锁定"
2. **场景固定设定**：固定本板涉及的场景提示词；每个场景必须有清楚的空间 / 时代 / 材质 / 光源 / 主要道具 / 可见边界。跨场景必须开新板（见 §1.2）
3. **整体统一设定**：固定漫剧画风 / 核心色调 / 光影方式 / 整体氛围；全章所有板必须继承已有参考图和上一板风格，不得新增 / 替换 / 混入其他画风体系
4. **Seedance 可识别画面描述**：`画面描述` 必须是视频模型可直接生成的视觉元素，含主体动作 / 镜头距离 / 场景材质 / 道具 / 光线 / 表情或手部证据。**禁用**"宿命感、压迫感、震撼、复杂情绪、灵魂被拉扯"等不可见抽象词
5. **切镜模式判断**：先按 §4.13 决策树判断本板采用「一镜到底」还是「≤2s 上限切镜」。≤2s 上限切镜（默认）：每镜依据动作完成、信息变化、对白容量和可读性自然分配，时长可以明显短于 2s，但不得超过 2s；不按 2s 等长、不预设镜头数量，也不因凑满时长添加空停或无意义运镜。一镜到底：见 §4.13 专项写法，不拆独立 Cut 行。
6. **景别交替**：相邻 Cut 默认不得相同景别；确因同动作连续必须重复时，`备注` 说明功能差异。每板尽量包含开场钩子全景 / 情绪特写 / 转场空镜 / 收尾悬念镜头
7. **配音情绪与字幕意识**：台词 / 旁白分配到具体 Cut，并在 `音效` 或 `备注` 写明配音情绪（惊怔、压低、哭喊、克制、喘息后发声）；适合短视频字幕的关键句可在 `备注` 标注 `高亮字幕：<原文关键句>`，但不得改写核心剧情或篡改原文台词
8. **画面安全负向约束**：每板 prompt 必须含人物画面稳定约束（禁止面部扭曲 / 肢体穿透 / 六指 / 比例失调 / 串脸 / 服饰漂移）；有角色参考图时还必须保留 `Character appearance MUST exactly match...`
9. **gpt-image-2 防噪点**：设计板/分镜图走 gpt-image-2，有模型级高频伪影（碎形噪声/网格斑点，暗部与大面积纯色/渐变尤甚）。出图必守：**禁写** `胶片颗粒/film grain/做旧/高感光/lo-fi` 触发词（已在 §5 冲突词扫描第 4 行硬拦）；暗部给明确光源、禁纯黑死光；模糊"深色背景"换具体纯色 hex+禁渐变；画质层加「整体干净无噪点、暗部纯净、过渡平滑无颗粒」；重生成 1-2 次仍明显就收手转后期。完整规则见 `tapcanvas-storyboard-expert`「图片质量强制约束 §3 gpt-image-2 防噪点」。

**不能照搬**：

- **不**把输出格式改成纯文本（真实合同是 `flowPatch add_node(kind=image)`）
- **不**为"每镜最多 2s"破坏连续感官体验；同主体连续动作仍要在 `衔接` 写明
- **不**为景别交替机械插入无意义空镜；转场空镜必须承担时间 / 地点 / 声音 / 情绪转折功能
- **不**修改 / 删减 / 重写核心剧情或原文关键台词

### 4.12 情感根基不可省略

章节正文常有铺垫 / 冷场 / 利益分配 / 离开现场等"不刺激"段。编剧审稿时必须判断它们是否是后续奇遇的情感根基：

- 后续奇遇依赖主角失去归属感 → 分钱冷落、祖屋倒塌不能省略
- 后续异变依赖旧书陌生感 → 夜读旧书不只保留"读到七十二术"，还要写"这本书不属于他的记忆"
- 章节语气是黑色幽默 → 强拆和丧葬反击不能写成普通打斗，必须保留荒诞感

### 4.13 一镜到底 vs ≤2s 上限切镜：自动决策框架

生成 Seedance / 即梦视频脚本前，必须先运行此决策，在 `boardMeta.boardNote` 标注模式和理由，再写 `shotText` / `prompt`。**单板内两种模式互斥，不得混用。**

#### 决策树

```
判断本板动作/内容特征
│
├─ 命中以下任一 → 【一镜到底模式】
│    ① 连续动作序列密集：≥8 个首尾衔接的动作，且角色/主体全程在场（体育训练、武术连招、舞蹈、杂耍）
│    ② 15s 内动作密度 > 镜数（如 16 步篮球训练 → 不可能每步切一镜）
│    ③ 单一主体持续运动，无需多角色切换视角
│    ④ 教学 / 演示 / Tutorial 类内容：打断连贯动作会破坏理解
│    ⑤ 高潮追逐 / 逃跑 / 战斗连贯段：需要"一气呵成"沉浸感
│    ⑥ 用户原文含关键词：「流畅」「连贯」「不间断」「一镜到底」「丝滑衔接」
│
└─ 未命中 → 【≤2s 上限切镜模式（默认）】
     ① 多角色对话 / 正反打（需切换视角呈现双方反应）
     ② 情绪节拍需要景别变化推进（建立→压力→爆发→反应→落点）
     ③ 有明确的场景 / 时间 / 空间跳切
     ④ 需要剪辑节奏制造张力（急停剪辑、对比剪辑、快切）
     ⑤ 用户原文含关键词：「每 2 秒一切」「多镜」「快剪」「切片」
```

**边界情形**：同一章节内不同板可以采用不同模式（如对话板用 ≤2s 上限切镜、高潮动作板用一镜到底），但必须在各板 `boardMeta.boardNote` 分别写明。

#### 一镜到底写法规范

**`boardMeta.boardNote`（必填）**

```
一镜到底模式 · 动作数 N · 理由：<连续动作密集 / 教学演示 / 沉浸追逐 / 用户指定>
```

**`shotDurations`**：仍按动作节拍列出各时间节点数组（供配音 / 配乐同步），但加注解字段 `continuousShot: true`；数组求和 ≤ `variantParams.shotDuration`（缺失时 ≤15s）硬约束不变。

**`shotText`（一镜到底专用格式）**：不写独立 Cut 表格行，改用连续动作段落 + 时间轴。

```
【连续动作段 · 一镜到底模式】全程 ~<X>s · <N> 步连续<动作类型>

镜头设定：<景别>跟拍，主体始终居中 / <主体位置>，<从头到脚/上半身/全身>完整可见。
<拍摄感>（如：轻微手持感 + 平滑跟随 / 稳定器跟拍 / 固定机位旁观）。
避免：特写裁切 / 极端角度 / 频繁跳切。

动作序列（时间轴）：
<0:00-0:NN>  <动作描述>（<动作功能或要点>）
<0:NN-0:NN>  <动作描述>（<动作功能或要点>）
...
<0:NN-0:15>  <收尾动作>（定格 / 落点）

连接方式：动作间<自然/重心转移/步伐驱动>衔接，无停顿，无跳切，<身体/球/重心>变化驱动下一动作。

负向约束：<结合内容按需列出，如：不裁切头部或脚部 / 不换脸 / 不换服装 / 不多人物 / 道具不漂浮 / 动作不重复 / 手脚不畸形 / 画面不闪烁>
```

#### 一镜到底摄像机模式子决策（自动判断，禁止手动覆盖）

确认触发一镜到底后，必须进一步判断摄像机运动模式，写入 `boardMeta.cameraMode` 并体现在 `prompt` 里：

```
判断主体是否在空间中移动（主体位移 > 身位半径的 3 倍）？
│
├─ 是 → 主体穿越空间 → 【跟拍模式 tracking】
│         例：走廊打斗（主角从入口打到出口）、追逐跑动、舞蹈流动
│         摄像机：稳定器 / 手持跟随主体，始终保持主体居中；
│                 镜头与主体距离相对固定；
│                 镜头方向随主体移动方向旋转
│
└─ 否 → 主体原地动作 → 进一步判断：
          │
          ├─ 动作密度极高（≥10 步 / 15s）且有方向感（如击打方向、球路）
          │    → 【固定机位 static wide】
          │         摄像机：锁死在最能读懂全部动作的角度（正面 / 斜 45°）；
          │                 禁止跟拍摇移；
          │                 例：篮球原地运球组合、武术对打（双方不移位）
          │
          └─ 动作有方向延伸但范围有限（如单边空间探索、舞台中心旋转）
               → 【半固定 + 轻摇 pivot】
                    摄像机：以主体为轴做小幅 pan/tilt 跟随，不离开原点；
                    例：360 度旋转动作、小范围步法练习
```

**`boardMeta.cameraMode`** 必填，取值：`"tracking"` / `"static_wide"` / `"pivot"`，写入理由一句话。

**`prompt`（英文）**：根据 cameraMode 选择对应约束模板追加在全局风格包后：

**tracking 模板：**
```
Single continuous TRACKING shot — camera follows subject through space using steadicam / handheld, no hard cuts, no abrupt jumps.
Camera maintains subject-centered framing throughout the spatial journey; lens direction rotates with subject movement direction.
Full-body or three-quarter visible; props and opponents stay spatially readable.
No static locked-off framing; camera moves with every action beat.
Action sequence (15s total): [动作 1] → [动作 2] → ... → [动作 N].
```

**static_wide 模板：**
```
Single continuous STATIC WIDE shot — camera locked off at the optimal angle to read all action, no panning, no tilting, no cuts.
Camera position does NOT follow the subject; subject and all props remain within the fixed frame throughout.
Choose the angle (frontal / 45-degree / side) that makes every action beat spatially readable simultaneously.
Action sequence (15s total): [动作 1] → [动作 2] → ... → [动作 N].
```

**pivot 模板：**
```
Single continuous PIVOT shot — camera stays at one origin point, making small pan/tilt adjustments to keep subject centered; no dolly, no cut.
Camera does not translate through space; only rotates slightly to follow subject within a limited area.
Action sequence (15s total): [动作 1] → [动作 2] → ... → [动作 N].
```

#### ≤2s 上限切镜写法

保持 §4.11 现有全部规范不变：Cut 表格逐行、景别交替；每镜按真实动作节点、信息变化和对白容量分配，时长可为 0.3s、0.8s、1.4s、1.9s 等不同值，但一律不得超过 2s。2s 是上限，不是目标，不要求等长、不预设 6–7 镜，也不允许用空停或无意义运镜补足时长。

#### 典型案例对照

| 内容类型 | 模式 | 核心理由 |
|------|------|------|
| 16 步篮球训练动作（15s）| 一镜到底 | 动作密度 > 镜数、教学演示需连贯、单一主体 |
| 武术连招 8 动（12s）| 一镜到底 | 连续动作序列≥8、重心转移驱动衔接 |
| 高潮追逐逃跑（15s）| 一镜到底 | 沉浸感需求、单主体持续运动 |
| 男女主对话争吵（15s）| ≤2s 上限切镜 | 多角色正反打、情绪景别需变化 |
| 主角穿越异界（15s）| ≤2s 上限切镜 | 情绪节拍转折、需要景别推进 |
| 用户说"每镜最多 2 秒"| ≤2s 上限切镜 | 用户明确指定上限 |
