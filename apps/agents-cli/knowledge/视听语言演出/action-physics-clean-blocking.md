# 动作设计·物理合理性·干净利落的动作链

> 要符合物理与人类基本认知：每个动作都得"说得通"。这是导演/分镜师的动作设计职责，不是模型自由发挥。

## 每个动作 = 发力 → 运动 → 落点（三段完整）
- 真实动作有**发力源**（蹬地/挥臂/拧腰）、**运动轨迹**、**落点/收势**（落地/收拳/重心稳住）。缺发力或缺落点 = 违反物理与认知，观众一眼觉得"假"。
- **AI 视频最高频病：动作没定义落点 → 模型用最省力的"向后飘移 + 淡出/溶解消失"补完。**
  - 实测（ch117 clip1）：「石猴王一击不中立刻抽身欲退」→ 渲染成猴王**莫名其妙向后倒退、凭空消失**。**这不是导演设计的退场，是 prompt 没给退场轨迹、模型瞎填的缺陷。**

## "干净利落"的脱离 / 退场怎么写
- 一击不中要脱离 → 给**明确的物理脱离动作 + 落点**：借爪反弹后空翻、落在三步外的碎石上；侧身一滚脱出攻击范围；蹬地跃退、落到石柱旁；转身没入阴影（**身体先转，再位移，有落脚点**）。
- **禁**：无发力的"向后平移"、"原地淡出"、"溶解消失"、"飘退出画"——全是无物理的假退场。
- 退场要在画面里**走完**（起 → 离 → 落）。时长不够就给够（见 [[pacing-shot-length-speech-rate]]）：4s 塞不下"扑击+受击+趔趄+干净退场"，要么加时长、要么把退场放到**下一镜续写**。

## 一镜一主动作（动作密度上限）
- 一条 clip 别堆 7 个节拍（显形+扑击+撞身+护光炸亮+趔趄+碎石+退场）。动作太密 → 每拍 <0.6s → 模型全演不全、退场被压成"瞬间消失"。
- **核心动作 1 个 + 收尾点缀**；多余节拍拆到相邻镜（状态接力/共享桥接帧承接·恒并发；续写链已下线·2026-07-11 口径对齐）。内部节拍数 ≤ `floor(durationSeconds ÷ 2)`。

## 与轴线/续写配合
- 退场的**银幕方向**也要守轴线（见 [[staging-axis-screen-direction]]）：向画右跃退，下一镜衔接时它仍从画右进/出。
- 受击的物理后果（趔趄方向、碎石飞溅方向）与攻击来向一致（左侧来击 → 身体向右偏）。

## 自检（三问）
1. 这镜每个动作有**发力源和落点**吗？（没落点的动作 = 会被渲染成飘移/消失）
2. 退场/脱离写了**明确物理轨迹**吗？还是只写了"欲退/消失"？
3. 一镜是不是塞了太多动作节拍？（> `floor(时长÷2)` 个就拆到相邻镜）
