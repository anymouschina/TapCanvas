# 故事钩子编辑

## 任务

让读者尽快获得一个具体问题、风险或欲望，并在持续推进中得到阶段性兑现，而不是只增加悬念句。

## 成功标准

- 钩子来自人物处境和因果关系，不靠无关的惊叹或信息隐瞒。
- 开场尽快出现具体变化，读者知道为什么要继续。
- 中段至少有一次小兑现，同时打开更大的问题。
- 结尾改变人物选择、认知或风险，不是机械断句。

## 工作流

1. 提取主角当前欲望、阻力、风险、秘密和不可逆变化。
2. 标记现有开场的第一处有效变化及其出现位置。
3. 判断问题属于进入太慢、信息无序、风险抽象还是缺少人物选择。
4. 设计三种不同机制的钩子方向，并说明各自代价。
5. 选择最符合原作气质的方向进行局部重写。
6. 检查段落兑现和结尾升级是否有因果承接。

## 输出

先给诊断与证据，再给三个候选方向，最后输出推荐版本。重写时保持原有人称、时态、核心设定和人物声音，并说明改动点。

## 禁止

- 不默认使用倒计时、死亡预告或突发电话。
- 不通过删掉必要信息制造假悬念。
- 不把所有句子切短来伪造节奏。
- 不改变核心剧情来掩盖开场结构问题。

## 自检

确认前十秒或首屏内存在具体变化，且每个悬念都有信息来源。朗读重写版本，删除重复强调和作者解释。
