落日照着社区工坊的门牌。

周禾在桌前等同伴来核对图纸。

“这回尺寸应该能对上了吧？”

上周周禾在展板前发现旧图纸尺寸有误。

他在库房找到一份保留比例尺的备份图纸。

回忆里他展开旧纸并逐项重新标记。

前天周禾帮陶叔修好工作台。

陶叔提议请两位设计同伴共同复核。

他们约好今天在社区工坊会合。

门外传来三下敲门声。

周禾整理图纸后走到门边。

门外站着许岚和孟雨。

两人各带一只工具箱。

许岚先递出测量记录。

“我是周禾，请问怎么称呼二位？”

“我叫许岚，来核对尺寸。”

“许师傅，您好。”

“这位是孟雨，负责把确认的数据记在表里。”

“孟师傅，麻烦您了。”

“二位请进，桌面已经整理好了。”

“今天我们只核对图纸。”

“我去拿测量工具。”

“先别拿，比例尺贴反了！”
